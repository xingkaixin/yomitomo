WeRead（微信読書）は優れたUIと豊富な書籍ラインナップで多くの読者に愛用されています。しかし数十冊を読了し何百ものハイライトやメモを蓄積したとき、避けて通れない課題に直面します。それは**読書思考データが閉じたプラットフォーム内に閉じ込められてしまう**ことです。

WeReadは構造化された全ノートのエクスポート機能を提供していません。読書メモを整理するには手動でコピー＆ペーストを繰り返すしかなく、過去の思いつきに対して深い論理的検証を展開することも難しく、他書と横断的に関連付けることもできません。

Yomitomoは公式のWeRead Skillオープンプロトコルを活用し、**ローカルへの完全同期と二重加工ワークフロー**を提供します。公式API経由で書籍、ハイライト、思考、読書進捗をローカルのSQLiteデータベースへ直接取得し、読書データの主権を取り戻せます。

## WeReadローカル同期ワークフロー

| フェーズ | 入力 (Input) | システム内部処理 (System Processing) | 成果物 (Output) | 機能の境界と制限 (Boundaries) |
|---|---|---|---|---|
| **API認証** | 公式WeRead Skill API Key | OSのKeyringへ安全に保存し、直接HTTPS通信を確立 | 書籍やメモを取得するための暗号化ローカル認証情報 | パスワードやアカウント機密情報は収集しません |
| **書籍同期** | 同期対象の書籍を選択 | 公式Skill APIを呼び出し、目次・ハイライト・個人メモを取得 | ローカルSQLite内に独立したミラーエントリーを生成 | ユーザーのメモと目次のみ同期し、DRM保護された本文全文の無断取得は行いません |
| **認知タグ付け** | 同期されたハイライト・思考 | 5つの認知的分類（`A`）にマッピングし、AIコンパニオンと議論 | ハイライトに紐づく深い論理的考察と対話ログ | AI機能の利用にはローカルまたはクラウドLLMのAPI Keyが必要です |
| **知識の結晶化** | 複数書籍を横断するハイライト群 | 結晶化スタジオ（`T`）に集約し、レビュー専門家が推敲 | 外部知識ベースにエクスポート可能なMarkdown結晶化カード | 成果物はローカルに保存され、WeReadクラウドへ逆送信されることはありません |

## 3ステップ実践ガイド

### ステップ1：公式Skill API Keyを取得して直接接続

Yomitomoは中継サーバーを一切介さず、デスクトップ端末からWeRead公式APIへ直接通信します。

1. ブラウザで <a href="https://weread.qq.com/r/weread-skills" target="_blank" rel="noopener noreferrer">WeRead Skill管理ページ</a> にアクセス（またはモバイルアプリの「私 > 設定 > WeRead Skill」）。
2. 「クイック設定」をクリックしてQRコード認証を行い、専用のAPI Keyを生成。
3. Yomitomoの「設定 > データソース > 微信読書」にAPI Keyを貼り付けて保存・接続テストを実施。

> 詳しい設定手順は [WeRead API Key設定ドキュメント](/ja/docs/weread-api-key/) を参照してください。

### ステップ2：柔軟な同期と認知的分類

Yomitomo内の「微信読書」専用パネルから、同期したい書籍を選択します：
- **オリジナルの思考メモを保持**：ハイライトだけでなく、WeRead上で記録した生の思考メモも一緒に同期されます。
- **認知属性を付与**：書籍を開き、ハイライトを選択して `A` キーを押すことで、5つの認知タグ（要点・前提・概念・疑問・引用）を付与できます。
- **AI専門家との多角的対話**：ディスカッション欄で `@周硯` や `@沈清源` を呼び出し、著者の論理構造を検証します。

### ステップ3：複数書籍を横断した結晶化とエクスポート

単一書籍の枠を超えて思考を整理できます。`T` キーを押して結晶化スタジオを開き、異なる書籍から共通テーマのハイライトを集約して、500字程度の高密度な知識カードにまとめ上げます。

## 対象読者と利用の境界

### こんな方におすすめ

- WeReadで膨大なハイライトやメモを蓄積しており、ローカルに永久アーカイブを構築したい読者；
- 複数書籍を横断してテーマ研究や知識アウトプットを行いたい研究者・クリエイター；
- デスクトップ環境でAIアシスタントと共に深い読書と思考の対話を行いたい方。

### 適していないケース

- **電子書籍本文の無料ダウンロード目的**：Yomitomoは公式APIを厳格に遵守し、個人のメモやメタデータのみを同期します。DRMの解除は行いません；
- **WeRead側への逆同期**：ローカルで行った深い注釈やAI対話は、WeReadのクラウドデータを書き換えません；
- **複数人でのリアルタイム共同編集**：個人用の深い思考と蓄積に特化しています。

## よくある質問 (FAQ)

### Q1: WeReadのAPI Keyを利用することでアカウントが凍結されるリスクはありますか？
**回答:** ありません。YomitomoはTencent WeReadが公式に提供している開発者向け「WeRead Skill」インターフェースを利用しています。非公式のスクレイピング技術ではありません。

### Q2: 同期されたデータはどこに保存されますか？PC移行時の方法は？
**回答:** すべてローカルのSQLiteデータベースに保存されます。「設定 > 一般」からデータベースのバックアップファイルを書き出し、新しいPCで復元できます。

### Q3: WeRead上で書籍が配信停止になった場合、同期済みのノートは消えますか？
**回答:** 消えません。一度ローカルSQLiteに同期されたデータは恒久的な資産となり、クラウド側の配信状況に左右されません。
