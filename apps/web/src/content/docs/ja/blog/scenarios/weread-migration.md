WeRead（微信読書）は豊富な蔵書と快適な読書体験で多くの読者に使われています。しかし、何十冊も読み進めてハイライトやメモが増えてくると、**自分の読書記録がアプリの中に閉じ込められたままになる**という課題に直面します。

Yomitomoは公式の WeRead Skill API を使い、ノート付き書籍のハイライト・メモ・読書記録を端末内のローカルSQLiteへ直接同期できます。同期した記録は章別に閲覧・整理でき、Markdownファイルとして持ち出すことも可能です。

## WeReadローカル同期ワークフロー

| フェーズ | 入力・操作 | システム内部処理 | 成果物 | 機能の境界と制限 |
|---|---|---|---|---|
| **API認証** | 公式 WeRead Skill API キー | OSの資格情報ストア（Keychain等）に暗号化保存し、WeRead APIへ直接HTTPS通信 | ローカル保存された認証情報 | パスワードは収集せず、中継サーバーも経由しません |
| **ノート同期** | 「WeReadを同期」（または30分ごとの自動同期）。個別再同期は「書籍を同期」 | 公式Skill APIからノート付き書籍の目次・ハイライト・メモ・読書時間を取得 | ローカルSQLiteのWeRead書籍エントリー | 同期前に書籍を選ぶパネルはありません。DRM保護された電子書籍本文の取得・解除は行いません |
| **閲覧・整理・Markdown出力** | WeRead書籍ページを開く | 章別にハイライトとメモを表示し、コレクション分類やMarkdown生成を実行 | 章別ノート一覧、コレクション整理、Markdown (.md) 出力／コピー | WeRead書籍ページは**閲覧専用**です。ページ内での `A` 注釈、`@` AI対話、まとめ（蒸留）、読書メモリー索引化は非対応です |
| **原文ジャンプ・内蔵ウェブ版** | 「設定 > データソース > WeRead」で挙動を設定し、ノートから原文へ移動 | WeReadアプリ・ブラウザ、または「Yomitomo でウェブ版を開く」で原文を表示 | 原文前後の文脈確認と継続読書 | 内蔵ウェブ版の小窓操作は進捗を書き戻さず、全画面読書時は位置と読書時間を書き戻します。ログイン状態はローカル保存され、完全バックアップの対象外です |

## 3ステップ実践ガイド

### ステップ1：公式Skill APIキーを取得して接続する

Yomitomoは中継サーバーを介さず、デスクトップ端末からWeRead公式APIへ直接通信します。

1. ブラウザで <a href="https://weread.qq.com/r/weread-skills" target="_blank" rel="noopener noreferrer">WeRead Skill管理ページ</a> を開きます（またはモバイルアプリの「私 > 設定 > WeRead Skill」）。
2. 「クイック設定」からQRコード認証を行い、APIキーを発行します。
3. Yomitomoの「設定 > データソース > WeRead」にAPIキーを貼り付けて保存し、接続テストを行います。

> 詳しい手順は [WeRead API キーの取得](/ja/docs/weread-api-key/) を参照してください。

### ステップ2：同期したノートを閲覧・整理し、原文を確認する

「WeReadを同期」を実行する（または30分ごとの自動同期を待つ）と、ノートが付いている書籍がローカルへ取り込まれます。特定の1冊だけ最新状態にしたい場合は、書籍ページの「書籍を同期」を使います。

WeRead書籍ページでは以下が行えます。

- **章別の閲覧とコレクション整理**：ハイライトと自分のメモを章ごとに確認し、テーマ別のコレクションへ分類できます。
- **読書時間の確認**：「統計 > WeRead」タブで同期された読書時間を確認できます。
- **原文へのジャンプ**：WeReadアプリ、外部ブラウザ、または「Yomitomo でウェブ版を開く」（「設定 > データソース > WeRead」で設定）から原文へ移動できます。内蔵ウェブ版では、小窓での確認は読書進捗を書き戻さず、全画面で読書するときのみ位置と読書時間を書き戻します。

### ステップ3：Markdown出力して外部ノートやAI精読につなぐ

WeRead書籍ページから「Markdown (.md) をエクスポート」または「Markdownをコピー」を使うと、章別に整理されたハイライトとメモをそのまま取り出せます。

WeRead書籍ページ自体は閲覧専用であり、そのままでは `A` 注釈、`@` によるAI対話、まとめ（蒸留）、読書メモリーの検索対象にはなりません。**WeReadのノートを題材にAIと議論したり、まとめを作成して読書メモリーへ蓄積したりしたい場合は、MarkdownでエクスポートしたファイルをYomitomoへローカルのテキスト・Markdown資料として取り込んでください。** そうすれば、他のローカル資料と同じようにハイライト・AI対話・まとめ・読書メモリーを利用できます。

## 対象読者と利用の境界

### こんな方におすすめ

- WeReadに蓄積した大量のハイライトとメモをローカルへ保管したい読者
- WeReadのノートを章別のMarkdownとして取り出し、Obsidianやローカル精読に活かしたい方
- 「統計 > WeRead」で読書時間を振り返りつつ、デスクトップで原文確認も行いたい方

### 適していないケース

- **電子書籍本文のダウンロードやDRM解除目的**：公式APIの範囲で個人のハイライト・メモ・メタデータのみを同期します
- **YomitomoからWeRead側への注釈逆同期**：WeRead書籍ページは閲覧専用であり、ローカルの操作でWeRead側のノートを書き換えることはありません（全画面での内蔵ウェブ版読書時の位置・読書時間を除く）
- **WeRead書籍ページ上での直接AI対話・読書メモリー検索**：Markdown出力後にローカルテキストとして取り込む手順が必要です

## よくある質問 (FAQ)

### Q1: WeReadのAPIキーを利用することでアカウントに影響はありますか？
**回答:** 公式のWeRead Skill APIを使用していますが、アカウント状態、将来の利用規約、APIの継続提供を保証することはできません。公式ルールに従い、認証エラーや回数制限が表示された場合はWeRead側の案内を確認してください。

### Q2: 同期したデータはどこに保存されますか？PC移行時の注意点は？
**回答:** 同期したノートは端末内のローカルSQLiteに保存され、「設定 > データ管理」からバックアップできます。データベースのみのバックアップにはローカルに取り込んだPDFや電子書籍の原本は含まれないため、必要に応じて完全バックアップを使ってください。APIキーおよびWeRead内蔵ウェブ版のログイン状態は完全バックアップの対象外のため、復元後に再設定・再ログインが必要です。

### Q3: WeRead上で書籍の配信が停止された場合、同期済みのノートは消えますか？
**回答:** 消えません。一度ローカルSQLiteへ同期されたハイライトとメモは端末内に残り、Markdownとして出力することもできます。
