WeRead（微信読書）は、中国語圏の電子書籍プラットフォームとして多くの読書家に愛用されています。何十冊もの本を読み、何百箇所ものハイライトやメモを残してきた読者も多いでしょう。しかし、使い続けるうちに必ず直面する問題があります。**蓄積された読書データが閉じたプラットフォーム内に閉じ込められている**という点です。

WeRead は構造化された全文エクスポートを提供していません。読書メモをまとめようとすれば手作業で 1 つずつコピーするしかなく、過去のメモに対して長文の考察を書き足したくても、アプリ内の簡素なコメント欄では書籍をまたいだリンクもリッチテキストの編集もできません。万が一アカウントが使えなくなれば、貴重な思考の記録は失われてしまいます。

Yomitomo は、WeRead 公式の Skill API を活用し、**ローカルへの無損失な移行パス**を提供します。書籍、ハイライト、思考メモ、読書進捗をローカル環境へ同期し、真の自由な知的生産環境でさらに深めることができます。

## ステップ 1：公式 Skill API キーを発行して直接接続する

Yomitomo は中間サーバーを一切介しません。データ同期はローカルアプリから公式 WeRead エンドポイントへの直接通信で行われます。

API キーの取得は 1 分で完了します：
1. PC ブラウザで <a href="https://weread.qq.com/r/weread-skills" target="_blank" rel="noopener noreferrer">WeRead Skill 公式管理ページ</a>を開きます（またはスマホアプリの「我 > 設定 > 微信読書 Skill」）。
2. 「快速配置」をクリックし、QR コード認証で即座に専用 API キーを発行します。
3. Yomitomo の「設定 > データソース > 微信読書」にキーを貼り付けて保存し、接続テストを行います。

## ステップ 2：必要な書籍を選んでスマートに同期

Yomitomo はライブラリ全体を無差別に取得するのではなく、必要な書籍を選択してオンデマンドでハイライトや思考メモを同期できます。

同期されたコンテンツは、ローカルの EPUB、PDF、Web 記事と同じライブラリに統合されます：

- **高度な再注釈**：同期した WeRead ハイライトに対して、Yomitomo の 5 つの認知注釈（コア論点・暗黙の前提・重要概念・疑問・引用）を適用可能。
- **思考の継続**：WeRead で残した元のメモの下に、さらに深い考察や返信を追記。
- **AI アシスタントとの共同読書**：ディスカッションスレッドで `@アシスタント名` を呼び出し、WeRead の注釈について多角的に対話。
- **複数書籍をまたぐ蒸留**：複数の書籍からハイライトを「蒸留」ウィンドウに集約し、テーマ別のリサーチノートを作成。

## ステップ 3：ローカル化によって手に入る自由

データをローカルに保有することで、閉じたサービスでは得られない自由が手に入ります：

- **全文ミリ秒検索**：同期したすべての書籍のハイライトやメモを一瞬で横断検索。
- **テーマ別の知識融合**：1 冊の枠組みを超え、複数の書籍の知見を有機的に結びつける。
- **統合された読書ダッシュボード**：WeRead の読書時間と Yomitomo の思考産出量を同一画面で可視化。
- **安全な SQLite バックアップ**：Yomitomo のローカルデータベースとして一括バックアップされ、プラットフォームの制約から完全に解放。

## こんな方におすすめ

WeRead に多くのハイライトと思考メモが蓄積されており、それらをローカルの個人資産として安全に管理し、二次加工や構造化を進めたい読者。
