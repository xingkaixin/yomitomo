個人のナレッジベースやZettelkasten（ツェッテルカステン）を運用していると、多くの人が同じ壁にぶつかります。

**収集と整理の断絶**です。リーダーで大量にハイライトを引いてそのままObsidianへ流し込むと、文脈を失った断片が大量に溜まり、整理する気力が続かなくなります。

Yomitomoは、**読書の現場で考えと対話を「まとめ（蒸留）」に仕上げてからMarkdownで持ち出す**ことで、Obsidianへ入れる情報の質を保つ役割を担います。

---

## 読書からObsidianへの4段階フロー

```text
[ 1. 原文の取り込み ]
Web記事 / 電子書籍 (EPUB・AZW3・MOBI) / PDF / テキスト・Markdown / WeRead同期ノート
      │
      ▼ (Yomitomo内での精読・ハイライト・考えの記録)
[ 2. 原文に結び付く対話 ]
ハイライト (A) + 自分の考え + 読書パートナー (@高橋 葵 / @黒沢 蓮 / @白川 澪 など) との議論
      │
      ▼ (1つのハイライトのディスカッションから「この考えをまとめる」)
[ 3. まとめ（蒸留） ]
議論の整理と差分プレビュー + レビュー担当アシスタント (藤堂 玲奈 / 伊藤 直人 など) の点検
      │
      ▼ (「Markdown (.md) をエクスポート」または「Markdownをコピー」)
[ 4. Obsidian のノート資産 ]
自分の保管庫へ配置し、タグや [[双方向リンク]] で既存の知識と接続
```

## 持続可能な知識ループを作る3ステップ

### 1. 読書の現場で自分の考えと対話を終わらせる
未整理の生ハイライトをすべてObsidianへ送るのではなく、Yomitomo内で `A` キーを使って疑問や解釈を書き残し、必要に応じて `@黒沢 蓮`（前提を問う批評者）や `@白川 澪`（概念の翻訳者）と対話します。Obsidianへ送るのは、自分の頭を通した論点だけに絞ります。

### 2. 重要な1つの対話を「まとめ（蒸留）」に整える
手元に残したい論点が固まったら、そのハイライトのディスカッション画面から「この考えをまとめる」を開きます。「議論を整理」（追加提案のみ）と差分プレビューで抜け漏れを補い、右側のレビューパネルで **藤堂 玲奈**（論理監査官）や **伊藤 直人**（最終編集者）の点検を通してから公開します。

複数資料を横断して要点を引き出したい場合は、「読書メモリー」の「ライブラリに質問」を使い、引用付きの回答をそのままMarkdownコピーして下書きの材料にすることもできます。

### 3. 内蔵のMarkdown出力でObsidianへ取り込む
Yomitomoは用途に応じて複数の場所から「Markdown (.md) をエクスポート」または「Markdownをコピー」を実行できます。

- **個別のまとめだけ欲しいとき**：まとめウィンドウ、または読書メモリーの「まとめ」一覧から出力
- **資料1本分の記録をまとめて残したいとき**：リーダーのツールバーからハイライト・考え・対話・公開済みまとめを一括出力
- **WeReadの同期ノートを取り出したいとき**：WeRead書籍ページから章別にMarkdown出力
- **複数資料への質問結果を使いたいとき**：「ライブラリに質問」の回答を引用付きでコピー

出力したMarkdownファイルをObsidianの保管庫へ配置するか本文を貼り付け、そこで既存のノートと `[[双方向リンク]]` やタグでつなぎます。原文の詳しい文脈を確認したいときはYomitomo側へ戻れます。

## よくある質問 (FAQ)

### Q1: Obsidianとの自動同期やプラグイン連携はありますか？
**回答:** ありません。ObsidianやNotionとの自動同期・双方向同期には対応していないため、内蔵の「Markdown (.md) をエクスポート」または「Markdownをコピー」を使って必要なノートを手動で取り込みます。

### Q2: Obsidian側で編集した内容はYomitomoに反映されますか？
**回答:** 反映されません。Yomitomoは原文に結び付いた精読と「まとめ（蒸留）」の場、Obsidianは長期的なリンク付けと執筆の場として役割を分けると管理しやすくなります。
