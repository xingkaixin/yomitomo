現代のソフトウェア開発において、「クラウドファースト」は当たり前の標準となりました。ドキュメントも、ノートも、読書記録もすべてクラウドに預けられています。このモデルは複数端末での同期という利便性をもたらした一方で、見過ごされがちな重大な代償を伴っています。**あなたの思考プロセスそのものが、もはやあなただけのものではなくなっている**という事実です。

読書データは、単なるスケジュールやタスクリストとは根本的に異なります。本文の横に残した直感的な疑問、著者の主張に対する違和感、複数の概念を頭の中で結びつけた思考の跳躍——これらは**あなた自身の認知の軌跡そのもの**です。それらを外部のクラウドサーバーに預けることは、事業者に分析され、AI の学習データとして使われ、最悪の場合はサービス終了とともにデータが消滅するリスクを無条件に受け入れることを意味します。

Yomitomo は明確に異なる道を選択しました。それが**ローカルファースト（Local-First）**です。

## 完全なデータ主権：すべてのデータはあなたの端末に完結

Yomitomo で扱うすべてのデータ（Web 記事、EPUB 電子書籍、PDF 論文、ハイライト、思考メモ、ディスカッション履歴、蒸留ドラフト、読書統計）は、あなたの PC のローカルディレクトリに 100% 保管されます。Yomitomo がユーザーの読書内容を収集するクラウドサーバーは存在しません。

- **アカウント登録不要**：ダウンロードして起動すれば、すぐに使い始めることができます
- **サービス停止の不安ゼロ**：外部サービスの規約変更や終了に左右されません
- **完全オフライン対応**：機内モードでも一切の制限なく精読と蒸留を行えます
- **プロファイリングの排除**：あなたの興味関心や思考パターンがアルゴリズムに覗き見られることはありません

## OS ネイティブの安全な認証情報管理（Keyring）

外部の AI プロバイダー（OpenAI、Anthropic、DeepSeek など）と連携する際も、API キーを平文のテキストファイルに保存することはありません。

macOS のキーチェーン（Keychain）や Windows の資格情報マネージャー（Credential Manager）といった OS ネイティブのセキュア領域で管理されます。ローカルの SQLite データベースにはプロバイダー設定とキーの参照情報のみが保持されます。また、AI との通信はあなたの端末からプロバイダーのサーバーへ直接行われ、Yomitomo が中間プロキシとして通信を傍受・中継することはありません。

## オフラインでこそ真価を発揮する強靭さ

クラウド前提のツールは、通信が切れると表示が崩れたり利用不能になります。一方、ローカルファーストである Yomitomo は、コンテンツの解析、電子書籍や PDF の閲覧、多層注釈、ディスカッション、知識の蒸留といった中核機能がオフラインで完全に動作します。ネットワークは外部の AI モデルを呼び出す際に追加のパワーをもたらす手段にすぎません。

## オープン規格：ベンダーロックインからの解放

ローカルファーストはデータの閉鎖性を意味しません。Yomitomo は SQLite データベースの完全なバックアップ・復元機能を標準搭載しています。独自のブラックボックス形式ではなく標準の SQLite 形式で保存されるため、将来的に他のツールへデータを移行・抽出することも容易です。WeRead（微信読書）から同期したノートもローカル SQLite に保存され、特定プラットフォームの制約から解放されます。

## 思考の自由：監視のない私的空間で深く学ぶ

真の読書とは、自分自身と深く対話する極めて私的な営みです。初歩的な疑問や荒削りな仮説を恐れずに書き留められる環境があって初めて、人は本質的な学び（深い認知の変容）を遂げることができます。

思考のプライバシーを守ることは、知性の独立性を守ることに他なりません。
