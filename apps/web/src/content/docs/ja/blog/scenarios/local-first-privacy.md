今日、多くの読書・ノートアプリが「クラウドファースト」をデフォルトにしています。しかしこの便利さの裏には見過ごされがちなコストが存在します。それは、**あなたの知的思考データが、もはや完全にはあなた自身のものではない**ということです。

読書中の思考データは極めてプライベートなものです。それは公開されたToDoリストとは異なり、**あなたの脳の思考プロセスそのもの**です。それらをサードパーティのクラウドに預けることは、データの解析、AI学習への無断利用、サービス終了によるデータ消失リスクを受け入れることを意味します。

Yomitomoは根本的に異なる道を選びました。それが**ローカルファースト（Local-First）**です。

---

## ローカルファーストのアーキテクチャとデータフロー

| コンポーネント | 入力と操作 (Input) | システム内部処理 (System Processing) | 保存と成果物 (Output) | セキュリティと境界 (Boundaries) |
|---|---|---|---|---|
| **ドキュメントライブラリ** | EPUB・PDFの取り込み、Web記事の保存 | ローカルで構文解析し、ファイルシステムへ永続化 | ローカルSQLiteリレーショナルデータベース | 中継サーバーなし。読書内容を収集するクラウドDBは存在しません |
| **注釈と思考の履歴** | ハイライト（`A`）、メモ、ディスカッション | 物理アンカーの紐付け、5分類の管理、ミリ秒単位のインデックス化 | ローカル構造化知識グラフと全文検索インデックス | 完全オフラインで検索・編集が可能 |
| **AIモデル認証情報** | BYOK API Key（OpenAI / Claude / DeepSeek / Ollama） | OS標準の安全なKeyring（macOS Keychain / Windows 資格情報マネージャー）で暗号化管理 | ローカルSQLiteには設定情報とKey識別子のみ保存 | デスクトップからモデルAPIへ直接HTTPS接続。中継は一切なし |
| **知識の結晶化とバックアップ** | ハイライトを集約してMarkdownカード化 | ワンクリックで標準SQLiteバックアップおよびMarkdown書き出し | ローカルの `.sqlite` ファイルおよび標準Markdownファイル | オープンフォーマットを採用。ベンダーロックインを排除 |

## ローカルファーストがもたらす4つの安心

### 1. データ主権：全データが100%ローカル端末内に保持
Yomitomoのすべてのデータは、お使いのPC内に保存されます。アカウント登録やログインは不要で、サードパーティの規約改定やサービス終了の影響を一切受けません。

### 2. ハードウェア級の認証情報保護：OS標準Keyringの活用
API Keyはプレーンテキストとして設定ファイルに保存されることはありません。macOS KeychainやWindows資格情報マネージャーに暗号化保存され、データファイルがコピーされてもKeyは漏洩しません。

### 3. オフラインで完結：通信は機能の拡張であり前提ではない
オフライン状態でも、EPUB/PDFのレンダリング、多層注釈、ディスカッション閲覧、結晶化編集が100%動作します。ローカルのOllamaモデルと組み合わせれば、完全脱ネット環境でAI伴読が可能です。

### 4. オープン標準フォーマット：ロックインを排除
すべてのノートは標準のSQLiteおよびMarkdownで保存されており、将来的にいつでも他ツールへ移行可能です。

## 対象読者と利用の境界

### こんな方におすすめ

- 機密文書、論文、商業レポートを扱い、プライバシーとデータ主権を最優先する知識労働者；
- SaaSのサブスクリプションやデータ囲い込みに疲弊したユーザー；
- フライト中やオフライン環境で集中して読書と思考を深めたい研究者；
- 自前のAPI KeyやローカルLLM（Ollama）環境を活用したい方。

### 適していないケース

- **複数人でのリアルタイム同時共同編集**：個人の深い思考環境に特化しています；
- **事前パッケージ化されたクラウドAI従量課金**：API Keyは各自でご用意いただく仕様です。

## よくある質問 (FAQ)

### Q1: 複数台のPC間でデータを同期するにはどうすればよいですか？
**回答:** 「設定 > 一般」からデータベースのバックアップファイルを書き出し、iCloud DriveやDropbox等の個人用ストレージ経由で別PCにインポートすることで移行可能です。

### Q2: 登録したAPI KeyがYomitomoの開発者に送信されることはありますか？
**回答:** 一切ありません。Yomitomoは純粋なデスクトップクライアントであり、通信は直接モデル事業者のエンドポイントに対して行われます。

### Q3: Yomitomoが更新を停止した場合、過去のノートはどうなりますか？
**回答:** 標準的なSQLiteファイルとして保存されているため、一般的なデータベース閲覧ツールやスクリプトでいつでも全データを抽出できます。
