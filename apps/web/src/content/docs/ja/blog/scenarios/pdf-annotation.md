YomitomoではPDFのテキストを選択し、ハイライトに自分の考えとAIとの対話を残せます。注釈は原文の位置に結び付けて端末内に保存します。macOS・Windows向けの無料アプリで、AIには自分で設定したモデルを使います。

Yomitomoプロジェクトがv0.18.2の機能と設定に基づいてまとめたガイドです。

## 1. PDFを取り込む

ライブラリの「+」からPDF文書の追加を選び、ファイルを選択するか追加画面にドラッグします。1回に最大10ファイル、1ファイル120MBまで取り込めます。

取り込み後に文書を開き、文章を選択できるか確認してください。画像だけのスキャンPDFにはOCR機能がないため、別のOCRツールでテキスト層を追加する必要があります。

PDFリーダーはPDFiumで描画され、「幅に合わせる」「ページ全体」「100%」および `⌘/Ctrl + / − / 0` で表示倍率を調整できます。ダーク表示時は既定で元のページ色を保ちつつ、必要に応じてダーク保護フィルターへ切り替えられます。単段テキストPDFでは、ページ単位の二言語対訳も利用できます。

## 2. ハイライトと自分の考えを残す

1. 気になる文章を選択します。
2. 必要なら選択範囲のハンドルで端を調整します。
3. 標準ショートカットの `A`（考えを記録）、または選択メニューのワンクリック「ハイライト」で注釈を作成します。
4. 疑問や自分の解釈を書き、必要に応じてハイライトの色を変えます。

たとえば論文の結論に線を引き、「この主張を支える実験はどこか」と記録します。あとで注釈を開くと、元の位置に戻って前後の文脈を確認できます。

## 3. 同じ箇所についてAIに質問する

ハイライトの対話欄で `@` からアシスタント（`@黒沢 蓮` や `@白川 澪` など）を選び、質問します。テキスト選択時の `Q` キーや「アシスタントに頼む」からも質問できます。利用前に[設定、モデル、データ管理](/ja/docs/settings/)でモデルを設定してください。手動の読書とメモにはモデルAPIは不要です。

質問は「この段落の前提を挙げて」「この説明と図の結論は一致するか」など、原文と照合できる内容から始めます。AIの回答だけで正しさを判断せず、参照した文章や図を自分で確認してください。

対話を整理して残したいときは、そのハイライトのディスカッション画面にある「この考えをまとめる」から「まとめ（蒸留）」を作成できます。

## 保存と共有の範囲

| 項目 | 対応範囲 |
| --- | --- |
| 注釈・対話・まとめ | YomitomoのローカルSQLiteに保存 |
| 元のPDF | Yomitomoの注釈をPDFファイルへ書き戻す機能はありません |
| Markdown出力 | リーダーツールバーからPDF全体のハイライト・考え・対話・公開済みまとめを「Markdown (.md) をエクスポート」または「Markdownをコピー」可能。個別のまとめも出力可 |
| 外部ツール連携 | Obsidian・Notionとの自動同期、LaTeX・BibTeX出力、注釈付きPDF出力は非対応 |
| 複数端末への移行 | 「設定 > データ管理」のバックアップと復元を利用。原本も含める場合は完全バックアップを選択 |

フォーム入力、署名、注釈付きPDFの納品が目的なら、その機能を持つPDF編集ツールを使ってください。

## PDFの内容は外部に送信されますか？

取り込んだPDFと注釈は端末内に保存されます。リモートAIを使う場合、質問や翻訳に必要な原文・対話の内容は設定したモデルの接続先に送信されます。端末内のモデルを使えば、そのモデルへの推論処理をローカルで行えます。

機密資料を扱う場合は、接続先と組織の利用ルールを確認してください。保存先がローカルであることと、すべてのAI処理がローカルであることは別です。
