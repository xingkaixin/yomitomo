## 読書ビュー

リーダーには、本文、ハイライトマーク、ハイライト接続、およびサイドバーが含まれています。フローティング ツールバーでは、目次、検索、ハイライト ナビゲーションなどの一般的なアクションに加え、現在の項目についてアシスタントに質問するための永続的なチャットが提供されます。 Web 記事はバイリンガル翻訳もサポートしており、翻訳が本文に適用される際に影響を受ける段落に関するフィードバックが表示されるため、どのテキストが変更されたかを確認できます。

- **目次**: 目次を切り替えて章リストを展開します。アクティブなセクションが強調表示されてフォーカスされるため、現在の位置から周囲の構造を検査できます。
- **検索本文**: 現在の項目内のキーワードを検索し、一致する位置にジャンプします。
- **ハイライト ナビゲーション**: 本文をスクロールせずに、前のハイライトと次のハイライトの間をすばやく移動します。

レイアウトを調整できます:

- ウェブ記事と電子ブック: **フォント サイズ** と **記事の幅**。
- PDF: **PDF ズーム** を使用してページ サイズを変更します。これは、他のソース タイプのフォント サイズとページ幅に対応します。

テーマとリーダー用紙は、リーダー内からではなく、**ホーム** ページのテーマエントリ (明、暗、黄昏、その他のテーマとリーダー用紙) から切り替えられます。紙の色は、Web 記事、電子ブック、PDF の閲覧面に影響します。ダーク モードでは、PDF は元のページの色を維持します。

## ハイライトを作成する

1. リーダーでテキストを選択します。
2. ドラッグ可能なハンドルが選択範囲の両端に表示されます。ハンドルをドラッグすると、再選択せずに範囲を拡大または縮小できます (Web 記事、電子ブック、PDF でサポートされています)。
3. デフォルトの `A` ショートカットを押すか、選択アクション ボタンを使用します。
4. 考え、質問、メモを書きます。

ハイライトはパーソナルカラーで表示され、ソーステキストに固定されます。ハイライトの作成、選択範囲のコピー、および同様のアクションをサウンド フィードバックと組み合わせることができます ([設定] > [一般] でサウンドと音量を切り替えます)。

## ディスカッション

すべてのハイライトには独自のディスカッション スレッドがあります。注釈カードからディスカッションを開いて、考えを追加したり、既存のメモに返信したり、`@assistant name` で AI アシスタントに言及したりできます。アシスタントの返信は、記事のコンテキスト、選択した文章、および既存のディスカッションから生成されます。

ディスカッションでは、重要なメモの固定、自分のメモの削除、分割レイアウトと左揃えレイアウトの切り替えがサポートされています。

## 蒸留ノート

ハイライトが、保持する価値のある判断、フレームワーク、質問、またはアクションのリマインダーに成長したら、蒸留ウィンドウを開いて散在するコメントを簡潔なメモに変換し、レビュー アシスタントの構造化されたフィードバックを項目ごとに検証、プレビュー、および適用します。 「【雑記とレビュー](/ja/docs/sedimentation/)」】をご覧ください。

## ショートカット

|ショートカット |アクション |
| -------- | ------------------------------------- |
| `C` |選択したテキストをコピー |
| `A` |選択したテキストからハイライトを作成 |
| `Q` |選択したテキストについて質問する |

これらのショートカットは、[設定] > [ショートカット] でカスタマイズできます。
