リーダーは、本文テキスト、ハイライト表示、ディスカッションスレッド、蒸留ノートを同一の読書空間に統合したワークスペースです。メモからいつでも原文の正確な位置へジャンプバックできるため、文脈から切り離された断片的なメモになる心配がありません。

## リーダー画面と操作ツール

リーダーは紙面に本文を表示し、下線と余白のカードを脚注番号で対応させます。上部のフローティングツールバーから主な操作を行えます。

- **目次ナビゲーション**：章構成ツリーを展開します。現在読んでいる位置が自動的に強調・スクロール表示され、前後の構成を把握しやすくなります。
- **全文検索**：⌘F（Windows は Ctrl+F）またはツールバーのボタンで現在の資料を検索し、該当箇所へジャンプします。
- **ハイライト巡航**：手動でスクロールすることなく、前後のハイライトへワンクリックで移動します。
- **リーダーの質問**：現在開いている資料全体について、いつでも AI アシスタントへ質問や対話を行えます。
- **二言語翻訳**：Web 記事と EPUB の章ごとの段落単位対訳に対応し、原文は変更されません。PDF はページごとに翻訳でき、訳文を段落単位で元のページに重ねて表示します（初版は 1 段組みのテキスト PDF が対象で、テキスト層のないスキャンページは翻訳できません）。翻訳先言語、表示スタイル、および「AI コンテキスト翻訳」は「設定 > 全般」で設定できます。
- **Markdown エクスポート**：現在の資料のハイライト、考え、ディスカッション、公開した蒸留を `.md` ファイルに書き出すか、クリップボードにコピーします。内容は原文のまま出力されます。

### タイポグラフィと表示カスタマイズ

- **Web 記事・電子書籍**：リーダーのツールバーで本文の**フォントサイズ**、**本文幅（行長）**、**紙色**、および既定のハイライト・蒸留の下線色を調整できます。
- **PDF 文書**：**幅に合わせる**、**ページ全体**、**100%** を選べるほか、⌘/Ctrl + / − / 0 で拡大・縮小できます。
- **テーマと読書表示**：サイドバー下部でライト、ダーク、システムに合わせる表示を切り替えます。ダーク時も PDF は既定で元の色を保ち、必要に応じて PDF のツールバーで「ダーク保護フィルター」をオンにできます。

## ハイライトとメモの作成

1. 本文内の任意のテキストを選択します。
2. 選択範囲の両端に調節ハンドルが表示され、ドラッグすることで範囲を微調整できます（Web 記事、電子書籍、PDF すべてで対応）。
3. デフォルトのショートカットキー `A` を押すか、選択ポップアップメニューのボタンをクリックします。
4. その瞬間の考え、疑問、または重要な気づきをメモに記録します。

メモを書かずに印だけ付けたい場合は、ポップアップメニューの「ハイライト」をクリックするとそのまま保存されます。

ハイライトは選択したカラーの手描き風下線で表示され、脚注番号で余白のカードと対応しながら原文の座標に正確に固定されます。注釈カードのメニューまたはディスカッションウィンドウの上部から、ハイライトごとに色を変更できます。ハイライト作成やテキストコピー時には効果音フィードバックを設定することも可能です（「設定 > 全般」で調整可能）。

## ハイライト独立ディスカッション

各ハイライトには個別のディスカッションスレッドが用意されています。カードをクリックしてディスカッション画面へ入ると、左側に考えの一覧、右側に吹き出し形式の対話が表示されます：

- 継続して新しい考察を書き込んだり、過去のメモに返信したりできます。
- 入力欄で `@アシスタント名` を指定して特定の AI コンパニオンを対話に招待できます。アシスタントは前後の文脈、選択段落、ディスカッション履歴を踏まえて回答します。
- 重要なメモのピン留めや削除に対応し、左右分割ビューと左揃えビューを柔軟に切り替えられます。
- 自分で書いた考えと返信は保存後も編集できます。アシスタントの返信とハイライトした原文は変更できません。

ディスカッションウィンドウを最小化すると、リーダー内のしおり型カプセルになります。クリックすると同じウィンドウと未送信の返信が戻ります。カプセルのグループはリーダーの四隅へドラッグでき、フォーカス中は矢印キーでも移動できます。Esc でドラッグを取り消します。

## 思考の蒸留

あるハイライトに対する考察が深まり、まとまった知見、論理フレームワーク、または具体的なアクションプランとしてまとめたい場合は、「蒸留」ウィンドウを開きます。散在していたメモを構造化されたドラフトにまとめ、レビューアシスタントから行単位の修正提案や変更プレビューを受け取ることができます。詳細は「[蒸留とレビュー](/ja/docs/sedimentation/)」をご覧ください。

## ショートカット一覧

| ショートカット             | 操作内容                                  |
| -------------------------- | ----------------------------------------- |
| `C`                        | 選択テキストをコピー                      |
| `A`                        | 選択テキストにハイライト/注釈を作成       |
| `Q`                        | 選択テキストについて AI に質問する        |
| `⌘F` / `Ctrl+F`            | 現在の資料を検索                          |
| `←` / `→`                  | 電子書籍・PDF の前のページ / 次のページ   |
| `⌘/Ctrl` + `+` / `−` / `0` | PDF の拡大、縮小、倍率のリセット          |
| `⌘L` / `Ctrl+L`            | アプリをロック（アプリロック有効時）      |

`C`、`A`、`Q` およびメッセージ送信ショートカットは「設定 > ショートカット」からカスタマイズできます。
