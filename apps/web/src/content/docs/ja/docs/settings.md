設定画面では、UI 言語、外部 AI プロバイダー、テーマと効果音、アプリロック、キーボードショートカット、ローカルデータベースのバックアップ、自動アップデートなど、アプリ全体の動作環境を管理します。

## モデルプロバイダーの設定

Yomitomo は、主要なプリセットプロバイダーおよび任意の OpenAI 互換 API エンドポイントをサポートしています。プロトコルを選択し、接続情報とモデルを指定するだけで簡単に連携できます。

プリセットプロバイダー：

- OpenAI
- Anthropic
- Google Gemini
- DeepSeek
- Alibaba Cloud DashScope
- Moonshot (Kimi)
- Zhipu GLM（智譜）
- Volcengine（火山エンジン / Doubao）
- Xiaomi MiMo

プロバイダーを選択後、任意の表示名、API Base URL、API キーを入力します。「取得」をクリックすると、利用可能なモデル一覧が自動取得されます。ネットワークが制限された環境でも、定番のプリセットモデルをそのまま利用できます。カスタムモデルの追加・編集・削除や、不要なプリセットモデルの非表示にも対応しています。

API キーは OS ネイティブの安全な領域（macOS のキーチェーン、Windows の資格情報マネージャー）で暗号化管理されます。Yomitomo がディスク上に平文で秘密鍵を保存することはありません。

## WeRead（微信読書）連携

WeRead のノート同期には専用の Skill API キーが必要です（詳細は「[WeRead API キーの取得](/ja/docs/weread-api-key/)」を参照）。

設定完了後、以下の同期モードを選択できます：

- **手動同期**：ライブラリで「WeRead を同期」をクリックした時のみ取得します。
- **自動同期**：アプリ起動時に 1 回同期し、その後 30 分ごとにバックグラウンドで静かに同期します。実行中の処理と競合することはありません。

## タスクルーティング

作業の認知的負荷に応じて、最適なモデルを柔軟に割り当てることができます：

| タスク             | 主な役割                                             |
| ------------------ | ---------------------------------------------------- |
| 読書理解アシスタント | ハイライト時の即時考察、`@` 対話の返信、テキスト質疑 |
| 詳細レビュー担当   | 蒸留ドラフトの論拠検証、論理チェック、文章推敲       |
| 二言語対訳翻訳     | Web 記事の段落ごとのストリーミング翻訳と更新         |

「アシスタント実行モード」は全体に適用されます。**高速応答**は低遅延での出力を優先し、**詳細な検証**はアシスタントがツールを用いて多段階の検証を行ってから回答します。

## 多言語と外観設定

- **言語切り替え**：「設定 > 一般」から日本語、英語、簡体字中国語を即座に切り替えられます。UI 文言やアシスタントのキャラクター設定も連動します。
- **テーマとリーダー用紙**：サイドバーからライト、ダーク、ダスクインディゴなどのテーマや質感豊かな用紙カラーを選択できます。ダークモード時でも PDF はオリジナルの白背景を保持し、技術図表や数式のコントラストを維持します。
- **操作効果音**：取り込み完了、削除確認、ハイライト作成、蒸留公開、ロック解除、AI のタイピング音などの音量調整やオン/オフが可能です。

## セキュリティとプライバシー

- **アプリロック（PIN コード）**：有効にすると、一定時間の放置や再起動時に PIN コードの入力が要求されます。PIN 認証情報は OS の保護領域で管理されます。
- **イントラネット遮断保護**：`localhost`、プライベート IP、クラウドのメタデータアドレスへの Web 取り込み要求をデフォルトで遮断し、SSRF のリスクを防ぎます。
- **テレメトリ制御**：バージョンごとの稼働統計のため 1 日最大 1 回の軽量な匿名ハートビート（匿名 UUID、アプリバージョン、OS）を送信します。**読書内容、書名、ハイライト、ファイルパス、AI 対話履歴を収集することは一切ありません。**設定から完全にオフにできます。

## データ管理とバックアップ

データ管理画面から、ローカルの保存フォルダーを開く、動作ログを確認する、SQLite データベースの完全なローカルバックアップ・復元を実行することができます（OS キーチェーン内の API キーや外部電子書籍の元ファイルは除きます）。

## 静かな自動アップデート

Yomitomo は読書を妨げないバックグラウンド更新チェックに対応しています。起動時および 24 時間ごとに更新を確認し、新しいバージョンがある場合は上部バーに控えめなバッジを表示します。ダイアログで読書が中断されることはありません。バッジをクリックしてリリースノートを確認し、バックグラウンドでダウンロードできます。完了後、今すぐ再起動するか次回終了時に適用するかを選択可能です。公開インストーラーはすべて署名・公証されています。
