設定画面では、UI 言語、外部 AI プロバイダー、翻訳設定、効果音、アプリロック、キーボードショートカット、ローカルデータのバックアップ、自動アップデートなど、アプリ全体の動作環境を管理します（ライト・ダーク表示はサイドバー下部で切り替えます）。

## モデルプロバイダーの設定

Yomitomo は、主要なプリセットプロバイダーおよび任意の OpenAI 互換 API エンドポイントをサポートしています。プリセットからプロバイダーを選択し（Ollama や LM Studio、独自エンドポイントを使う場合は `OpenAI compatible` のプリセットを選び、Base URL とカスタムモデル名を編集します）、接続情報とモデルを指定するだけで連携できます。

プリセットプロバイダー：

- OpenAI
- ChatGPT（OAuth による ChatGPT ログイン）
- Anthropic
- Google Gemini
- DeepSeek
- Alibaba Cloud DashScope
- Moonshot (Kimi)
- Zhipu GLM（智譜）
- Volcengine（火山エンジン / Doubao）
- Xiaomi MiMo
- OpenRouter
- Vercel AI Gateway

プロバイダーを選択後、任意の表示名、API Base URL、API キーを入力します。「ChatGPT」を選んだ場合は、ブラウザの OAuth 認証で ChatGPT アカウントにログインし、API キーなしで対象プランのモデルを利用できます（すべての ChatGPT 設定で 1 つのアカウント接続を共有し、設定を複製して別のモデルを割り当てられます）。推論レベルに対応するモデルでは、モデルごとの「思考強度」も選べます。キーの入力またはログイン後に「取得」をクリックすると、利用可能なモデル一覧が自動取得されます。ネットワークが制限された環境でも、定番のプリセットモデルをそのまま利用できます。カスタムモデルの追加・編集・削除や、不要なプリセットモデルの非表示にも対応しています。「設定を複製」で既存の設定のコピーを作成でき、API キーは別のキーチェーン項目にコピーされます。

API キーおよび ChatGPT の OAuth 認証情報は OS ネイティブの安全な領域（macOS のキーチェーン、Windows の資格情報マネージャー）で暗号化管理されます。Yomitomo がディスク上に平文で秘密鍵を保存することはありません。

## WeRead（微信読書）連携

WeRead のノート同期には専用の Skill API キーが必要です（詳細は「[WeRead API キーの取得](/ja/docs/weread-api-key/)」を参照）。

設定完了後、以下の同期モードを選択できます：

- **手動同期**：ライブラリで「WeRead を同期」をクリックした時のみ取得します。
- **自動同期**：アプリ起動時に 1 回同期し、その後 30 分ごとにバックグラウンドで静かに同期します。実行中の処理と競合することはありません。

### Yomitomo 内で微信読書を開く

「設定 > データソース > WeRead」で、既定の開き方を「Yomitomo でウェブ版を開く」に変更します。本やハイライトを開くと、小窓で原文を確認し、ページや章を移動できます。拡大して読書することもできます。小窓での操作はアカウントの読書位置を更新しません。拡大した状態では、ウェブ版が現在位置と読書時間を微信読書へ記録します。

ログイン状態は独立したローカルセッションだけに保存され、完全バックアップには含まれません。WeRead の設定からログイン状態を削除できます。アプリをロックすると内蔵リーダーは閉じます。

## タスクルーティング

まず、読書理解・詳細レビュー・二言語翻訳で共通の既定モデルを選びます。別のモデルが必要な場合はタスク別設定を開きます。個別に設定していないタスクには「既定のモデルを継承」と表示され、既定モデルを変更すると追従します。

| タスク               | 主な役割                                                           |
| -------------------- | ------------------------------------------------------------------ |
| 読書理解アシスタント | ハイライトのアシスタント考察、`@` 対話の返信、リーダーの質問       |
| 詳細レビュー担当     | 蒸留ドラフトの論拠検証、論理チェック、文章推敲                     |
| 二言語対訳翻訳       | Web 記事・EPUB の章・単段テキスト PDF の段落ごとの翻訳と更新       |

## 多言語・翻訳・外観設定

- **言語切り替え**：「設定 > 全般」から日本語、英語、簡体字中国語を即座に切り替えられます。UI 文言やアシスタントのキャラクター設定も連動します。
- **翻訳設定**：「設定 > 全般」で翻訳先言語と 5 種類の表示スタイルを選べるほか、「AI コンテキスト翻訳」を有効にすると、翻訳対象段落に加えて資料タイトル・要約および前後最大 2 段落の原文を送信して文脈精度を高められます。
- **テーマと読書表示**：サイドバー下部でライト、ダーク、システムに合わせる表示を選べます。リーダーのツールバーで文字サイズ、本文幅、紙色、既定の下線色を調整でき、ダーク時も PDF は既定で元の色を保ちます（必要に応じて PDF ツールバーでダーク保護フィルターを切り替えられます）。
- **操作効果音**：取り込み完了、削除確認、ハイライト作成、蒸留公開、ロック解除、AI のタイピング音などの音量調整やオン/オフが可能です。

## セキュリティとプライバシー

- **モデルおよび翻訳リクエスト**：リモート AI 機能では、タスクに必要な原文、注釈、対話が設定したモデルの接続先へ送信されます。翻訳または段落の再試行を実行すると、対象段落のテキスト、書名、翻訳先言語、既存の要約が送信されます（「AI コンテキスト翻訳」がオンの場合は前後最大 2 段落の原文も付与されます）。ChatGPT ログイン、トークン自動更新、接続解除の際は、`auth.openai.com` へ OAuth/OIDC リクエストが送信されます（読書内容は含みません）。自分の端末で動くモデルに接続する場合、推論は端末内で行われます。
- **アプリロック（PIN コード）**：有効にすると、サイドバーのロックボタンまたは ⌘+L（Windows は Ctrl+L）でいつでもロックできます。「起動時のロック」をオンにすると、起動やアップデート後の再起動のたびにロックされた状態で始まります。一定時間操作がなくても自動ではロックされません。解除には PIN コードの入力が必要で、PIN 認証情報は OS の保護領域で管理されます。
- **テレメトリ制御**：既定でオンです。`telemetry.yomitomo.app` へ 2 種類のデータを送信します。1 日最大 1 回の匿名ハートビート（匿名インストール ID、アプリバージョン、OS の種類とバージョン、アーキテクチャ、ローカルの日付、タイムゾーン）と、読書メモリーを開いた回数・検索完了・出典への移動・再検討の判断・縮退の回数です。後者にはインストール ID を含みません。**どちらにも読書内容、書名、ハイライト、ファイルパス、AI 対話履歴は含まれません。**「設定 > 全般 > プライバシー」からオフにでき、オフにすると未送信の読書メモリーの集計を消去します。
- **モデル価格カタログ**：起動の約 5 秒後と、その後 24 時間ごとに、ローカルの価格キャッシュが 24 時間以上経過していれば `https://models.dev/api.json` から公開のモデル価格カタログを取得し、アシスタント利用料金の見積もりに使います。通常の GET リクエストで、読書内容、API キー、インストール ID は含みません。ほかの通信と同様に、IP アドレスとリクエスト時刻は models.dev に伝わります。このリクエストはテレメトリ設定の対象外で、モデルプロバイダーを設定していない場合も行われます。

## データ管理とバックアップ

更新前にデータをバックアップしてください。v0.16.3 はデータベースを reader level 4 に移行するため、更新後は v0.16.2 以前では開けません。旧版に戻すには、更新前の互換性のあるバックアップを復元してください。

データ管理画面から保存フォルダーやログを確認し、完全バックアップまたはデータベースのみのバックアップを選べます。

- **完全バックアップ**：データベース、元の電子書籍・PDF、PDF サムネイル、ファイルのチェックサム一覧を含むフォルダーを作成します。移行時はフォルダー全体を保管してください。復元前にファイルとデータベースを検証し、現在のデータを安全用にバックアップします。復元内容の適用に失敗した場合は元に戻します。
- **データベースのみ**：注釈・対話・蒸留・設定を含む SQLite ファイルを保存します。元の電子書籍・PDF・サムネイルは含まれないため、元ファイルを別途保管してください。

完全バックアップには API キーおよび ChatGPT の OAuth 認証情報を含まず、アプリロックも移行しません。復元後にモデルと WeRead のキーの再設定や ChatGPT の再ログインを行い、必要に応じてアプリロックを有効にしてください。新しい端末では読書メモリーのローカルモデルも再ダウンロードしてください。アシスタントの会話の記憶はバックアップに含まれず、データベースを復元すると消去されます。バックアップ内の注釈、ディスカッション、リーダーの質問は通常どおり復元されます。

## 読書メモリーの対象範囲とローカルモデル

読書メモリーは「まとめ」「ライブラリに質問」「読み直す」およびリーダー内の「関連を探す」で構成され、ローカル資料に保存されたハイライトや考え、自分が参加したディスカッション、公開済みのまとめを検索します。資料全文、未公開の下書き、WeRead 同期書籍は対象外です。「ライブラリに質問」では全ローカル資料・コレクション・手動で選んだ資料を対象にできます。「読み直す」では、過去の考えを表示する前に今の判断を書き、必要に応じて新しい根拠と比較できます（元の記録は上書きされません）。

意味索引の作成と検索はローカルで実行されます。「設定 > モデルとルーティング」のローカル読書メモリー欄から固定バージョンのローカル埋め込みモデルを明示的にダウンロードでき（既定は ModelScope、Hugging Face へ切り替え可。モデルファイルのみを取得し、読書内容は送信しません）、一時停止・再開・再構築・削除も行えます。ローカルモデルが未準備の間はキーワード検索にフォールバックします。AI に関係判断や回答を依頼する場合は、入力上限内の候補根拠と質問のみを設定したモデルの接続先へ送信します。

ローカルモデルやモデルサービスの準備ができていない場合、読書メモリーのパネルから「ローカルモデルをダウンロード」やプロバイダー設定に移動でき、モデルのダウンロードと索引作成の進捗を表示します。ライブラリへの質問はこのセッションの履歴を最大 20 件保持し、回答を引用付きの Markdown としてコピーできます。

## 静かな自動アップデート

Yomitomo は起動時および 24 時間ごとにバックグラウンドで更新を確認します。新しいバージョンがある場合はサイドバーに更新カードが表示され、リリースノートの確認とダウンロードを開始できます。ダウンロード後、再起動してインストールできます。

0.16.0 から macOS の更新に Sparkle を使用します。旧バージョンからの初回更新は完全な ZIP をダウンロードします。インストールして再起動した後は、次回以降のリリースで差分更新を利用できます。適切な差分がない場合や検証に失敗した場合は完全パッケージに切り替わります。macOS パッケージは引き続き Developer ID 署名と公証を使用し、Windows は従来の更新方式を使用します。
