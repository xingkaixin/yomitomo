統計ページは、資料のリストを表示するだけでなく、読書活動を確認するのに役立ちます。これには、Local Reading および WeRead のソースが含まれます。

## 指標

統計情報:

- 今日のアクティビティ
- 記録された日数
- 週間のアクティブ日数
- アクティビティのピーク時
- 輸入記事
- 注釈数
- 蒸留音数
- ディスカッション数
- アシスタントの参加数（概要指標におけるアシスタントの貢献を含む）

チャートは、記事のインポート、ハイライト、抽出されたメモ、ディスカッションのコメントの傾向を示します。設定 IA の更新後は、統計関連のビューからアシスタントの使用状況を簡単に確認できるようになります。アクティビティ カレンダーには、過去 70 日間の読書アクティビティが表示されます。

## WeRead統計

WeRead API キーを設定した後、統計ページを WeRead に切り替えます。 WeRead 統計は、週、月、年、または常時でクエリできます。期間を切り替えると保存データのみが読み込まれます。期間を更新する必要がある場合は、「クエリ」または「再クエリ」をクリックします。

WeRead クエリ結果はキャッシュされるため、以前に取得した期間は、別の API リクエストを行わなくても利用可能なままになります。

## AI機能が反応しない

チェックしてください:

1. 少なくとも 1 つのモデル プロバイダーが追加されているかどうか。
2. API キーが正しいかどうか。
3. 「接続テスト」が成功したかどうか。
4. 該当タスクに対してタスクルーティングが設定されているかどうか。

## ウェブ記事のインポートに失敗する

一般的な原因は次のとおりです。

- URL は有効な `http://` または `https://` アドレスではありません。
- URL はローカルホスト、プライベート ネットワーク、またはクラウド メタデータ アドレスを指していますが、これらはデフォルトでブロックされています。
- HTML レスポンスが 5 MB を超えています。
- ソース サイトにはスクレイピング防止保護が施されています。
- ネットワーク接続がタイムアウトしました。

Yomitomoは内蔵ブラウザでページをレンダリングしようとしますが、一部のサイトでは依然として解析に失敗する可能性があります。

## 電子書籍のインポートに失敗する

ファイルが `.epub`、`.azw3`、または `.mobi` ファイルであり、80 MB 以下であることを確認してください。 DRM で保護されたファイルや、解凍されたサイズが大きすぎるファイルはインポートできません。

## PDF のインポートに失敗する

ファイルが標準の `.pdf` ファイルであり、120 MB 以下であることを確認してください。

## データはどこに保存されますか?

すべてのデータはローカル アプリ データ ディレクトリに保存され、YomiTOMO サーバーにはアップロードされません。 API キーはシステム キーリングに保存されます。

## Yomitomoは匿名データを送信しますか?

デフォルトでは、Yomitomo は、匿名のインストール ID、アプリのバージョン、プラットフォーム、OS バージョン、アーキテクチャ、現地の日、およびオプションのタイムゾーンを含む匿名ハートビートを 1 日に最大 1 回送信します。これは、アクティブなバージョンとシステムの分布を理解するために使用されます。読書内容、本のタイトル、注釈、ファイル パス、AI の会話は収集されません。 [設定] > [一般] の [プライバシー] グループにある [匿名のバージョンとシステム メトリクスを送信する] 切り替えを使用してオフにできます。

## サポートされているシステム

Yomitomoは現在、macOS と Windows をサポートしています。
