統計ダッシュボードは、単なるファイルの羅列ではなく、長期的な読書習慣と思考の軌跡を可視化する画面です。「ローカル読書」と「WeRead（微信読書）」の 2 つの視点からデータを集計します。

## 主要な指標

統計画面では、以下のディメンションをグラフと数値で確認できます：

- **本日のアクティビティ**：本日の読書時間と操作回数
- **継続性と記録**：記録日数、週あたりのアクティブ日数、最高連続記録
- **思考の産出量**：取り込み記事数、ハイライト・注釈数、蒸留ノート数
- **対話と考察**：ディスカッション発言数、AI アシスタントの参加回数

アクティビティ推移グラフでは、記事の取り込み、ハイライト、蒸留、ディスカッションの推移を確認でき、70 日間の読書ヒートマップが日々の読書リズムを鮮明に映し出します。

## WeRead 読書統計の同期

設定で WeRead API キーを登録すると、統計画面で「WeRead」タブに切り替えることができます。「週間」「月間」「年間」「全期間」ごとに読書時間や書籍一覧を照会可能です。照会結果はローカルにキャッシュされるため、再読み込みなしで過去の期間を瞬時に振り返ることができます。

## よくある質問とトラブルシューティング

### AI アシスタントが応答しない・エラーになる

以下の項目を順番に確認してください：

1. **プロバイダーの登録**：「設定 > モデルとルーティング」で少なくとも 1 つの AI プロバイダーが追加されているか確認します。
2. **API キーの確認**：前後に不要なスペースが含まれずに正しく貼り付けられているか確認します。
3. **接続テスト**：プロバイダーカードの「接続テスト」をクリックし、正常に通信できるか確認します。
4. **タスクルーティングの割り当て**：「タスクルーティング」で「読書理解アシスタント」や「詳細レビューアシスタント」にモデルが割り当てられているか確認します。

### Web 記事のインポートに失敗する

主な原因として以下が考えられます：

- URL が `http://` または `https://` で始まっていない。
- ローカルホスト（`localhost`）、プライベート IP、クラウドのメタデータアドレスを指している（安全のため自動遮断されます）。
- HTML レスポンスが 5MB を超えている。
- 接続先サイトで厳格なスクレイピング防止機構やログインウォールが設定されている。
- ネットワーク接続がタイムアウトした。

Yomitomo は SPA などの動的ページも内蔵環境で描画して抽出を試みますが、一部の特殊なサイトではテキストを抽出できない場合があります。

### 電子書籍のインポートに失敗する

- ファイル拡張子が標準の `.epub`、`.azw3`、または `.mobi` であり、1 冊あたり 80MB 以下であることを確認してください。
- DRM（デジタル著作権管理）で保護された電子書籍や、展開後の内部構造が極端に巨大なファイルは取り込めません。

### PDF のインポートに失敗する

- 標準の `.pdf` 形式であり、1 ファイルあたり 120MB 以下であることを確認してください。
- パスワード保護された PDF や破損した PDF は、事前に解除・修復してからインポートしてください。

### 読書データはどこに保存されますか？

すべての資料、ハイライト、ディスカッション履歴、蒸留ノートは**完全にローカルのアプリケーションディレクトリ**に保存されます。Yomitomo のサーバーに送信されることは一切ありません。API キーは OS の安全な資格情報ストア（macOS Keychain / Windows Credential Manager）で暗号化保管されます。

### プライバシーや個人情報は収集されますか？

Yomitomo は、バージョンごとの稼働状況と OS 分布を把握するため、1 日最大 1 回の軽量な匿名ハートビート（匿名 ID、アプリバージョン、OS、アーキテクチャ、タイムゾーン）を送信します。**読書内容、書名、ハイライト、ファイルパス、AI 対話内容などは一切収集されません。**「設定 > 一般 > プライバシー」からいつでもオフにできます。

### 対応しているオペレーティングシステムは？

現在 **macOS（Apple Silicon & Intel）** および **Windows（x64 & ARM64）** をサポートしています。
