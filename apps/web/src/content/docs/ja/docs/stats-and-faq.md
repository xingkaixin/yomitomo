統計ダッシュボードは、長期的な読書活動、注釈のリズム、アシスタントの利用状況を可視化する画面です。「ローカル読書」「アシスタント使用量」「WeRead」のビューを切り替えられます。

## 主要な指標

ローカル読書統計では、以下の内容を確認できます：

- **本日と累計のアクティビティ**：まとめ、考え、ハイライト、アシスタント投稿の件数（ローカル統計では読書時間は計測しません）
- **継続性と記録**：記録日数、週あたりのアクティブ日数、7 日連続バッジ、最高連続記録
- **21 日間の活動推移**：まとめ、考え、ハイライトの日ごとの推移グラフ
- **70 日間の読書マップ**：日々の読書リズムを映すアクティビティヒートマップ

「アシスタント使用量」ビューに切り替えると、呼び出し回数、総トークン数、`models.dev` の公開価格表に基づく推定コスト、およびアシスタント別の内訳を確認できます。

## WeRead 読書統計の同期

設定で WeRead API キーを登録すると、統計画面で「WeRead」タブに切り替えることができます。「週間」「月間」「年間」「全期間」ごとに読書時間や書籍一覧を照会可能です。照会結果はローカルにキャッシュされるため、再読み込みなしで過去の期間を瞬時に振り返ることができます。

## よくある質問とトラブルシューティング

### AI アシスタントが応答しない・エラーになる

以下の項目を順番に確認してください：

1. **プロバイダーの登録**：「設定 > モデルとルーティング」で少なくとも 1 つの AI プロバイダーが追加されているか確認します。
2. **API キーの確認**：前後に不要なスペースが含まれずに正しく貼り付けられているか確認します。
3. **接続テスト**：プロバイダー設定を開き、ダイアログ下部の「テスト」をクリックして正常に通信・認証できるか確認します。
4. **既定モデルとルーティング**：「設定 > モデルとルーティング」で既定モデルが選択されているか確認します（タスク別の個別設定を開いている場合は、該当タスクに有効なモデルが割り当てられているか確認します）。

### Web 記事のインポートに失敗する

主な原因として以下が考えられます：

- URL が `http://` または `https://` で始まっていない。
- HTML レスポンスが 5MB を超えている。
- 接続先サイトで厳格なスクレイピング防止機構やログインウォールが設定されている。
- ネットワーク接続がタイムアウトした。

Yomitomo は SPA などの動的ページも内蔵環境で描画して抽出を試みますが、一部の特殊なサイトではテキストを抽出できない場合があります。

### 電子書籍のインポートに失敗する

- ファイル拡張子が標準の `.epub`、`.azw3`、または `.mobi` であり、1 冊あたり 80MB 以下であることを確認してください。
- DRM（デジタル著作権管理）で保護された電子書籍や、展開後の内部構造が極端に巨大なファイルは取り込めません。

### PDF のインポートに失敗する

- 標準の `.pdf` 形式であり、1 ファイルあたり 120MB 以下であることを確認してください。
- パスワード保護された PDF や破損した PDF は、事前に解除・修復してからインポートしてください。

### 読書データはどこに保存されますか？

すべての資料、ハイライト、ディスカッション履歴、蒸留ノートは**完全にローカルのアプリケーションディレクトリ**に保存されます。Yomitomo のサーバーに送信されることは一切ありません。API キーは OS の安全な資格情報ストア（macOS Keychain / Windows Credential Manager）で暗号化保管されます。リモート AI 機能では、タスクに必要な読書内容と対話が設定したモデルの接続先へ送信されます。自分の端末で動くモデルに接続する場合、推論は端末内で行われます。

### プライバシーや個人情報は収集されますか？

Yomitomo は、バージョンごとの稼働状況と OS 分布を把握するため、1 日最大 1 回の軽量な匿名ハートビート（匿名インストール ID、アプリバージョン、OS の種類とバージョン、アーキテクチャ、ローカルの日付、タイムゾーン）を送信します。読書メモリーについては、開いた回数・検索完了・出典への移動・再検討の判断・縮退の回数を、インストール ID を含めずに別途送信します。**読書内容、書名、ハイライト、ファイルパス、AI 対話内容などは一切収集されません。**「設定 > 全般 > プライバシー」からいつでもオフにでき、オフにすると未送信の読書メモリーの集計を消去します。

### 対応しているオペレーティングシステムは？

現在 **macOS（Apple Silicon）** および **Windows（x64）** をサポートしています。
