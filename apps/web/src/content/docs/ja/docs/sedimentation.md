title: 蒸留とレビュー
description: ハイライトでの対話を構造化された蒸留ノートへ昇華させ、レビューアシスタントの客観的なフィードバックを検証・プレビュー・適用します。
---

知識の蒸留（Distillation）とは、ハイライトを起点に生まれた断片的なメモや対話を、長期的に価値のある論理的な判断、分析フレームワーク、本質的な問い、または具体的なアクションプランとしてまとめ上げるプロセスです。蒸留ノートは常に原文の位置に固定されているため、文脈を失うことなくいつでも思考の原点へ立ち戻ることができます。

## 蒸留ウィンドウを開く

注釈カードからディスカッションに入り、「蒸留」ボタンをクリックすると専用ウィンドウが開きます。画面左側が蒸留ドラフトの編集エリア、右側がレビューアシスタントとの対話エリアです。

ドラフトは手動で自由に執筆できるほか、レビューアシスタントに依頼して対話内容を整理し、修正提案を生成させることも可能です。ドラフトには 2 つの状態があります：

- **下書き（Draft）**：推敲やレビューを重ねながらブラッシュアップする作業中の状態。
- **公開（Published）**：公開すると、サイドバー上の元のハイライトが蒸留ノートに置き換わります。非公開に戻しても下書きやレビュー履歴はすべて保持されます。

## 構造化レビューの流れ

右側のレビューパネルでレビュー担当アシスタントを選択し、ドラフトに対するレビューをリクエストします。アシスタントは一般的な文章ではなく、明確に構造化されたフィードバックを返します：

- **総合評価**：ドラフトの論理性や説得力に対する総合的な判定（「論拠が強固」「論理の飛躍あり」「補強が必要」など）。
- **カテゴリ別指摘事項**：**証拠の妥当性**、**論理展開**、**網羅性**、**文章の明快さ**、**実行可能性**の観点から問題点を整理し、重要度とともにドラフト内の該当箇所を引用します。
- **具体的な修正提案**：ドラフトへ直接反映可能な修正指示（挿入、置換、削除）。

レビュー結果はリアルタイムでストリーミング表示されるため、生成完了を待たずに確認を始められます。

## 提案の検証と安全性

すべての修正提案は、適用前に現在のドラフトテキストと厳密に照合され、誤った箇所の書き換えや位置ずれを防止します：

- 変更対象のテキストが見つからない場合や、複数箇所に一致する場合は手動確認を促します。
- 提案された追記内容がすでに存在している場合は重複を検出します。
- ドラフトが大幅に書き換えられ、アンカー位置がずれている場合は警告を表示します。

提案が安全に適用できるか、手動での調整が必要かを事前に確認できます。

## 差分のインラインプレビュー

提案を採用する前に「変更をプレビュー」をクリックすると、ドラフト上で Diff 表示を確認できます。追加箇所は緑色、削除箇所は赤色の取り消し線でハイライトされ、編集画面は一時的に読み取り専用になります。

プレビューは**項目ごとに個別判定**が可能です。それぞれの変更について「採用」または「破棄」を選択できます。複数の提案に競合がある場合は、手動での編集を案内します。

## ディスカッションの整理・抽出

「ディスカッションを整理」を実行すると、レビューアシスタントがハイライト原文、あなたの思考メモ、すべての対話履歴を読み込み、ドラフトに追加すべき新たな洞察を自動抽出します。既存の文章を勝手に上書き・削除することはなく、純粋な追記提案として生成されます。

抽出された各項目は個別にプレビューし、納得した上でドラフトへ安全に取り込めます。

## スマートアンカーハイライト

指摘事項や修正提案の上にマウスを置くかフォーカスすると、ドラフト内の該当箇所が連動してハイライトされます。提案生成後に本文が編集されていた場合、アンカー位置のずれを警告色で知らせます。
