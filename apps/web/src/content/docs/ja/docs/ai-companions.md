## 読書フローでアシスタントを活用する

読書中は以下の 3 つの方法でアシスタントを呼び出せます：

1. **ハイライト作成時の思考支援**：本文を選択してハイライトを作成すると、アシスタントが該当箇所の考察を補助します。
2. **ディスカッションでの `@` メンション**：ハイライトごとの対話スレッドで `@アシスタント名` と入力し、特定の専門ペルソナを持つアシスタントを対話に招待します。
3. **蒸留ウィンドウでのレビュー**：蒸留作成画面でレビュー担当者を選択し、下書きに対する構造化されたフィードバックと修正提案を受け取ります。

アシスタントの出力は常に前後の文脈やユーザーのメモに根ざしており、文脈から浮いた一般的な要約を出力することはありません。

## コンテキスト参照範囲

アシスタントが考察や返信、レビューを生成する際、以下の情報を参照します：

- 対象段落および前後の完全なテキスト
- あなたがこれまでに残した注釈やディスカッション履歴
- 以前の読書セッションで蓄積された読書記憶
- 資料全体の目次構成と論理構造

EPUB 電子書籍では、ネタバレ防止スコープ（選択範囲のみ、現在の章、既読範囲、書籍全体）を柔軟に設定できます。

## 読書伴読アシスタント

読書伴読アシスタントは、共読、概念の整理、問いの深掘り、文章構造の把握に優れています：

| アシスタント | ペルソナ           | 得意分野                               |
| ------------ | ------------------ | -------------------------------------- |
| 高橋 葵      | 読書パートナー     | 概念の整理と時代背景・前提知識の補足   |
| 黒沢 蓮      | 根本原因レビュアー | 暗黙の前提の検証と因果関係の追跡       |
| 水野 花      | 問いのメンター     | 漠然とした疑問を具体的で鋭い問いへ変換 |
| 橘 駿        | 洞察エディター     | 汎用的に応用可能なメンタルモデルの抽出 |
| 白川 澪      | 概念ナビゲーター   | 専門用語の系譜と文脈の平易な解説       |
| 森 海斗      | 構成ガイド         | 全体構成における各段落の論証機能の解明 |

## レビュー担当アシスタント

レビュー担当アシスタントは、証拠の妥当性、論理的一貫性、文章の推敲、実行可能性の検証に特化しています：

| アシスタント | ペルソナ           | 得意分野                                   |
| ------------ | ------------------ | ------------------------------------------ |
| 佐伯 証      | 証拠アーキビスト   | 事実関係と証拠チェーンの厳格な検証         |
| 小野寺 凛    | 読者の代弁者       | 読者目線に立ち、わかりにくい箇所の疑問提起 |
| 伊藤 直人    | 最終エディター     | 冗長な表現の削減と文章の明快化             |
| 藤堂 玲奈    | 論理レビュアー     | 論理の飛躍や矛盾、前提の欠落の検出         |
| 安西 誠      | リスクレビュアー   | 過度な一般化や潜在的なバイアスの指摘       |
| 宮本 結衣    | 行動設計レビュアー | 抽出されたアクションの実行可能性の検証     |

「アシスタント」画面で、各アシスタントの有効化/無効化やプロンプト設定をいつでも確認・変更できます。
