---
title: "WeRead API キーを取得する"
description: "Web アプリまたはモバイル アプリから WeRead API キーを取得し、Yomitomo の WeRead 設定に保存します。"
---

WeRead 同期には WeRead API キーが必要です。作成したら、[設定] > [データ ソース] > [WeRead] の下にあるYomitomoに貼り付けて保存します。

## ウェブでキーを入手

1. <a href="https://weread.qq.com/r/weread-skills" target="_blank" rel="noopener noreferrer">WeRead スキル ページ</a>を開きます。
2. 「クイック設定」をクリックします。
3. WeRead にサインインします。
4. API キーセクションで API キーを作成します。すでにキーを作成している場合は、既存のキーをコピーします。
5. Yomitomoに戻り、設定 > データ ソース > WeRead にキーを貼り付けて保存します。

## モバイル アプリでキーを取得する

1. WeRead アプリを開いてサインインします。
2. 「自分」タブをタップします。
3. 右上隅のメニューをタップします。
4. 設定をスクロールして、WeRead スキルを開きます。
5. 「API キー」セクションまでスクロールします。
6. API キーを作成します。すでにキーを作成している場合は、既存のキーをコピーします。
7. Yomitomoに戻り、設定 > データ ソース > WeRead にキーを貼り付けて保存します。

## Yomitomo に保存

Yomitomoで、[設定] > [データ ソース] > [WeRead] を開き、API キーを [API キー] フィールドに貼り付けて、[保存] をクリックします。その後、接続をテストしてキーが機能することを確認できます。
