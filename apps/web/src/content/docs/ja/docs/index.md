Yomitomo は、デスクトップ向けのローカルファースト AI 読書コンパニオンです。あなたの代わりに読んでくれるわけではありません。読書中にハイライトを付けたり、注釈を付けたり、質問したり、議論したりするのに役立ちます。記事、注釈、ディスカッション、プロバイダー設定、API キーはコンピューター上に残ります。

## 最初の実行

1. Yomitomo を開き、オンボーディングの案内を確認します。
2. [設定]、[モデルとルーティング] の順に移動します。
3. モデルプロバイダーを追加し、その API キーを入力して、接続をテストします。
4. 読書アシスタントとレビューアシスタントにタスクルートを割り当てます。
5. ライブラリに戻って、Web 記事、EPUB/AZW3/MOBI 電子ブック、または PDF ドキュメントをインポートします。

アプリの表示言語は設定から切り替えられます。ヘルプは [中国語](/docs/)、[英語](/en/docs/)、日本語で利用できます。WeRead からハイライト、感想、読書の進捗を同期する場合は、先に「[WeRead API キーを取得する](/ja/docs/weread-api-key/)」を確認してください。

## 製品分野

Yomitomo は、次の主要な領域で構成されています。

- ライブラリは、Web 記事、EPUB/AZW3/MOBI 電子ブック、PDF ドキュメント、WeRead ノート、およびコレクションを管理します。
- リーダーでは、読書、ハイライト、注釈、ディスカッション、まとめノートを扱います。
- アシスタントでは、AI 読書アシスタントとレビューアシスタントを管理します。
- 統計では、ローカルの読書活動と WeRead の統計を確認します。
- 設定では、言語、モデル、テーマ、効果音、アプリロック、ショートカット、データ管理、アップデート、プライバシーを構成します。
- WeRead は、API キーを通じてハイライト、感想、読書の進捗状況を同期します。

## 読書モデル

Yomitomo は要約を作るためだけのアプリではありません。読書中に生まれた判断の流れを残すことを重視しています。

- ハイライトはソーステキスト内の証拠アンカーです。
- メモは、読書の最小の耐久性のある出力です。
- コメントにより、質問や修正が可能なメモが残されます。
- AI アシスタントは、ディスカッションや共同読書の流れで必要な場合にのみ参加します。

「ライブラリとインポート」に進み、最初の読書アイテムを取り込みます。
