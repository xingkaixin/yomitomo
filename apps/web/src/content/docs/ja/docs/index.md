Yomitomo は、デスクトップ向けのローカルファースト AI 読書コンパニオンです。あなたに代わって本を読むのではなく、読書中にハイライトを引き、疑問を投げかけ、メモを深め、AI と対話するための環境を提供します。記事、注釈、ディスカッション履歴、モデル設定、API キーはすべてローカル端末内に安全に保存されます。

## はじめの使い方

1. Yomitomo を起動し、初回ガイドを確認してアプリに入ります。
2. 「設定 > モデルとルーティング」を開きます。
3. 利用したい AI プロバイダーを追加し、API キーを入力して「接続テスト」を実行します。
4. 読書理解アシスタント、詳細レビューアシスタント、二言語翻訳のタスクルートを設定します。
5. 「ライブラリ」に戻り、Web 記事、電子書籍（EPUB/AZW3/MOBI）、PDF 文書、または Markdown テキストを取り込みます。

アプリの表示言語は「設定 > 一般」からいつでも切り替えられます。ヘルプドキュメントは[中国語](/docs/)、[英語](/en/docs/)、[日本語](/ja/docs/)に対応しています。WeRead（微信読書）のハイライトや読書記録を同期したい場合は、先に「[WeRead API キーの取得](/ja/docs/weread-api-key/)」をご覧ください。

## 主な機能と画面構成

Yomitomo は主に以下のモジュールで構成されています。

- **ライブラリ**：Web 記事、電子書籍（EPUB/AZW3/MOBI）、PDF、テキスト/Markdown、WeRead ノート、カスタムコレクションを一元管理します。
- **リーダー**：没入感のある本文読書、正確なテキストアンカー、ハイライトごとのディスカッション、二言語翻訳、思考の蒸留（詳細は「[蒸留とレビュー](/ja/docs/sedimentation/)」を参照）を行います。
- **アシスタント**：独自のペルソナを持つ読書コンパニオンや多角的なレビューアシスタントを管理します。
- **統計**：ローカルの読書活動、注釈トレンド、アクティビティヒートマップを確認し、WeRead の読書データも照会できます。
- **設定**：言語、モデルプロバイダー、テーマ、効果音、アプリロック、ショートカット、データバックアップ、プライバシーをカスタマイズします。
- **WeRead**：公式 Skill 認証を通じて、書籍、ハイライト、メモ、進捗を安全に同期します。

## 読書の思想

Yomitomo の目的は、AI に安易な要約を作らせることではありません。読書によって生まれるあなた自身の思考プロセスをそのまま残すことです。

- **ハイライト**は、原文内の確かな証拠アンカーです。
- **メモ**は、読書中にひらめいた貴重な第一印象や洞察です。
- **ディスカッション**は、メモに対する追究や修正を重ねる対話の場です。
- **AI アシスタント**は、必要なときにだけディスカッションに参加し、思考を広げる手助けをします。
