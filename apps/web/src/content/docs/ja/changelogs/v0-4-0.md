title: "0.4.0"
description: "Yomitomo 0.4.0 リリースノート。"
---

公開日: 2026-05-21

## 新規

- デスクトップ アプリの更新フローを追加し、概要、オンボーディング、Web サイトのダウンロード エントリを GitHub リリース アセットに接続しました。
- Yomitomoランディング ページ、macOS / Windows ダウンロード、SEO メタデータ、サイトマップ、ロボット、ソーシャル プレビュー画像を含む製品 Web サイトを追加しました。
- データ ディレクトリ、ログ、データベース ファイル、SQLite バックアップ/復元、およびデータベース非互換性メッセージのクリアの設定にデータ管理を追加しました。
- プロバイダー設定では、API キーを安全に保存し、保存されたキーの公開をサポートし、モデル リストを取得し、タスク ルーティングを構成し、モデル フォームを簡素化するようになりました。
- 選択 `@assistant` ルーティング、レビュー アシスタント コメント、注釈ディスカッション カード、フローティング目次、両面メモ、保留中のアシスタント状態を備えた読者の意見とディスカッションがアップグレードされました。

## 変更点

- 読書後の出力フローを削除し、ソースアンカー、思考スレッド、コメントディスカッション、およびアシスタントの共読に重点を置いた製品になりました。
- Web 記事と EPUB 書籍のライブラリ エントリを分割し、ホーム レイアウト、リターン ソース、マテリアル カード、および EPUB インポート レコード サイズを改善しました。
- ソース リーダーのレイアウト、注釈の接続、思考カウント、共読コントロール、アバターのホバー、思考入力のインタラクションなど、リーダーのレイアウトとインタラクションを継続的に磨き続けています。

## パフォーマンス

- EPUB 読み取り用の DOM テキスト インデックスを再利用して、ページネーション、ページ更新、注釈のレンダリング中の繰り返し作業を削減しました。
- 大きな書籍や大きなライブラリ向けに、注釈ホット パス、ランタイム インポート ホットスポット、ライブラリ記事ペイロードの読み込みを最適化しました。

## 修正

- EPUB アノテーションのレンダリング、ページネーションの速度、位置情報の復元、ページの更新、スタックされたアノテーションの接続の安定性を修正しました。
- API キー削除後のプロバイダー名の保持、開発データベースの移行履歴の保持、データベース互換性エラーの表示、およびターゲット アノテーションの所有権を修正しました。
- 失われたライブラリのリターンソース、非表示の保留中のアシスタント状態、思考入力の詳細、および共読制御状態を修正しました。

## エンジニアリング

- メイン アプリの状態、ソース 本棚、設定パネル、リーダー コンポーネント、注釈コメント入力、アシスタント注釈キュー、エージェント ランタイム、プロバイダー設定、EPUB ランタイム境界を分割します。
- 読み取りカードのワークフロー状態、ソース エージェントのリクエスト パイプライン、コード健全性のホット境界とランタイム パフォーマンス ホットスポット監査ドキュメントを抽出しました。
