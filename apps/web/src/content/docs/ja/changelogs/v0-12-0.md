公開日: 2026-07-14

## 特徴

- モデル ルーティングにアシスタント実行モード スライダーを追加しました。これにより、読者の注釈、フォローアップの質問、および共読タスクについて、迅速な応答とツールによる詳細な検証のどちらかを選択できるようになりました。 (#618)
- キーボード ハンドル、ローカライズされたアナウンス、ボタン フォールバックを備えたコレクション ピッカーのドラッグ アンド ドロップを再構築し、入力メソッド間でコレクションの編成動作の一貫性を維持しました。 (#616)
- ライブラリ グリッドが利用可能なコンテンツの幅に対応するようにしたため、カードと読み込みスケルトンはコンパクト ウィンドウからワイド ウィンドウまで同じレイアウトを使用します。 (#634)
- スクロールによる表示、ローカライズされたモバイル製品プレビュー、より明確な証拠チェーンのレイアウト、製品とシナリオのページのより豊富な構造化データを備えた Web サイトを更新しました。 (#619、#632、#637、#638)

## パフォーマンス

- 簡略化された Web サイトではアニメーションが表示され、プログレッシブ エンハンスメントを維持しながら、重複する観察者とアニメーション作業を削減します。 (#622)

## 修正

- Web 記事のインポートを DNS 再バインドに対して強化し、リクエストをバインドして予約アドレスをバイパスし、インポートを検証済みの IP アドレスにレンダリングします。 (#623)
- AI ランタイム ログから API キーのフラグメントを削除しました。ログには、プロバイダー ID と資格情報が構成されているかどうかのみが記録されるようになりました。 (#624)
- 置換前に一時コピーを検証し、ロールバック スナップショットを保持し、切り替えに失敗した場合は以前のデータベースを再度開くことで、データベースの復元をアトミックにしました。 (#625)
- 記事の概要に考察とディスカッションの合計を個別に保存することで、注釈の詳細が読み込まれない場合でも読み取り統計の正確さを維持しました。 (#626)
- キーボード チャットのショートカットがすぐに開いたり閉じたりするようにしましたが、ポインタの操作では割り込み可能なパネルの動作が維持されました。 (#630)
- Web サイト上の動きを減らした動作、ミュートされたテキストのコントラスト、キーボード スキップ ナビゲーション、画像レイアウトの安定性が改善されました。 (#631、#636、#640)

## エンジニアリング

- コンパイラ API が TypeScript 7 をサポートするまで、Astro Web サイトを TypeScript 6 に維持しながら、コマンドラインのタイプチェックをネイティブ TypeScript 7 にアップグレードしました。 (#615)
- pnpm とワークスペースの依存関係を更新し、Vite 共有チャンクのデスクトップ リソース パス解決を修正し、文書化されたローカル CI ゲートにデスクトップ E2E を追加しました。 (#617、#627)
- デスクトップ IPC レジストラの依存関係の絞り込み、アノテーション データフロー ドキュメントの更新、シェル/ライブラリ スタイルの所有権の明確化、ライブラリの遷移の簡素化、アプリ ヘッダーの圧縮、および温かみのある紙のニュートラルと共有の辰砂のアクセントを中心としたデフォルトのテーマ サーフェスの統合。 (#628、#629、#633、#635、#639、#641)
