リリース日: 2026-05-11

## 新規

- デスクトップ ライブラリは、URL によって Web 記事をインポートし、本文の画像を保持し、ベースラインの記事のタイポグラフィをレンダリングできます。
- Reader には、選択コピー、ショートカット、注釈アクションとタイプ アイコン、サイドバー フィルタリングが追加されました。
- メッセージ送信のショートカットは設定で設定でき、リーダーの送信、キャンセル、ヒントのコピーに反映されます。
- ユーザーの注釈は、注釈のタイプと読み取り意図を非同期的に推測でき、`@` アシスタントのメッセージは複数のアシスタントのタスク計画に分割できます。
- 章カード、手動アシスタント割り当て、章メッセージ、記事分析ベースのルート生成による集中的な共読機能を追加しました。

## 修正

- ユーザー注釈の意図とショートカットの永続性、ショートカットのヒントの配置、注釈カードのクリックによる展開、および SubmitShortcutKeys のレイアウトを修正しました。
- コンパクトなレイアウトでプロバイダー エディターの選択メニューがダイアログ オーバーレイの背後に隠れていた問題を修正しました。
- アシスタントの章の冒頭テキストの欠落と浅いフッター見出しが章の計画を歪めている問題を修正しました。
- 長すぎる自動注釈タグを修正し、集中共読がマージされた後にユーザー注釈コメントを復元しました。
- ルートレベルの単一タスクとしてではなく、ワークスペース パッケージごとに実行されるように lint/format タスクを修正しました。

## ドキュメント

- lint/フォーマットフローに関する開発エージェントドキュメントを更新し、Chrome 拡張機能、プライバシー、サードパーティ通知、配布資料をクリーンアップしました。

## その他

- 製品ラインをデスクトップ アプリに集中させるため、Chrome 拡張機能のワークスペース、ランタイム、デスクトップ ペアリング ブリッジ、ストア アセットを削除しました。
- PR とメイン プッシュ、lint の実行、フォーマット チェック、テスト、および固定タイムゾーンでのビルド用の GitHub Actions CI を追加しました。
