公開日: 2026-06-01

## 新規

- 読み取りメモリ基盤、書き込み段落、選択、スレッド、および注釈メモリをローカル ストレージに追加し、後のアシスタント世代で既存の判断チェーンを再利用しました。
- AI アシスタント ランタイムを、選択アクション、スレッド応答、共読ツール ループ、診断、ディープ ランタイム用の AI SDK 移行を備えた追跡可能なツール呼び出しフローにアップグレードしました。
- アノテーション ディスカッションをスタンドアロンのディスカッション ウィンドウと、アシスタントの参加、蒸留されたドラフト、レビュー アシスタントのフィードバック、公開された蒸留カード、蒸留統計を含む蒸留フローにアップグレードしました。
- 統一された Web 記事、EPUB、PDF の閲覧ビジュアル用に、テーマ コントラクト、テーマ ピッカー、リーダー用紙の背景コントロールを追加しました。 PDF では、濃い色の紙でも元のページの色が維持されます。
- Web 記事の表紙と進行状況、バッチ ファイルのインポート、洗練されたインポート ダイアログ、カード統計のヒント、PDF/EPUB メタデータのクリーンアップなど、ライブラリとインポートのエクスペリエンスが向上しました。

## パフォーマンス

- 長い記事と長い書籍を一緒に読む際の繰り返しのパッセージ検索を減らすために、語彙関連のパッセージをキャッシュしました。
- インポート中に UI の応答性がブロックされないように記事のインポートを最適化しました。
- 起動時に同じ履歴移行が再実行されるのを避けるために、重複するアノテーション メモリのバックフィルをスキップしました。

## 修正

- PDF 注釈アンカー、オーバーフローしたリスト テキスト、PDF の暗い用紙の色、EPUB 矢印キーによるページネーション、およびリーダー ヘッダーのドラッグ リグレッションを修正しました。
- 重複した思考、スレッド メモリ ソース、読み取りメモリとアシスタント ランタイムにおけるツール呼び出しの安定性を修正しました。
- ライブラリのページサイズの永続性、WeRead の詳細カバー、電子ブックの章ノート数、電子ブックのヘッダー カバーのホバー、および暗黙的な注釈メタデータ推論を修正しました。
- 洗練された注釈カード、アシスタント アバター、注釈アクション、ショートカット ツールチップ、カバー ホバー、概要ページ、テーマ ペーパー、および一般的な UI インタラクション。

## エンジニアリング

- タイプ認識リンティングを有効にし、依存関係を更新し、選択コンテ​​キスト ユーティリティを抽出し、ディープ ランタイムを AI SDK に移行し、重複するランタイム境界ロジックを削減しました。
- リリース サイズを削減するために、古い集中的な共同読み取りフローを削除し、デスクトップ パッケージからネイティブ モジュール ファイルをトリミングしました。
- Web サイトのバージョンのリンクがデスクトップのオープンソース ライセンス情報と一致するように、ユーザー ドキュメント、Web サイトのダウンロード エリア、サードパーティのライセンス リストを更新しました。
