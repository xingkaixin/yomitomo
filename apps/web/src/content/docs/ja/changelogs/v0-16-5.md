公開日: 2026-10-17

## 新機能

- アシスタントは資料ごとに会話の記憶を保持し、スレッドの返信、ハイライトへの考察、読者Q&Aでこれまでのやり取りを引き継ぎます。目次、章、本文検索、読書メモリ、ディスカッションを必要に応じて参照します。EPUB ではハイライトから始めると章全体を読み、テキストを選択しない質問は読書の進み具合までに限られます。(#971)
- ウィンドウを閉じてもアシスタントの返信は続き、再起動後に再開します。同時にメンションしたアシスタントは並行して返信します。ツール呼び出し前に書かれた文章を保持し、ディスカッションと読者Q&Aに各ツールの手順を表示します。「アシスタント実行モード」（高速応答 / 詳細な検証）の設定は廃止しました。(#971)
- 返信で引用された段落やディスカッションを下線付きのリンクにしました。クリックするとリーダーが該当箇所へ移動するか、ディスカッションを開きます。(#971)
- 蒸留レビューは、その資料でのレビュー担当者の会話を引き継ぎます。不適切なレビュー項目はモデルが修正して再提出し、レビュー全体は失敗しません。(#972)
- プリセットモデルを現行版に更新して提供終了のモデル ID を削除し、読書メモリのローカルモデル設定カードを整理しました。(#972)

## 修正

- pi-ai のモデルカタログに基づいてモデルごとの思考と温度のパラメータを設定し、Claude 5、Gemini 3.8、GPT-6 などに非対応のパラメータを送らないようにしました。温度は思考がオフのときだけ適用します。(#972)
- プロバイダーのモデル一覧が長い場合はスクロールするようにし、項目の詰まりやフッターの欠けを修正しました。(#972)

## 開発・保守

- アシスタントの返信、蒸留レビュー、翻訳、読書判断、メンションの振り分け、接続テストを pi-ai と pi-durable に移行し、AI SDK のツールループ実行基盤と旧コメントストリームを削除しました。(#971, #972)
- 未使用の注釈生成、エージェントレビュー、読書コンテキスト、記憶ビューのコードを削除しました。(#972, #973)
