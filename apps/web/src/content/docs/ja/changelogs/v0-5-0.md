---
title: "0.5.0"
description: "Yomitomo 0.5.0 リリースノート。"
---

公開日: 2026-05-26

## 新規

- ローカル PDF ライブラリ エントリ、アウトライン、選択、統一された注釈ビジュアル、アシスタント ドック、集中的な PDF の共同読み取りを含む、デスクトップ アプリでの PDF のインポートと読み取りが追加されました。
- WeRead ノートをYomitomoのローカル読書ライブラリに取り込むための WeRead ノートの同期、読書統計、API キー設定ドキュメントを追加しました。
- 完成したキーボードのページネーション、バンドルされた読み上げフォント、自動設定によりフィードバックが保存されるため、EPUB、PDF、設定のワークフローがより安定しています。
- タイプ付き IPC およびローカル記事パッチを中心にデスクトップ記事の更新を再調整し、状態の読み取り、下書きの設定、およびマルチウィンドウの同期を中断するストア全体の置き換えを削減しました。

## パフォーマンス

- デスクトップの起動、統計の読み込み、セカンダリ モジュールのプリロードが改善され、インポート中のフルストア読み取りが減少しました。
- EPUB コンテキストおよびインデックス範囲クエリのインデックスを追加し、長い本の章の検索、コンテキストの取得、および注釈の生成における繰り返しのスキャンを削減しました。
- スクロール中のリーダー注釈のスキャンとレイアウト作業を軽減し、大きなドキュメントの診断用に PDF オープン パフォーマンス トレースを追加しました。

## 修正

- PDF の選択、アウトラインの動作、注釈フロー、PDF の思考拡張の調整を修正しました。
- リーダー本体のフォントサイズの継承、外部リンクの開き方、アニメーションのレイアウトコスト、中幅の注釈レイアウト、アシスタントメニューのクリッピングを修正しました。
- 保存後にデスクトップ プロファイル ダイアログが閉じる問題を修正し、ファイル インポート ダイアログのリグレッションを保護し、関連するテスト カバレッジを追加しました。

## エンジニアリング

- デスクトップ記事概要レコード、ストア永続性、記事設定、メイン IPC 登録、ファイル インポート ダイアログ、PDFium リーダー ユーティリティ、およびソース リーダー セッション境界を分割します。
- 共有タイプのエクスポートとリーダー UI モジュールの境界を分割し、エージェントのアノテーション アクションを一元化します。
- PDF.js の依存関係を削除し、関数スコープの警告に対処し、リーダー インタラクション フロー、エージェント シアター データ フロー、デスクトップ ストア パッチ ルール ドキュメントを追加しました。
- 開発リソースの分離、リリース プロキシ ワーカー、Web サイトのドキュメント/変更ログ ページ、およびアニメーション ロゴの実験を追加しました。
