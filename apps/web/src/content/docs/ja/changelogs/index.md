## 0.14.0

公開日: 2026-07-31

- 記事のアイデンティティとソースの読み取りが、Web 記事、電子ブック、PDF、テキストのインポート全体で明示的に行われるようになり、翻訳、進行状況、注釈が適切なソースに添付された状態が維持されます。
- アシスタント タスクのオーケストレーションがより深くなり、ストリーミングされた作業は元のウィンドウに留まります。ページ化されたカタログと再利用されたインデックスにより、大規模なライブラリと長時間の読み取りセッションが軽量になります。
- スクロール中の PDF 選択、再起動が必要なテキストのインポート、更新ダイアログのタイミングとインポート、Kindle デコード、および IPC の安全境界を修正しました。

[0.14.0 リリースノートを見る](/ja/changelogs/v0-14-0/)

## 0.13.0

公開日: 2026-07-20

- 新しい蒸留ライブラリは、公開されているすべての蒸留を 1 つの検索可能なリストに集め、全文検索とソースの注釈へのジャンプが可能です。
- EPUB リーダーは、元のテキストに加えて章レベルの対訳読み上げを追加し、再起動後に自動的に復元します。
- コレクション カードは、ホバーまたはフォーカスすると広がるファンアウト カバーになり、アプリのフィードバック アニメーションはよりスムーズで抑制されたものに感じられます。
- ページ化されたカタログにより、大規模なライブラリの起動時の応答性が維持されるほか、コレクションのナビゲーション、インポートのフィードバック、進行状況の保存、PIN の調整が修正されています。

[0.13.0 リリースノートを見る](/ja/changelogs/v0-13-0/)

## 0.12.0

公開日: 2026-07-14

- アシスタントの実行モードは、注釈、フォローアップ、および共読にわたる迅速な応答とより深い検証を切り替えることができます。
- コレクションの整理にはアナウンスとともにキーボードのドラッグ アンド ドロップが追加され、ライブラリのグリッドは利用可能な幅に適応します。
- データベースの復元はアトミックで回復可能になりましたが、Web インポートと API キーのログのセキュリティ境界はより厳しくなりました。
- デフォルトのテーマは、温かみのある紙と辰砂を中心にしています。 Web サイトには、モバイル製品のプレビュー、スクロール モーション、およびアクセシビリティの改善が追加されています。

[0.12.0 リリースノートを見る](/ja/changelogs/v0-12-0/)

## 0.11.0

公開日: 2026-07-05

- 注釈カードはファンスタックシャッフル動作を獲得するため、密集したレールをスキャンしやすくなります。
- オートメーションの実行では実際のテレメトリ ハートビートが送信されなくなりました。
- デスクトップ E2E の対象範囲は、ライブラリのインポート、リーダー ナビゲーション、注釈、進行状況、設定、AI、EPUB/PDF インポート、レスポンシブ レイアウトにまで及びます。
- Reader、PDFium、Web ソース、スタイル、記事リポジトリの境界は、将来の変更リスクを軽減するために分割されました。

[0.11.0 リリースノートを見る](/ja/changelogs/v0-11-0/)

## 0.10.0

公開日: 2026-06-28

- ライブラリはテキスト タイプを追加します。テキストを貼り付けるか、`.txt` / `.md` をアップロードし、原稿の表紙、タイプ フィルター、およびコレクションのサポートを追加します。
- 選択項目にはドラッグ可能なエンドポイント ハンドルが追加され、インポートとモデルのルーティングにはプライバシー境界の通知が表示されます。
- 電子ブックのクリックしてページに移動するホット ゾーンと適応型見開きレイアウト。PDF のデフォルト ズームはウィンドウの幅に適応します。
- ダブルクリック選択を無効にし、更新後にカバーが圧迫されるのを修正し、デスクトップのセキュリティ境界を強化しました。

[0.10.0 リリースノートを見る](/ja/changelogs/v0-10-0/)
