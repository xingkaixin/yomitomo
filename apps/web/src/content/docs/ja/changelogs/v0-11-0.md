公開日: 2026-07-05

## 特徴

- 注釈カードがファンスタックシャッフル動作をサポートするようになりました。密度の高い注釈レールはスキャンしやすく、重なっているメモを前方に持ってきて読むことができます。 (#590)

## 修正

- 自動化中はテレメトリ ハートビートが無効になるため、ローカルおよび CI E2E の実行では実際のデスクトップ ハートビート イベントが書き込まれません。 (#591)

## エンジニアリング

- デスクトップ UI ハーネス、分離された E2E テスト データを追加し、ライブラリのインポート、リーダー ナビゲーション、注釈、進行状況、設定、AI、EPUB/PDF インポート、レスポンシブ レイアウトの E2E 対象範囲を拡張しました。 (#592–#605)
- デスクトップ レンダラー App Shell、Web ソース ヘルパー、PDFium ドキュメント ロジック、リーダー検索ナビゲーション、および選択調整ルールを、テスト対象の共有境界に分割します。 (#606、#607、#610、#611、#612)
- リーダー会話 CSS を分割し、従来のスタイルのオーバーライドを削除し、デスクトップ スタイルの所有権を文書化し、記事リポジトリ ドメインを分解しました。 (#608、#609、#613)
