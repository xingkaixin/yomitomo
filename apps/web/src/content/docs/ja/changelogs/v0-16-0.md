公開日: 2026-10-01

## 新機能

- macOS の更新に Sparkle を導入し、読書をテーマにした DMG 背景を追加しました。旧バージョンからの初回更新では完全な ZIP をダウンロードします。インストールして再起動した後は、次回以降のリリースで差分更新を利用でき、適用できない場合は完全パッケージに切り替わります。(#893)

## パフォーマンス

- 同じ文書の検索で正規化済みテキストと位置情報を再利用し、検索語を変更する際の重複処理を減らしました。(#894)
- PDF エンジンを Worker に移し、UI スレッドの処理を減らしました。PDF を開くと現在のページと隣接ページのテキストを優先し、全文検索や全文が必要なアシスタント操作の際に全文を準備します。(#895, #896)
- 読書メモリの意味検索で一時的な候補リストのサイズを制限し、大きなライブラリの検索時にメモリ使用量を抑えました。(#899)
- 公式サイトのコンテンツ指紋付き静的アセットを1年間キャッシュし、再訪時のダウンロードを減らしました。(#890)

## 修正

- 初回ガイドをすべて読む前にアプリへ入れるようにしました。AI の設定は後から行えます。(#897)
- 公式サイトのモバイル向け製品プレビューと、ダウンロードボタンの対応環境表示を改善しました。(#892)
- ローカルの読書データ、外部 AI への送信、データベースのバックアップ範囲を明確にしました。未実装の本全体のエクスポートなどの記述を、項目ごとの手動コピーの説明に修正しました。(#898, #900)

## 開発・基盤

- Electron を 44.3.0、pnpm を 12.3.4 に更新し、実行時・ビルド依存関係を更新しました。(#889, #891)
- 署名付き Sparkle フィード、差分ファイル、macOS 更新のスモークテストを追加しました。旧クライアント用の ZIP、blockmap、latest-mac.yml も引き続き提供します。(#893)
