公開日: 2026-06-17

## 特徴

- オプションのアプリロックを追加しました。アプリから離れたり、再度開いたりするときに、ローカルの読み取りワークスペースを保護するために PIN を設定できます。 PIN 検証情報はシステム キーリングに保存されますが、SQLite は必要な状態のみを保持します。
- ウェブ記事の翻訳に段落レベルのフィードバックを追加しました。これにより、どの段落に翻訳されたテキストが適用されているかが明確になります。
- リーダーの目次ナビゲーションの改善: アクティブなセクションが強調表示され、目次を開いたときにアクティブなエントリがフォーカスされ、目次の切り替えがよりスムーズにアニメーション化されるようになりました。
- ウェブサイトのダウンロードとアプリの更新アセットを Cloudflare ダウンロード ワーカー経由でルーティングし、ダウンロード/更新イベントを Analytics Engine に書き込む際にウェブサイトのインストーラー、更新マニフェスト、更新パッケージ、ブロックマップをカバーしました。
- ウェブサイトの読み込みを継続し、藍インク パレットを使用してビジュアルを磨きました。

## 修正

- リーダー チャット ストリーミングが安定化されたため、アシスタントの返信がセッション状態を失ったり、ストリーミング中にレンダリングが一貫して行われたりする可能性が低くなります。
- 完了したアクションを確認しやすくするために、選択範囲をコピーした後もコピー フィードバックが表示されるようにしました。
- ダウンロード サービスと Web サイトのデプロイメント スクリプトを修正しました。これにより、ダウンロード ワーカーはデプロイメント前にビルドされ、Web サイトの Pages デプロイメントでは冗長なビルドが回避されます。
