公開日: 2026-11-03

## 新機能

- ライトテーマ「藍墨」を追加しました。冷たい白の紙面、万年筆の青、鉛筆で描いた枠や罫線で、ライブラリ、設定、統計、読書メモリ、アシスタント、ダイアログ、リーダー UI を描きます。本の本文には装飾を加えません。(#1007)
- 初回起動画面を刷新しました。言語を切り替えられ、ハイライト・考察・アシスタントの返信の例を表示し、AI なしでも読めることを説明します。インポートの入口は AZW3 と MOBI にも対応します。(#1006)
- カードを注釈と蒸留の間で切り替えると 3D でめくれ、蒸留の公開時には紙をめくる音が鳴ります。重なったカードは上の角を軸に扇状に開き、注釈の多いレールでも蒸留の確定で読書が止まらなくなりました。(#1008)
- アプリアイコンとウェブサイトのロゴを刷新し、ウェブサイトのランディングページ、ドキュメントのレイアウト、404 ページを作り直しました。フォントのダウンロード量は 67–90% 減りました。(#1011, #1012)

## パフォーマンス

- PDF のページを canvas に直接描画し、大きな PDF を開くときのメモリ使用量を 24–27%、スクロール中は 24–35% 削減し、最初の表示も速くなりました。(#999)
- 以前のバージョンでインポートした EPUB の章に残っていた base64 画像を削除しました。サンプルのライブラリでは章データが 53 MB から 4.4 MB に減り、大きな本でページをめくってもメモリが膨らまなくなりました。(#1000)
- 電子書籍を最大 3 冊同時にインポートし、一括インポートの時間がおよそ半分になりました。(#1018)
- ウェブ記事の画像を並行してダウンロードし、1 枚の遅い画像がほかの画像を待たせないようにしました。ファビコンは 3 秒でタイムアウトします。(#1017)
- キーチェーンの読み取りをメインスレッドの外に移し、アシスタントの返信ごとのキーチェーン読み取りを 1 回減らしました。アシスタントが考察を書く前の余分なモデル呼び出しもなくしました。(#1014, #1015)
- 起動時のキャッシュ整理、バックアップファイルのハッシュ計算、電子書籍を初めて開くときの読み込みを並行化しました。(#1016)

## 修正

- 既存ユーザーのタスク別モデル設定を修正しました。個別に設定していないタスクは既定モデルに従って「既定のモデルを継承」と表示し、既定モデルだけを設定した場合もアシスタントがルート未設定と表示しなくなりました。(#1005)
- PDF を開いたときに最初のページの上端に留まり、上端付近の注釈がすぐに表示されるようにしました。(#1004)
- スクロール中に注釈レールのカードが現れる・消える・移動する動きを滑らかにし、注釈の多いページでも跳ねたりちらついたりしなくなりました。(#1003)
- 重なった注釈カードを切り替えると入れ替わるカードだけが動き、背の高いカードの後ろにある短いカードも見えるようにしました。(#1002)
- リーダーの目次を閉じるとき、半透明にならずに格納されるようにしました。(#1001)

## 開発・保守

- レンダラーの状態を zustand ストア、reducer、TanStack Query に移し、レンダラーのコードで状態・副作用フックを直接使うことを制限しました。(#983–#997)
- Electron を 45.2.1、Node.js を 24.22.2、Effect を 4.1.1、pi を 1.5.0 に更新し、undici のセキュリティ修正版を取り込み、プロバイダーへのリクエストで pi の帰属ヘッダーを送らないようにしました。(#979, #998, #1013)
- 並列ジョブと変更範囲に応じたスキップで CI を高速化し、oxlint の suspicious と perf ルールをエラーにし、パッケージ版の起動ベンチマークを追加しました。(#978, #980, #1009)
- README とウェブサイトの文言を整理しました。(#981, #982)
