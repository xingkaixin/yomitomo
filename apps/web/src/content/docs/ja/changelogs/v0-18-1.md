公開日: 2026-11-20

## 新機能

- 対話ウィンドウを最小化すると、Dock やタスクバーではなく、リーダー内の折り返したしおり型カプセルに戻ります。カプセルを開くと、同じウィンドウと未送信の返信が復元されます。カプセルのグループはリーダーの四隅にドラッグして配置できます。ウィンドウがリーダーの外にはみ出していても、最小化と復元のアニメーションは途切れません。(#1084, #1085, #1091)
- ⌘F / Ctrl+F で、開いているウェブ記事、電子書籍、PDF を検索できます。選択メニューにワンクリックの「ハイライト」を追加し、入力欄を開かずに保存できます。記事内のアンカーと脚注はリーダー内でスクロールして移動します。対話や蒸留のウィンドウで段落の引用をクリックすると、メインウィンドウで該当する資料を開き、その段落を一時的に強調します。(#1100)
- 保存した自分の考えと返信を編集できます。AI の返信とハイライトした原文は変更されません。ハイライトの色は、カードのメニューまたは対話ウィンドウの上部から個別に設定できます。(#1101)
- 記事のメモ、蒸留、微信読書の書籍メモを Markdown でエクスポートまたはコピーできます。ハイライト、考え、対話、公開した蒸留は原文のまま出力します。(#1102)
- アシスタントの返信に失敗すると、モデル未設定、無効なキー、残高不足、レート制限、ネットワーク障害などの原因を表示し、再試行とモデル設定へのリンクを示します。リーダーの質問では、生成の停止、セッションの新規作成・切り替え・消去、回答のコピーができます。ダイアログを開いている間、内蔵の微信読書は読書位置を保ったまま非表示になります。(#1104)
- 読書メモリの準備ができていない場合は、ローカルモデルのダウンロードやプロバイダー設定に直接移動でき、モデルのダウンロードと索引作成の進捗を表示します。ライブラリへの質問はこのセッションの履歴を最大 20 件保持し、回答を引用付きの Markdown としてコピーできます。プロバイダー設定は複製でき、API キーは別のキーチェーン項目にコピーされます。(#1105)
- EPUB、AZW3、MOBI、PDF、TXT、Markdown ファイルをライブラリにドラッグしてインポートできます。「ファイル > テキストを読み込む」も使えます。カードのメニューに「コレクションに追加」と、タイトルと著者を変更する「情報を編集」を追加しました。ライブラリは最近の更新、タイトル、読書の進捗、注釈数で並び替え、未読、読書中、読了、注釈ありで絞り込めます。ローカルの PDF や電子書籍のファイルが見つからない場合は、リーダーからファイルを選び直せます。(#1107)
- PDF の現在のページを翻訳し、訳文をページに重ねて表示できます。初版は 1 段組みのテキスト PDF が対象で、テキスト層のないスキャンページは翻訳しません。PDF にダーク保護フィルター、幅に合わせる、ページ全体、100% の表示倍率と、⌘/Ctrl + / − / 0 のズームショートカットを追加しました。(#1108)
- OpenRouter と Vercel AI Gateway のプロバイダープリセットを追加しました。(#1111)

## パフォーマンス

- PDF のインポートとサムネイル描画をメインプロセスからワーカースレッドに移しました。リーダーは PDF を読み込んだ後にファイルのバッファを解放し、本文や目次が変わったときだけ書籍全体のテキストをアシスタントに送ります。(#1096)
- SQLite で `synchronous = NORMAL` とビジータイムアウトを有効にし、`VACUUM` を起動後にバックグラウンドで実行するようにしました。読書の進捗の書き込みを遅くしていた古い索引も削除しました。(#1097)
- 読書メモリの検索と索引作成で 1 つの埋め込みワーカーを共有し、検索を優先します。見直しのクエリも高速化しました。(#1098)
- 対訳翻訳は段落が完了するたびにその段落だけを送り、訳文全体を繰り返し送らなくなりました。ウェブリーダーのハイライト位置は描画のたびに再計算しません。(#1095)

## 修正

- 微信読書の同期、翻訳、インポートがネットワークを待っている間も、バックアップと復元がデータベース使用中で失敗しなくなりました。バックグラウンド処理が止まっていても、アプリの終了が止まりません。(#1097)
- EPUB の読書メモリ検索、対話の読み取り、返信のリンクがアシスタントの読める範囲に従い、未読の章のメモを表示しなくなりました。(#1082)
- 別のウィンドウで削除された考えへの返信は拒否され、下書きは残ります。アシスタントを切り替えても届いたばかりの返信が消えず、全体同期中に微信読書の 1 冊を更新しても新しいメモが失われません。(#1088, #1089, #1090)
- 配信の途中でアプリが終了しても、アシスタントはメッセージを飛ばさなくなりました。ある対話でコメントを取り消しても、別の対話に影響しません。リーダーの質問はウィンドウ間で同期し、新しい返信を上書きしません。データベースの復元前には、実行中のアシスタントと読書メモリの処理を停止します。(#1092, #1093, #1099)
- ウェブ記事のインポートで、直接取得とブラウザ描画のタイムアウトを分け、空のシングルページアプリは描画して再試行します。ファイルパスに `%` を含む EPUB もインポートでき、インポートの失敗時には具体的な理由を表示します。(#1095)
- ログの整理中に書き込まれた診断記録が失われなくなり、アシスタントのログは 10 MB を上限とします。(#1094, #1095)

## 開発・保守

- Effect を 4.1.4、Electron を 45.3.3、better-sqlite3 を 13.2.0、pnpm を 12.21.0 に更新し、Astro、Vite、DOMPurify などの依存関係と第三者ライセンス表示も更新しました。型情報を使う lint を tsrs に切り替え、中央値の実行時間を約 8 秒から 3 秒に短縮しました。(#1086, #1087)
- 読書メモリの人手レビュー用テンプレートをオフラインで書き出すツールと、AI を模擬するローカルのデバッグタスクを追加しました。(#1083, #1110)
