## 特徴

- ライブラリはテキスト コンテンツ タイプを追加します。テキストを直接貼り付けることも、`.txt` / `.md` ファイル (一度に複数) をアップロードすることもできます。 Import はエンコーディングを検出し、確認できるようにタイトルと作成者を推測し、コンテンツの先頭に Markdown YAML 前付をメタデータ ブロックとしてレンダリングします。テキストには独自の原稿カバーが付けられ、タイプごとにフィルタリングしてコレクションに追加できます。 (#588)
- インポートとモデルのルーティングにプライバシー境界通知が表示されるようになりました。インポート ダイアログには、ファイルがデバイス上に残り、アップロードされないことが示されますが、モデルのルーティング設定には、構成および使用されると、関連するコンテンツが設定したエンドポイントに送信されることが示されます。 (#587)
- 選択範囲にドラッグ可能なエンドポイント ハンドルが追加されました。 Web 記事、電子ブック、または PDF 内のテキストを選択すると、両端にハンドルが表示されるため、再選択せずに選択範囲を拡大または縮小できます。 (#584、#585、#586)
- 電子書籍には、クリックしてページへ移動するホット ゾーンが追加され、左側または右側をタップしてページをめくることができ、目次のホバーとジャンプ ナビゲーションがよりスムーズになります。 (#565、#558、#559)
- 電子ブックはアダプティブ スプレッド レイアウトをサポートしており、注釈レール用のスペースを確保しながら、デフォルトの PDF ズームがウィンドウの幅に適応するようになりました。 (#556、#555)
- デスクトップ アプリは、項目がシステム言語 (中国語/英語、他の言語の場合は英語に戻ります) に従うローカライズされた運用アプリケーション メニューを追加します。 (#563)

## パフォーマンス

- リーダーのレンダリングのホットスポットを減らし、スクロールとインタラクションをよりスムーズにしました。 (#564)
- 電子ブックの繰り返しのページネーション測定作業を軽減し、ページングとレイアウトを軽量化しました。 (#557)

## 修正

- 記事や PDF コンテンツでのダブルクリック選択が無効になったため、ページめくりのタップで単語や段落が選択されなくなりました。 (#582、#583)
- 更新後に幅広のカバーが圧迫される問題を修正しました。カバー率は、デフォルトの狭い比率に戻るのではなく、キャッシュされた画像から正しく復元されるようになりました。 (#581)
- デスクトップのセキュリティ境界を強化し、アプリがロックされている間はレンダラー ストアをロックし、アプリ ロック中の状態変更を防止しました。 (#567、#562)
- テーマ トークンを介して暗いリーダーの色をルーティングし、思考がゼロの場合に WeRead 同期キーを保持し、更新ダイアログの進行状況とトリガーを調整しました。 (#561、#560、#554)

## エンジニアリング

- デスクトップ ストア モジュールを分割し、いくつかの沈降ウィンドウとリーダー コンポーネントを責任ごとにリファクタリングし、重要なリーダー パスのテストを追加し、ワークスペースの依存関係を更新しました。 (#580、#569～#579、#568、#566)
