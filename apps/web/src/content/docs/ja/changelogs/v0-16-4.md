公開日: 2026-10-13

## 修正

- EPUB を開く際の注釈への移動、繰り返し文の位置復元、改行をまたぐ選択を修正しました。PDF の選択範囲変更後に届く古いテキストを無視します。(#950, #951, #962)
- 保存の連続操作による注釈の重複を防ぎ、再翻訳を開始できなかった場合は既存の翻訳注釈を保持します。(#956, #967)
- カスタム Anthropic プロキシの URL を修正し、AI ストリームの途中エラーを失敗として扱います。詳細検証から高速応答に切り替わる際は、未完の詳細応答を破棄します。(#952, #957)
- アシスタントの記憶検索では件数制限の前にアシスタントと表示範囲で絞り込みます。重複する考えの確認も、現在のアンカー付近に絞ってから件数を制限します。(#958)
- 小文字化で長さが変わる文字を含むテキストでも、検索ハイライトの位置がずれないようにしました。(#965)
- 注釈、議論、まとめを実際の日付で集計し、記事を開き直しても過去の活動や連続読書日数が変わらないようにしました。(#953)
- WeRead の API キー変更後は古い同期結果を破棄し、保存に失敗した値をそのまま再試行します。(#964, #966)
- モデル一覧の遅延応答が、編集中のプロバイダー設定や別のプロバイダーの設定を上書きしないようにしました。(#968)
- キーチェーンが使えない場合は移行待ちの旧 API キーを保持し、キーの削除やバックアップ復元後に古い資格情報を使わないようにしました。(#954)
- アプリをロックすると議論・まとめウィンドウを閉じ、それらが開始した AI リクエストもキャンセルします。(#949)
- 記事取り込み中に読み込むページからの権限要求とポップアップを拒否します。(#948)
- 新しい Web 記事の ID に URL 全体のダイジェストを使って衝突を防ぎ、既存の記事 ID は保持します。(#959)
- モバイル版ドキュメントのサイドバーを復元し、読書デモのダイアログ内にキーボードフォーカスを保ちます。(#955, #960)

## 開発・保守

- デスクトップに同梱するコードの第三者ライセンス表示を補完し、リリースのパッケージ作成前に検証します。(#963)
- テレメトリー、モデル価格取得、アプリロックの実際の動作に合わせて、通信とプライバシーの説明を更新しました。(#961)
- Electron を 44.7.0、pnpm を 12.11.2 に更新し、実行・ビルド依存と CI actions も更新しました。インストール済みの読書メモリモデルが必要とするランタイムのバージョンは維持します。(#969)
