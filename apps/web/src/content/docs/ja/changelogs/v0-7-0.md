公開日: 2026-06-16

## 新規

- デスクトップ言語の切り替え、分割アプリ ロケール リソース、バイリンガル Web サイト ドキュメント、ローカライズされたアシスタント ペルソナ プレゼンテーション。
- 永続的なリーダーチャット、リーダー内検索、統合フローティングツールバー、再設計された記事ヘッダー、空のメモの洗練、適応型注釈レイアウト、スムーズなスタックカード切り替え、統合された選択の強調。
- 削除/再翻訳時のカスケード クリーンアップと UI ロケールに合わせた応答言語を備えたバイリンガル Web 記事翻訳。
- より深い注釈とディスカッションのフロー: ルートアシスタントの返信ルーティング、抽出ドラフトとレビュー提案の UX、移行モーション、インク書き込みの追加思考セレモニー、およびアシスタントの書き込みアニメーション。
- 設定とライブラリ IA、統計でのアシスタントの使用法、黄昏の藍のテーマ、アシスタントのプロフィール ダイアログ、情報ツールチップの設定の説明を再調整しました。
- リリースノートダイアログ、ローカルアノテーション書き込み、再デザインされたメディアカバー、手書きのインクペーパー/テーマピッカー、および発音によるブランド発音。
- 統合されたトースト (WeRead を含む)、効果音コントロール、ハイライト、コピー、ライブラリ アクション、蒸留のフィードバック。
- 読者スタイルの Web サイトのランディング ページとブログのシナリオ記事。

## パフォーマンス

- 読み取りメモリ、EPUB インデックス、SQL ベースのアシスタント サマリーの再利用を強化します。メモ化された Markdown レンダリング。インポートのライフサイクルとソースリーダーのワークスペース境界をより明確にします。

## 修正

- 設定、リーダー、ライブラリの改良。注釈レールのグループ化と蒸留アンカー。ディスカッションと思考のやり取り。統計におけるアシスタントの貢献。
- SQLite ネイティブ ルート パッケージ化、メモリ バックフィルの再試行、DOMPurify サニタイズ、およびレンダラー サンドボックス。
- Web サイトのランディング レスポンシブ レイアウトとカルーセル水平スクロール。

## エンジニアリング

- 大規模なモジュール分割、ベース UI の移行、検証された構造化 IPC、E2E スモーク ベースライン、および署名/公証された macOS リリース パイプライン。
