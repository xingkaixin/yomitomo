公開日: 2026-10-09

## パフォーマンス

- 起動時のモジュールと重い取り込み依存を必要時に読み込み、表紙キャッシュを制限し、アシスタント画像を表示サイズに合わせて保存して、起動処理とメモリ使用を減らしました。(#931, #932, #933, #942, #943)
- リーダーの再描画、記事の再計算、テキスト操作時の全文走査を減らしました。(#934, #935)
- 読書メモリのバックグラウンド処理を通知で起動し、モデルファイルの重複検証と検索バッファーのコピーを減らしました。(#936, #937)
- 本文とメタデータを分離し、読書位置の保存時に本全体を書き直さないようにしました。設定保存時の記事概要の読み込みも省きました。(#938, #940)
- UI ではシステムの中日韓フォントを優先し、ログ追記時のファイル操作を減らしました。(#939, #941)

## 修正

- Web リーダーで注釈が更新されてもテキストの選択範囲を保持します。(#944)
- Clash や Surge などの fake-IP プロキシ環境で Web 記事の取り込みが拒否される問題を修正しました。内部ネットワークの記事も追加設定なしで取り込めます。(#946)
- デスクトップの配布パッケージをビルド成果物と実行用リソースに限定し、不要なプロジェクトファイルの混入を防ぎました。(#930)

## 開発・保守

- Web サイトの検索とダウンロード集計を改善し、サイトと Worker のデプロイを cf CLI に移行しました。(#922, #926)
- テストの起動処理を軽量化し、価値の低いテストを削除して CI タスクをキャッシュしました。(#923, #924, #925)
- 共通の依存バージョンとプロジェクト文書を整理し、未使用の選択ルーティングと日替わり引用のコードを削除しました。(#927, #928, #929, #945)

## アップグレードについて

- 更新前にデータをバックアップしてください。本版はデータベースを reader level 4 に移行するため、更新後は v0.16.2 以前では開けません。旧版に戻すには、更新前の互換性のあるバックアップを復元してください。(#938)
