公開日: 2026-07-31

## 特徴

- 記事のアイデンティティとソースの読み取りが、Web 記事、電子ブック、PDF、テキストのインポート全体で明示的に行われるようになり、翻訳、進行状況、注釈が適切なソースに添付された状態が維持されます。 (#732、#733、#736、#770)
- アシスタント タスクのオーケストレーションがより深くなり、ストリーミングされた作業は元のウィンドウに残りますが、モデルの列挙は制限されます。 (#738、#739、#755、#759、#772)

## パフォーマンス

- SQLite カタログはページ化されており、大規模なライブラリや長時間の読み取りセッションでの繰り返しスキャンを減らすために、字句インデックス、章プレフィックス、テキスト範囲インデックス、およびアシスタント インデックスが再利用されます。 (#711、#712、#713、#726～#730、#761)
- WeRead スナップショットはバッチで書き込まれ、PDF および電子ブック リーダー ユーティリティは無関係な作業を実行します。 (#742、#756)

## 修正

- PDF の選択内容はスクロール中にアンカーされたままになり、テキストのインポートは再起動せずに表示され、リリース ノートが読み込まれる前に更新プロンプトが開きます。 (#760、#765、#766)
- テキストのインポートと Kindle デコードは制限されており、イベントとストリーミング IPC は検証され、受信 IPC はウィンドウ ロールによって許可され、データベース復元ライフサイクルの移行は明示的です。 (#709、#751–#754)
- 非同期ロガーの書き込み、ソースのライフサイクルの変更、資格情報の置換は、障害後に部分的な状態を残すのではなく回復できます。 (#706–#708)

## エンジニアリング

- 一元化されたデスクトップ IPC 記述子、プリロード ドメイン、記事の調整、アプリ セッションの所有権、アプリ ロックの読み取りを、クロスレイヤー コントラクトを限定して行います。 (#714、#720、#725、#744、#758、#767、#768)
- 統合された著者のアイデンティティ、翻訳セッション、カタログアイテムのバリエーション、注釈の受け入れ、およびソースリーダーの継ぎ目。未使用のパッケージ エクスポートを削除し、アイコンを Hugeicons に移行しました。 (#716、#718、#723、#735、#737、#740、#743、#745–#750、#771)
- PDF 翻訳、記事読み取りメモリ、およびプリロードに面した動作に関するデスクトップ UI/E2E の特性評価を拡張し、リリースゲートのドキュメントを検証可能にしました。 (#757、#762–#764)
