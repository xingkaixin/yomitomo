Yomitomo 可以通过微信读书官方 Skill API，把账号内有笔记的书籍信息、划线和想法同步到本地电脑。你可以在一个阅读库里按章节回看笔记、用合集整理、导出 Markdown、查看微信读书阅读时长，并跳转到微信读书原文继续阅读。**同步笔记不等于下载受保护的电子书全文，也不是双向同步。**

本文由 Yomitomo 项目维护，根据 v0.18.2 的功能与配置整理。

## 同步后能做什么，不能做什么？

在 Yomitomo 中，同步进来的微信读书书籍以**只读笔记视图**展示，与本地导入的网页、电子书、PDF、文本文档保持清晰区分：

| 能力                                                          | 是否支持 | 说明                                                                                                                           |
| ------------------------------------------------------------- | -------- | ------------------------------------------------------------------------------------------------------------------------------ |
| 同步有笔记的书籍、目录、划线和想法                            | 支持     | 点击「同步微信读书」或开启每 30 分钟自动同步，会同步全部有笔记的书籍（不支持同步前挑选书单）；单本书页支持「同步本书」单独刷新 |
| 按章节浏览笔记与加入合集                                      | 支持     | 与本地阅读材料一起归入「合集（Collection）」管理                                                                               |
| 导出 / 复制 Markdown                                          | 支持     | 在微信读书书籍页面工具栏中，可按章节导出 `.md` 文件或复制 Markdown                                                             |
| 查看阅读时长统计                                              | 支持     | 在「统计 > 微信读书」查看微信读书侧的阅读时长统计                                                                              |
| 跳回微信读书原文（含应用内网页版）                            | 支持     | 支持在微信读书 App、外部浏览器或 **Yomitomo 内置网页版**中打开原文定位                                                         |
| 直接在微信读书书籍里划线（`A`）、`@` 助手、沉淀或写入阅读记忆 | 不支持   | 微信读书条目为只读笔记视图，不参与本地批注、AI 伴读、沉淀与阅读记忆索引                                                        |

> 如果想对某本微信读书的划线和想法做 AI 伴读讨论、沉淀或纳入阅读记忆，可以先在该书工具栏导出为 Markdown，再把 `.md` 文件作为本地文本文档导入 Yomitomo。

## 1. 获取并配置 API Key

打开[微信读书 Skill 官方管理页](https://weread.qq.com/r/weread-skills)，按页面提示登录并创建 API Key。将它粘贴到 Yomitomo 的「设置 > 数据来源 > 微信读书」，保存后测试连接。

[微信读书 API Key 怎么获取？官方入口与配置教程](/docs/weread-api-key/)包含网页和手机 App 两种入口，以及连接失败时的检查步骤。微信读书的凭据与 AI 模型的 API Key 是两套独立配置。

## 2. 同步笔记并在需要时打开原文

1. 在阅读库进入微信读书来源，点击「同步微信读书」（或在设置中开启每 30 分钟自动同步）。
2. 同步完成后，打开任意一本有划线和想法的书，按章节浏览已同步的记录。
3. 如果某本书刚在手机上新增了划线，进入该书页面点击「同步本书」即可刷新。
4. 需要对照上下文原文时，可以在「设置 > 数据来源 > 微信读书」选择默认打开方式：微信读书 App、外部浏览器，或**在 Yomitomo 中打开网页版**。

选择**在 Yomitomo 中打开网页版**时，应用会区分两种查看方式：

- **小窗查看**：用于快速定位划线、跳转章节和翻页，**不会**向微信读书账号写回阅读进度；
- **展开全屏阅读**：网页版会把当前阅读位置和阅读时长写回你的微信读书账号。

网页版登录态只保存在本机独立的 session 中，可在设置中随时清除，不进入完整备份。

## 3. 导出 Markdown 与本地备份

- **导出 Markdown**：在任意一本已同步的微信读书书籍页面工具栏中，点击导出或复制 Markdown，即可按章节拿到该书的全部划线与想法，方便带入 Obsidian、Logseq、Notion 等工具（不支持自动双向同步）。
- **本地备份**：已同步的笔记保存在本机 SQLite 数据库中。在「设置 > 数据管理」中执行完整备份或仅备份数据库均可保留这些笔记；完整备份不包含微信读书 API Key、AI 模型 API Key 与微信读书网页版登录态，迁移到新电脑后需重新配置。详见[设置、模型与数据](/docs/settings/#数据备份与管理)。

## 常见问题

### 连接成功，但没有预期的书籍或笔记

先确认生成 Key 时使用的是同一个微信读书账号，并在官方 App 中检查对应书籍是否确实有划线或想法。同步范围以官方 Skill 接口返回的数据为准；没有电子书正文属于正常现象，不代表同步失败。保留错误提示，避免连续反复点击同步。

### 重置 API Key 后同步失败

将新的 Key 保存到「设置 > 数据来源 > 微信读书」并重新测试连接。不要把密钥贴到公开的问题反馈或截图里。

### 使用官方 API 是否保证账号不会受限？

Yomitomo 调用官方 Skill 接口，但无法保证账号状态、接口可用性或未来政策变化。请遵守微信读书当前规则；遇到限流或授权错误时，按官方提示处理。

### 数据会发到哪里？

同步请求发送到微信读书官方服务，已同步笔记保存在本机。如果启用了「在 Yomitomo 中打开网页版」，打开书籍或定位划线时会请求微信读书网页阅读器（全屏阅读会写回位置与时长，小窗定位不写回）。由于微信读书条目是只读视图，不会自动发送到你的 AI 模型；只有当你手动导出 Markdown 并作为本地文档导入后主动触发 AI 时，相关片段才会发往你配置的模型端点。
