微信读书凭借出色的阅读体验与丰富书库，成为了许多深度读者的主力工具。在读完数十本书、积累了数百条划线与想法后，你不可避免会面临一个痛点：**思考痕迹被锁定在封闭平台内部**。

微信读书不提供结构化的全书笔记导出。若想整理读书报告，只能零散复制粘贴；想对过去的某条想法展开长篇反驳与逻辑推演，原 App 仅支持简单的追加留言，无法跨书籍聚合，更无法引入 AI 专家深度研讨。一旦网络受限或账号变动，这些宝贵的思考痕迹便面临沦为数字孤岛的风险。

Yomitomo 基于微信读书官方 Skill 开放协议，提供了一条**本地化无损同步与深度二次加工路径**：直连官方接口拉取书籍、划线、想法与进度至本地 SQLite 数据库，让你重获阅读数据主权。

---

## 微信读书本地同步工作流

| 阶段 | 输入 (Input) | 系统处理 (System Processing) | 产出结果 (Output) | 功能边界 (Boundaries) |
|---|---|---|---|---|
| **API 授权** | 官方 WeRead Skill API Key | 本地校验并安全存储于系统 Keyring，建立直连 | 获得加密授权凭据，可拉取书架与笔记元数据 | 不收集用户微信密码或个人敏感账户信息 |
| **书籍同步** | 选择需同步的书籍条目 | 调用官方 Skill 接口增量抓取章节信息、划线高亮与个人想法 | 在本地阅读库生成独立的微信读书镜像条目 | 仅同步公开与个人笔记，不绕过版权下载加密正文全文 |
| **深度再加工** | 同步后的划线与想法 | 映射至 Yomitomo 五大认知分类，支持在讨论区 `@` AI 伴读助手 | 针对原生划线的多轮思辨记录与逻辑挑战 | AI 需配置本地或第三方大模型 API Key 驱动 |
| **知识沉淀** | 跨章节 / 跨书籍划线集 | 汇聚至沉淀工作台，提取核心论点并由审阅助手复核 | 结构化 Markdown 沉淀卡片，可导出至外部知识库 | 沉淀产物保存在本地，不反向写入微信读书云端 |

## 操作步骤：三步完成本地同步与再加工

### 第一步：获取官方 Skill API Key 并建立直连

Yomitomo 不设置任何中间服务器，所有请求均由桌面端直连微信读书官方接口。

1. 访问 <a href="https://weread.qq.com/r/weread-skills" target="_blank" rel="noopener noreferrer">微信读书 Skill 官方管理页</a>（或在手机端微信读书 App 依次点击「我 > 设置 > 微信读书 Skill」）。
2. 点击「快速配置」并扫码登录，一键生成专属 API Key。
3. 打开 Yomitomo，进入「设置 > 数据来源 > 微信读书」，粘贴 API Key 并点击「保存并测试连接」。

> 详细图文与授权排查指引可参阅 [微信读书 API Key 配置文档](/docs/weread-api-key/)。

### 第二步：按需精细化同步与认知分类

在 Yomitomo 的「微信读书」专属面板中，你可以浏览自己的全部书架，并按需勾选需要同步的书籍：

- **保留原生想法**：同步不仅导入划线高亮，还会完整拉取你在微信读书中撰写的原生即时想法。
- **赋予认知属性**：在阅读库中打开同步的书籍，选中划线按下快捷键 `A`，可为其补充五大认知标签（核心要点、隐含假设、关键概念、质疑存疑、经典金句）。
- **多轮 AI 研讨**：在划线右侧的讨论区输入 `@周砚` 审查作者论证逻辑，或输入 `@沈清源` 拆解专业术语演进。

### 第三步：跨书籍主题沉淀与导出

在 Yomitomo 中，来自微信读书的划线不再受限于单本书籍的孤岛。

按下快捷键 `T` 打开沉淀工作台，你可以跨越不同书籍调取相同主题的划线（例如同时对比 3 本商业管理书籍中的组织架构论点），将其打磨为 500 字的高密度认知卡片。随后呼叫 `@何明衡`（逻辑复核官）与 `@唐简`（终审编辑）对你的总结进行严密性把关。

## 适用对象与使用边界

### 适合以下读者

- 在微信读书中积累了大量高价值划线与个人想法，希望建立本地永久档案的深度读者；
- 需要打破单本书籍限制，跨书进行主题化研究与知识输出的研究者与创作者；
- 习惯在桌面端进行深度阅读，希望结合 AI 助手对书籍论点展开严肃辩论的读者。

### 暂不适合的情况

- **寻求免费盗版电子书下载**：Yomitomo 严格遵守微信读书官方开放协议，仅同步书籍元数据、目录、个人划线与想法，**不会非法破解或下载受版权保护的完整正文文件**；
- **需要划线反向同步回微信读书**：Yomitomo 定位为本地知识沉淀终点，在本地所做的深度批注与 AI 对话不会反向污染微信读书线上记录；
- **多设备实时在线协作**：数据完全保存在本地 SQLite 中，目前不提供中心化团队云端协作服务。

## 常见问题解答 (FAQ)

### Q1：配置微信读书 API Key 是否会导致账号被封禁？
**答：** 不会。Yomitomo 采用的是腾讯微信读书官方发布的「微信读书 Skill」开放接口（开放给开发者的合法授权协议），而不是非法的 Web 爬虫或内存注入技术。所有请求均符合官方速率与调用规范。

### Q2：微信读书同步的数据存储在哪里？如果更换电脑如何迁移？
**答：** 所有同步的书籍元数据、划线、想法与后续讨论均 100% 保存在本地 SQLite 数据库中。你可以在 Yomitomo「设置 > 通用」中随时一键导出数据库备份，并在新电脑上直接恢复。

### Q3：如果微信读书上的原书下架了，本地已经同步的划线和笔记还会丢失吗？
**答：** 不会。一旦数据成功拉取至本地 SQLite，它就成为了你的永久本地资产。即使微信读书线上书库下架该书，你在 Yomitomo 中的全部划线、想法、AI 对话及沉淀文章均不受任何影响。
