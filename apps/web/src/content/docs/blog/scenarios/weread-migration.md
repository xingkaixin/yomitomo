微信读书凭借出色的阅读体验，成为了许多深度读者的主力工具。在读完数十本书、积累了数百条划线与想法后，你不可避免会面临一个困境：**你的阅读思考被深深锁在了封闭平台内部**。

微信读书不提供结构化的全文导出功能。若想整理笔记，只能手动复制粘贴；想对过去的某条想法展开长篇反驳与追问，原 App 仅支持简单的评论追加，无法跨书籍关联，更无法自由定制排版。更令人担忧的是，一旦离开该平台，这些宝贵的思考痕迹便面临沦为「数字孤岛」的风险。

Yomitomo 基于微信读书官方 Skill 开放能力，提供了一条**本地化无损迁移路径**：将书籍、划线、想法与进度无缝同步至本地，并在更强大的深度阅读环境中继续加工。

## 第一步：绑定官方 Skill API Key，建立直连

Yomitomo 不设置任何中间服务器。数据同步基于官方 WeRead Skill 接口直连完成。

获取 API Key 仅需一分钟：
1. 访问 <a href="https://weread.qq.com/r/weread-skills" target="_blank" rel="noopener noreferrer">微信读书 Skill 官方管理页</a>（或在手机端微信读书「我 > 设置 > 微信读书 Skill」中操作）。
2. 点击「快速配置」并扫码登录，一键生成专属 API Key。
3. 将 Key 复制并粘贴至 Yomitomo 的「设置 > 数据来源 > 微信读书」中保存并测试连接。

配置完成后，所有同步请求均由本地应用直连微信读书官方接口，绝无第三方泄露风险。

## 第二步：按需精细化同步

Yomitomo 支持灵活的按需同步机制。在「微信读书」页面中，你可以根据主题挑选需要同步的书籍，拉取对应的划线、想法与阅读进度。

同步后的内容会自动融入 Yomitomo 的阅读库，与本地导入的 EPUB、PDF 和网页长文统一管理：

- **深度追注**：对同步的划线继续应用 Yomitomo 的五大认知类型（核心要点、隐含假设、关键概念、质疑存疑、经典金句）。
- **思维延伸**：在微信读书原生想法下方继续追加评论与辩论。
- **AI 智囊共读**：在讨论区 `@` 各类专业 AI 伴读助手，针对微信读书中的划线展开多维研讨。
- **跨书知识沉淀**：在沉淀窗口中跨越多本书籍聚合划线，输出专题研报。

## 第三步：重获数据主权与自由

将数据沉淀至本地后，你将获得平台无法给予的终身自由：

- **全文毫秒级检索**：在阅读库中瞬间检索所有同步书籍的正文划线与个人思考。
- **多书主题融合**：打破单本书籍限制，在沉淀窗口中将不同书籍的观点融会贯通。
- **统一数据看板**：在统计中心将微信读书阅读时长与本地思考产出合并呈现。
- **安全本地备份**：随 Yomitomo 的 SQLite 数据库进行统一备份，彻底摆脱单一平台锁死。

## 适合谁

在微信读书中积累了丰富划线与笔记，希望将阅读思考沉淀为本地终身资产、进行深度二次加工与专题输出的读者。
