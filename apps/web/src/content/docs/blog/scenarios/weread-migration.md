Yomitomo 可以通过微信读书官方 Skill API，把账号内可访问的书籍信息、划线和想法同步到电脑。你可以继续添加批注、与 AI 讨论，并把阅读记录备份到本地。**同步笔记不等于下载电子书全文，也不等于双向同步。**

本文由 Yomitomo 项目维护，根据 v0.16.2 的功能与配置整理。

## 可以同步什么？

| 内容 | 同步后的用途 | 边界 |
| --- | --- | --- |
| 书籍信息、目录和阅读进度 | 在阅读库中找到书籍及对应章节 | 以官方接口返回的数据为准 |
| 划线和个人想法 | 回看笔记，添加自己的讨论 | 不导出受保护的 EPUB/PDF 全文 |
| 在 Yomitomo 中新增的讨论和沉淀 | 保存到本地，继续整理 | 不反向写入微信读书 |

## 1. 获取并配置 API Key

打开[微信读书 Skill 官方管理页](https://weread.qq.com/r/weread-skills)，按页面提示登录并创建 API Key。将它粘贴到 Yomitomo 的「设置 > 数据来源 > 微信读书」，保存后测试连接。

[API Key 图文教程](/docs/weread-api-key/)包含网页和手机 App 两种入口，以及连接失败时的检查步骤。微信读书的凭据与 AI 模型的 API Key 是两套独立配置。

## 2. 同步并检查一本书

1. 在阅读库打开微信读书来源，点击同步。
2. 等待同步结束，打开一本你已经写过划线和想法的书。
3. 对照微信读书，检查书名、章节、划线原文和自己的想法。
4. 在已有划线的讨论区补充一条自己的笔记，确认可以在本地继续阅读和整理。

自动同步可在设置中开启；也可以保留手动同步，只在需要时拉取。使用 AI 讨论需要另外配置模型，手动查看笔记和记录想法不需要模型 API。

## 3. 保存与备份

同步数据保存在本机。在「设置 > 数据管理」中选择完整备份，可以一起备份阅读数据库和已导入的本地文件。仅备份数据库不会包含 PDF、电子书原文件。迁移后需要重新配置 API Key，详见[备份说明](/docs/settings/)。

如果需要在 Obsidian 等工具继续整理，可以手动复制自己的沉淀正文。Yomitomo 目前没有 Markdown 文件导出或外部笔记自动同步入口，原文锚点与讨论记录不会随复制自动迁移。

## 同步遇到问题怎么办？

### 连接成功，但没有预期的书籍或笔记

先确认生成 Key 时使用的是同一个微信读书账号，并在官方 App 中检查对应划线是否存在。同步范围由官方接口决定，书籍正文不可见不代表笔记同步失败。保留错误提示，避免连续反复点击同步。

### 重置 API Key 后同步失败

将新的 Key 保存到 Yomitomo 并重新测试连接。不要把密钥贴到公开的问题反馈或截图里。

### 使用官方 API 是否保证账号不会受限？

Yomitomo 使用官方 Skill 接口，但无法保证账号状态、接口可用性或未来政策。请遵守微信读书当前规则；遇到限流或授权错误时，按官方提示处理。

### 数据会发到哪里？

同步请求发送到微信读书官方服务，已同步笔记保存在本机。使用远程 AI 时，任务所需的笔记与上下文会发送到你配置的模型端点。连接本机模型时，模型推理可在本机完成。
