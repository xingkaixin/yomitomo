如今，「云端优先」已成为绝大多数软件的默认选择：文档在云端、笔记在云端、阅读数据也在云端。这一架构带来了多设备无缝同步的便利，但同时也伴随着一个鲜少被严肃讨论的代价：**你的阅读思考数据，不再真正属于你**。

阅读数据具有极其特殊的私密属性。它不同于日程表或待办事项这类公开行动记录，而是**你大脑思考过程的直接投射**：你在某段文字旁的困惑直觉、对权威论断的尖锐质疑、在两个陌生概念间建立的联想通路。这些构成了你最核心的认知底牌。将它们托管于第三方云端，意味着你默认允许服务商抓取、分析、用于大模型训练，甚至在服务关停时承受数据灭失的风险。

Yomitomo 坚定选择了一条截然不同的道路：**本地优先（Local-First）**。

## 数据主权：全部数据仅留存本地

Yomitomo 的所有数据——导入的网页文章、EPUB 电子书、PDF 论文、划线、想法、讨论历史、沉淀稿与阅读统计——均 100% 存储于你本地电脑的应用数据目录中。Yomitomo 没有用于收集用户阅读内容的中心化云端数据库。

- **无需注册登录**：下载安装即可开启使用，没有任何账号体系绑定
- **永不被动中断**：不受任何第三方平台服务条款变更或下线影响
- **天然离线可用**：即使处于飞行模式，依然能顺畅完成深度阅读与沉淀
- **零商业化分析**：没有任何算法可以窥探你的阅读偏好与思考模型

## 硬件级安全：API Key 托管于系统级 Keyring

Yomitomo 支持灵活接入外部大语言模型（如 OpenAI、Anthropic、DeepSeek 等）。但你的 API Key 绝不会明文保存在普通配置文件中。

系统严格调用操作系统底层的最高安全凭据库（macOS Keychain / Windows Credential Manager）。本地 SQLite 数据库仅保留供应商配置项与对应的密钥句柄引用。即便数据文件被意外复制，攻击者也无法提取出明文 API Key。所有模型请求均由本地客户端直连服务商接口，Yomitomo 不设任何中间代理中转。

## 离线即全能：网络只是能力的增量

主流「云端工具」在离线时往往降级为只读甚至完全白屏；而 Yomitomo 作为本地优先应用，其核心功能（文章解析、EPUB/PDF 渲染、分层批注、讨论流与知识沉淀）在完全脱网时依然 100% 可用。网络仅在唤起云端模型推理或抓取外部网页时长效增益——**网络带来的是能力的延伸，而非基础功能的枷锁**。

## 格式开放：杜绝数据孤岛与专有锁死

本地优先绝不等于脆弱。Yomitomo 内置了一键式 SQLite 数据库备份与恢复机制，支持随时导出至外部冷存储或个人受信任网盘。数据采用标准开源的 SQLite 关系型存储，绝无专有二进制封锁。即使未来不再使用 Yomitomo，你也可以使用任意通用数据库工具提取所有历史批注与沉淀稿。

从微信读书同步的书籍与笔记同样直接落入本地 SQLite，彻底摆脱对特定阅读平台的长期依赖。

## 思想自由：在无监督的私密空间中深度思考

阅读是一场极其私密的灵魂对话。你所记录的幼稚疑问、困惑反思与尚未成熟的假说，绝不该暴露于任何云端商业分析看板之下。

只有在绝对安全的本地空间中，你才能卸下防备，坦然直面自己的认知盲区——而这正是深度认知进阶不可或缺的前提。如果潜意识里意识到每一处划线都可能被抓取或泄露，人就会下意识进行「自我审查」，写下言不由衷的平庸笔记。

保护思考的私密性，就是保护思想的独立性。
