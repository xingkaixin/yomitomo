如今，多数阅读与笔记软件默认采用“云端优先”架构：文档、划线和笔记都存放在服务商的服务器上。这种方式换来了多端即时同步，但也带来长期隐患——阅读记录高度私人化，里面包含你对一段文字的困惑、质疑和思考；一旦托管在第三方云端，就要面对服务策略变动、涨价、停服或数据导出受限的风险。

Yomitomo 选择**本地优先（Local-First）**：核心阅读数据留在你的电脑上，网络只用于你明确触发的外部任务和少量公开基础请求。

## 本地存储与数据边界

| 数据类别             | 存储位置                                                                                     | 备份与迁移说明                                    | 边界说明                                           |
| -------------------- | -------------------------------------------------------------------------------------------- | ------------------------------------------------- | -------------------------------------------------- |
| **阅读库与原文件**   | 本地 SQLite 数据库及应用数据目录（网页正文与图片、EPUB/AZW3/MOBI、PDF 原文件与缩略图、文本） | 「设置 > 数据管理」支持完整备份或仅备份数据库     | 无 Yomitomo 账号与云端内容库                       |
| **批注、讨论与沉淀** | 本地 SQLite 数据库                                                                           | 随数据库备份保存；内置导出/复制 Markdown（`.md`） | 离线可读写、检索和编辑；不修改原始 PDF/电子书      |
| **助手会话缓存**     | 应用数据目录 `assistant-sessions/`                                                           | 可重建缓存，不进完整备份，删除文章时一并删除      | 用于保存每位助手在单篇文章中的对话与审阅上下文     |
| **API Key 凭据**     | 操作系统凭据库（macOS Keychain / Windows Credential Manager）                                | 不进完整备份，迁移设备后需重新配置                | SQLite 仅保存供应商配置与引用，不存明文密钥        |
| **阅读记忆模型**     | 应用数据目录（用户主动下载 `embeddinggemma-300m-ONNX`）                                      | 不进完整备份，新设备可重新下载                    | 仅索引本地文章已保存的划线、想法、讨论和已发布沉淀 |

## 哪些情况会有数据离开本机

本地优先不等于应用永远断网。为避免误解，以下是 Yomitomo（v0.18.2）全部可能发生外发请求的场景：

| 去向                                        | 触发条件                                                                                                | 外发内容                                                                                                                                                                 |
| ------------------------------------------- | ------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **你配置的 LLM / 翻译供应商**               | 触发 `@助手`、「让助手来」、「问一问」、沉淀审阅、「问书库」或 PDF 双语翻译                             | 完成该任务所需的选中文本、上下文、批注或评论，以及助手在本文的会话历史；连接本机 Ollama 时推理在本机完成                                                                 |
| **网页导入的目标站点**                      | 在阅读库导入网页 URL                                                                                    | 普通页面请求（用于抓取正文与可选保存图片）                                                                                                                               |
| **微信读书 API 与可选应用内网页版**         | 配置微信读书 API Key 同步；或在「设置 > 数据来源 > 微信读书」启用「在 Yomitomo 中打开网页版」后打开书籍 | Skill API 同步请求；启用网页版时发送网页阅读器页面请求与登录态（小窗定位不写回进度，展开全屏阅读会写回位置与阅读时长；登录态仅存本机独立 session，可清除，不进完整备份） |
| **ModelScope / Hugging Face**               | 用户明确点击下载本地阅读记忆模型                                                                        | 固定版本模型文件下载请求，不含阅读内容                                                                                                                                   |
| **`download.yomitomo.app`、`yomitomo.app`** | 检查与下载应用更新                                                                                      | 更新 manifest、安装包与更新说明请求                                                                                                                                      |
| **`telemetry.yomitomo.app`**                | 默认开启，可在「设置 > 通用 > 隐私」关闭                                                                | 每天最多一次匿名 heartbeat（安装标识、版本、平台与系统信息）；阅读记忆动作计数（不含安装标识）。**不包含任何阅读内容**                                                   |
| **`models.dev`**                            | 启动后及每 24 小时检查（本地价格缓存过期时）；不受遥测开关控制                                          | 获取公开模型价格目录的 GET 请求，用于「助手用量」花费估算。**不包含阅读内容、API Key 或安装标识**                                                                        |

## 本地优先带来的四个实际好处

### 1. 无需账号，阅读资产由自己掌控

下载安装后即可直接使用，没有账号体系绑定。已导入的网页文章、EPUB/AZW3/MOBI 电子书、PDF、文本以及你的划线、想法、讨论和沉淀都保存在本地电脑中，不依赖云端服务存活。

### 2. 系统凭据库托管 API Key，直连所选端点

Yomitomo 不提供也不代理 LLM 服务。你填写的 OpenAI、Anthropic、DeepSeek、Google Gemini 或 OpenAI 兼容接口密钥，由操作系统底层凭据库保管（macOS 使用 Keychain，Windows 使用 Credential Manager），请求直接发往你配置的端点。

### 3. 核心阅读与批注离线可用

没有配置 AI、网络断开或远程模型不可用时，已导入材料的阅读、划线、写想法、本地检索和沉淀编辑照常可用；保存操作不等待 AI、向量或远程请求。如果你同时配置了本机 Ollama 模型，也可以在离线状态下继续进行 AI 伴读。

### 4. 格式开放，可备份也可带走

应用数据存放在标准 SQLite 数据库中，同时内置**导出 Markdown（`.md`）**与**复制 Markdown** 功能，支持导出整篇文档笔记、单条沉淀、微信读书章节笔记和「问书库」回答。在「设置 > 数据管理」中，你可以按需创建完整备份或仅备份数据库。

## 适用对象与使用边界

### 适合的读者

- 看重阅读数据长期可控、不愿被云端账号或订阅制绑定的读者；
- 需要处理内部材料或未公开文档、希望明确知道哪些请求会离开本机的专业从业者；
- 自备 API Key 或使用本机 Ollama 模型进行阅读与研究的桌面端用户。

### 暂不适合的情况

- **多人实时在线协作**：Yomitomo 面向个人阅读与思考，不支持多人协同批注；
- **多设备云端实时同步**：目前没有内置云同步服务，跨电脑迁移通过本地备份还原完成；
- **免配置内置云端算力**：Yomitomo 不转售模型套餐，需要自行填写 API Key 或配置本地模型。

## 常见问题解答 (FAQ)

### Q1：换电脑时如何迁移全部数据？

**答：** 在「设置 > 数据管理」中创建**完整备份**，将备份文件夹复制到新电脑后还原即可。完整备份包含 SQLite 数据库、电子书与 PDF 原文件、PDF 缩略图；不包含 API Key、应用锁、`assistant-sessions/`、本地阅读记忆模型和微信读书网页版登录态，还原后按需重新配置或下载即可。详见[设置、模型与数据](/docs/settings/#数据备份与管理)。

### Q2：我的 API Key 会经过 Yomitomo 的服务器吗？

**答：** 不会。Yomitomo 不中转任何模型请求。API Key 保存在本机系统凭据库中，调用远程模型时由客户端直接发送到你配置的端点。

### Q3：如果将来不再使用 Yomitomo，我的笔记还能打开吗？

**答：** 可以。除了在应用内直接导出 Markdown 文件外，你的批注、讨论和沉淀都保存在标准 SQLite 数据库中，可用任意 SQLite 工具读取；电子书和 PDF 原文件也以原格式存放在本地数据目录中。
