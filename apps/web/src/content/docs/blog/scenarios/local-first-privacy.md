如今，「云端优先」已成为绝大多数阅读与笔记软件的默认选择：文档在云端、划线在云端、阅读数据也在云端。这一架构带来了多设备即时同步的便利，但同时也伴随着一个鲜少被严肃讨论的代价：**你的阅读思考数据，不再真正属于你**。

阅读数据具有极其特殊的私密属性。它不同于公开的社交动态或协同看板，而是**你大脑思考过程的直接投射**：你在某段文字旁的困惑直觉、对权威论断的尖锐质疑、在两个陌生概念间建立的联想通路。将它们托管于第三方云端，意味着你默认允许服务商抓取、分析、用于大模型训练，甚至在服务关停时承受数据灭失的风险。

Yomitomo 坚定选择了一条截然不同的道路：**本地优先（Local-First）**。

## 本地优先架构与数据流

| 核心组件 | 输入与操作 (Input) | 系统内部处理 (System Processing) | 存储与输出 (Output) | 安全与数据边界 (Boundaries) |
|---|---|---|---|---|
| **文章与文档库** | 导入 EPUB、PDF 或抓取网页长文 | 本地解析提取，并持久化到本地文件系统 | 本地 SQLite 关系型数据库 | 零云端中转服务器，无中心化数据库收集用户内容 |
| **批注与思考链** | 划线高亮（`A`）、记录想法、发起讨论 | 建立段落/文本锚点，关联五大认知分类与讨论时间线 | 本地结构化知识图谱与毫秒级全文检索索引 | 完全支持脱网运行，无网络亦可自由检索与编辑 |
| **AI 模型凭据** | 自定义模型 API Key（OpenAI / Claude / DeepSeek / Ollama） | 调用系统底层 Keyring（macOS Keychain / Windows Credential Manager）加密托管 | 本地 SQLite 仅保留配置项与 Key 句柄引用 | 本地客户端直连模型服务商，绝不经由中间代理 |
| **知识沉淀与备份** | 汇聚划线提炼 Markdown 沉淀卡片 | 一键生成标准 SQLite 数据库冷备份与 Markdown 导出 | 本地 `.sqlite` 文件与标准 Markdown 文档 | 数据采用标准格式，无专有二进制封锁，终身可迁移 |

## 本地优先给深度阅读者带来的四大核心保障

### 1. 数据主权：全部数据 100% 留存本地电脑

Yomitomo 的所有数据——导入的网页文章、EPUB 电子书、PDF 论文、划线、想法、讨论历史、沉淀稿与阅读统计——均保存在本地应用目录中。

- **无需注册与登录**：下载安装即可开启完整使用，没有任何账号体系绑定；
- **永不被动中断**：不受任何第三方平台服务条款变更、运营策略调整或服务器停机下线影响；
- **零商业化广告与分析**：没有任何追踪探针窥探你的阅读偏好与思考模型。

### 2. 硬件级凭据安全：API Key 托管于系统级 Keyring

Yomitomo 支持灵活接入任意兼容 OpenAI 规范的大语言模型或本地推理引擎（如 Ollama）。你的 API Key 绝不会明文保存在普通 JSON 或配置文件中。

系统严格调用操作系统底层的最高安全凭据库：
- macOS 环境：自动写入系统 **Keychain（钥匙串）**；
- Windows 环境：自动写入 **Credential Manager（凭据管理器）**。

本地 SQLite 仅保留供应商元数据与对应的密钥句柄。即便数据文件被意外复制，攻击者也无法提取出明文 API Key。所有模型请求均由本地客户端直连服务商接口，绝无第三方代理截获请求体。

### 3. 离线即全能：网络只是能力的增量，而非基础的枷锁

主流云端工具在网络中断时往往降级为只读甚至完全白屏。而 Yomitomo 作为本地优先应用，其核心功能（文章解析、EPUB/PDF 渲染、分层批注、讨论流与知识沉淀）在完全脱网时依然 100% 可用。

网络仅在你唤起云端模型推理或抓取外部网页时发挥作用。若配合本地 Ollama 运行开源大模型，你甚至可以在机舱或高铁等无网环境下完成完整的「离线 AI 伴读与沉淀」。

### 4. 格式开放：杜绝数据孤岛与专有锁死

本地优先绝不等于封闭脆弱。Yomitomo 内置了一键式 SQLite 数据库备份与恢复机制，支持随时导出至外部冷存储或个人受信任网盘（如 iCloud、Dropbox、坚果云）。

数据采用标准开源的 SQLite 关系型存储，绝无专有二进制封锁。即使未来不再使用 Yomitomo，你也可以使用任意标准数据库工具提取所有历史批注与沉淀稿。

## 适用对象与使用边界

### 适合以下读者

- 对阅读隐私、商业机密和思考记录安全性有极高要求的学者、律师、分析师、开发者与知识工作者；
- 厌倦了各类 SaaS 工具频繁改版、提价、服务关停与数据锁死的理性用户；
- 经常在离线或弱网环境（旅途、机舱、涉密办公区）进行深度阅读的研究人员；
- 拥有自备 API Key 或本地大模型（Ollama / vLLM）的高级玩家。

### 暂不适合的情况

- **多人实时协作编辑同一篇文章**：Yomitomo 定位为个人专属的深度思考与知识沉淀工具，暂不支持多用户在线协同打标与评论；
- **一键免配置开箱即用的内置云端模型**：Yomitomo 不在云端转售算力包，用户需在设置中填入自己的 API Key 或连接本地大模型。

## 常见问题解答 (FAQ)

### Q1：本地优先是否意味着多台电脑无法同步数据？
**答：** 目前 Yomitomo 提供了标准的 SQLite 数据库备份与恢复功能。你可以将导出的数据库文件放入个人受信任的网盘（如 iCloud Drive、Dropbox、Syncthing），在另一台电脑上一键导入还原。

### Q2：我填写的 OpenAI / DeepSeek API Key 会被 Yomitomo 的开发者获取吗？
**答：** 绝不会。Yomitomo 是一个纯桌面客户端，没有用于中转 LLM 请求的云端服务器。API Key 直接保存在你本机的系统安全凭据库中，发起的每一次 AI 请求均由你的电脑直接向大模型官方端点建立 HTTPS 加密连接。

### Q3：如果 Yomitomo 停止更新，我的笔记数据还能打开吗？
**答：** 完全可以。所有数据均存储在标准的 SQLite 数据库文件中，划线和沉淀内容均为明文或标准 Markdown 格式。你可以使用任何通用的 SQLite 查看工具或脚本完整导出所有数据。
