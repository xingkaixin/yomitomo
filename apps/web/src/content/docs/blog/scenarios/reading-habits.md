“这个月我到底认真读进去了多少内容？”——靠感觉回想通常不准。翻过多少页、窗口挂了多久，并不代表真的留下了思考；更有参考价值的信号，往往是你实际记下了多少划线和想法、把多少讨论整理成了沉淀，以及这种节奏是否连续。

Yomitomo 的「统计」面板按**本地阅读**、**助手用量**和**微信读书**分开呈现，帮你从真实记录里看清自己的阅读状态，而不是只看一个笼统的在线时长。

## 统计面板包含哪些指标

| 模块             | 记录内容                                             | 呈现形式                                                                                       | 用途                                               |
| ---------------- | ---------------------------------------------------- | ---------------------------------------------------------------------------------------------- | -------------------------------------------------- |
| **本地阅读统计** | 每日与累计的 `沉淀`、`想法`、`划线`、`助手参与` 次数 | 顶部计数卡片 + **21 天活动趋势**（`沉淀` / `想法` / `划线`）+ **7 天徽章** + **70 天阅读地图** | 观察是否只划线不写想法、是否保持连续阅读与沉淀节奏 |

## 本地阅读：记录真实的思考动作，而非屏幕挂机时长

Yomitomo 的本地阅读统计**不记录阅读时长或焦点计时**，也没有闲置暂停计时器。它聚焦在你能亲手留下的阅读动作上：

- **每日与累计统计**：分别展示 `沉淀`、`想法`、`划线` 和 `助手参与` 的今日数量与历史累计；
- **21 天活动趋势**：把近三周的 `沉淀`、`想法`、`划线` 变化放在同一视野下。如果某段时间划线很多、但想法和沉淀几乎为零，说明最近更偏向浅层扫读，可以刻意放慢节奏、多写几句自己的判断；
- **7 天徽章与 70 天阅读地图**：以热力方阵直观呈现过去 70 天的活跃轨迹，方便一眼看出阅读节奏何时稳定、何时中断。

## 助手用量：看清模型调用与估算花费

采用自备 API Key（BYOK）时，很多读者担心高频伴读不知不觉花掉过多额度。「统计」中的**助手用量**视图会汇总：

- 总调用次数与 Token 消耗；
- 基于 `models.dev` 公开模型价格目录计算的估算花费；
- 按助手维度的使用分布，方便了解自己最常依赖哪些伴读或审阅角色，从而在「设置 > 模型与路由」里合理分配默认模型与按任务覆盖模型。

## 微信读书统计：把通读时长与本地精读对照看

在「设置 > 数据来源 > 微信读书」配置官方 Skill API Key 后，可以在「统计 > 微信读书」标签页查看微信读书侧的阅读时长统计。

这两组数据天然互补：**微信读书**记录你在手机、墨水屏或网页端投入的阅读时长，**本地阅读统计**记录你在桌面端实际产出的划线、想法、讨论与沉淀。对照两者，更容易判断自己的时间投入是否转化为了真正消化的思考。

## 适用对象与使用边界

### 适合的读者

- 希望通过连续 21 天趋势与 70 天阅读地图维持稳定精读习惯的读者；
- 想检查自己是否陷入“只划线不写想法、不沉淀”状态的深度学习者；
- 使用自备云端 API、希望随时掌握 Token 与估算花费的用户；
- 同时使用微信读书和 Yomitomo，想在同一应用里查看微信读书阅读时长的用户。

### 暂不适合的情况

- **需要精确记录桌面端阅读秒表时长**：本地阅读统计不追踪屏幕停留或专注时长，只有「统计 > 微信读书」展示微信读书侧的阅读时长；
- **社交打卡与排行榜**：统计数据保存在本地，没有公开排行榜或社交分享广场。

## 常见问题解答 (FAQ)

### Q1：我的阅读统计数据会上传到云端吗？

**答：** 不会。你的划线数、想法数、沉淀数、70 天阅读地图和助手用量记录都保存在本地 SQLite 数据库中，不会上传到任何服务器。需要说明两项独立的基础网络行为：应用默认开启可在「设置 > 通用 > 隐私」关闭的匿名遥测（仅发送每天最多一次基础 heartbeat 及不含安装标识的阅读记忆动作计数，不包含任何阅读内容或统计明细）；另外应用会在启动及每 24 小时从 `models.dev` 拉取公开的模型价格目录用于估算花费（不含阅读内容、API Key 或安装标识）。

### Q2：为什么本地阅读统计不记录阅读时长？

**答：** 屏幕停留在文档页面并不等于正在思考，后台挂机或切窗查资料很容易让时长失真。因此 Yomitomo 的本地统计直接聚焦在真实留下的思考动作（`划线`、`想法`、`沉淀`、`助手参与`）上；如果你想追踪微信读书上的阅读时长，可以切换到「统计 > 微信读书」查看。

### Q3：换电脑后，70 天阅读地图和历史统计还在吗？

**答：** 在。只要在旧电脑的「设置 > 数据管理」中创建备份（完整备份或仅备份数据库），并在新电脑还原，历史统计计数和 70 天阅读地图都会随之恢复。
