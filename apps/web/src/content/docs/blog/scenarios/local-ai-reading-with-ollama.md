Yomitomo 可以通过 OpenAI 兼容接口连接本机 Ollama。把 Base URL 设置为 `http://localhost:11434/v1`，选择已下载的本地模型，并将它分配给阅读任务，即可围绕原文划线与本地 AI 讨论。

本文由 Yomitomo 项目维护，根据 v0.18.2 的配置和 [Ollama 官方兼容接口文档](https://docs.ollama.com/api/openai-compatibility)整理，不是硬件性能实测报告。

## 1. 准备本地模型

从 [Ollama 官网](https://ollama.com/)安装应用，在联网时下载模型。例如：

```bash
ollama pull qwen2.5:7b
ollama run qwen2.5:7b
```

这个模型标签只是配置示例。能否运行、生成速度和内存占用取决于模型大小、量化方式、上下文长度与硬件。先在 Ollama 中确认模型可以正常回答，再配置阅读器。

若希望在本机推理，应选择已下载的本地模型。连接地址是 localhost，并不代表选中的模型一定在本地运行；不要把 Ollama 云端模型当作离线模型。

## 2. 配置 Yomitomo

在「设置 > 模型与路由」添加供应商，选择一个 **OpenAI 兼容（OpenAI compatible）** 预设（例如 OpenAI），自定义 Base URL 与模型名称：

| 字段     | 示例值                              |
| -------- | ----------------------------------- |
| 名称     | Ollama 本地                         |
| Base URL | `http://localhost:11434/v1`         |
| API Key  | `ollama`，作为本地服务的占位值      |
| 模型     | 已安装的完整标签，例如 `qwen2.5:7b` |

获取模型列表或手动添加模型，测试连接后保存。将它设为默认模型，并检查「按任务单独设置」，确保「阅读理解助手」「深度审阅助手」和「双语对照翻译」没有继续指向远程供应商。工具调用与结构化审阅建议的效果取决于所选本地模型的能力。

## 3. 用一段原文验证

导入一份有文字层的 PDF 或无 DRM 的 EPUB / AZW3 / MOBI 电子书。选中一段文字，按默认快捷键 `A` 创建划线并记录想法，在讨论区通过 `@` 选择阅读理解助手（如 `@周砚` 或 `@林知微`），问一个可以对照原文的问题。例如：“作者的结论依赖哪些前提？”

先用普通材料验证结果，再决定是否适用于自己的资料。无文字层的扫描 PDF 需先在其他工具中完成 OCR。操作说明见[阅读器、批注与讨论](/docs/reader/)。

## 离线范围与数据去向

提前导入的文件、手动批注以及已下载且兼容的本地模型，可以用于离线阅读和讨论。使用前先完成应用和模型的下载，再断开网络验证实际需要的任务。

网页导入、微信读书同步、检查更新与阅读记忆模型下载需要网络。应用还有可在「设置 > 通用 > 隐私」中关闭的匿名使用指标（每天最多一次匿名 heartbeat 与不含安装标识的阅读记忆动作计数，不含阅读内容），并会在启动及每 24 小时从 `models.dev` 获取公开的模型价格目录（不受遥测开关控制）。配置本地 AI 不会关闭这些功能，也不等于电脑已经物理隔离。若某个任务仍使用远程模型，相关原文和对话会发送到那个端点。详见[设置、模型与数据](/docs/settings/)。

## 常见问题

| 问题                                   | 检查方式                                                                             |
| -------------------------------------- | ------------------------------------------------------------------------------------ |
| 连接被拒绝                             | 确认 Ollama 正在同一台电脑运行，端口与 Base URL 一致。                               |
| 找不到模型                             | 核对完整模型标签，包括冒号后的规格。                                                 |
| 响应很慢或内存不足                     | 换更小的模型、缩短上下文，并关闭占用内存的程序。                                     |
| 普通问答成功，但正文检索或沉淀审阅异常 | 部分轻量本地模型对工具调用或结构化输出支持较弱，可换用能力更强的本地模型重试。       |
| 请求仍发往远程服务                     | 检查默认模型和所有按任务单独覆盖的设置（阅读理解助手、深度审阅助手、双语对照翻译）。 |

本地推理可能消耗较多电量、内存和 GPU 资源，不能保证固定生成速度或轻微发热。
