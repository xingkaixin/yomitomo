合同条款、券商研报、技术白皮书和政策文件大多以 PDF 形式流转，动辄几十页，包含密集的数据表格、条款定义和图表。普通 PDF 阅读器只提供高亮和便签，读完后想整理待确认条款、核对论证逻辑或跨多份报告对比结论，往往还是得来回切窗口手工摘抄。

Yomitomo 把 PDF 阅读、原文锚点批注、AI 伴读讨论、单条沉淀审阅和跨文档阅读记忆整合在同一套本地桌面工作流里。

## 兼顾图表、排版与外文研报的阅读细节

- **原色保护与深色护眼滤镜**：研报和白皮书里常有彩色走势图和表格，强制反色会导致图例失真。Yomitomo 在暗色主题下默认保留 PDF 原始页面配色；如果长时间阅读纯文字页面，也可以按需开启**深色护眼滤镜**。
- **灵活缩放与文内查找**：提供 `适应宽度`、`适应整页`、`100%` 三种缩放预设，配合 `⌘/Ctrl + / − / 0` 微调比例；按 `⌘F / Ctrl+F` 可在当前 PDF 正文内搜索关键词。
- **单栏文本双语翻译**：阅读英文白皮书或海外研报时，单栏文本 PDF 支持逐页开启**双语翻译**，对照原文核查关键定义与数据。

## 用自定义颜色和原样想法记录条款判断

选中合同条款或研报数据段，点击「划线」快速标记，或按 `A` 记下第一反应。你可以为不同性质的划线设置不同颜色——例如区分责任条款、关键前提与待澄清的矛盾表述——把需要向对方或团队确认的问题直接写在「想法」中。

所有想法都原样保存，不会被后台自动改写，后续随时可以对照原句检查。

## 伴读追问与沉淀审阅的分工

面对复杂条款或长篇行业报告，可以把两个环节分开使用：

1. **在划线讨论区用阅读理解助手拆解原文**：
   - `@周砚`（根因审读者）：追问研报中的增长预测或因果推论是否依赖未明言的前提；
   - `@顾行简`（结构领航员）：厘清某一节在全文论证或协议框架中的位置；
   - `@沈清源`（概念翻译员）：辨析专业术语、财务口径或定义边界；
   - `@许问渠`（追问导师）：把模糊的疑虑整理成面向业务方或律师的具体问题。
2. **在单条划线的沉淀窗口用审阅助手复核结论**：
   - 当你把某条重要条款的讨论整理成待办意见或备忘录段落时，点击「把这些想法沉淀下来」，在右侧审阅面板选用 **苏定白**（风险审查员）、**梁证言**（证据司书）、**何明衡**（逻辑复核官）、**唐简**（终审编辑）、**叶听澜**（读者权益官）或 **夏归宁**（行动校准师）。
   - 审阅建议以 Git-diff 内联方式展示，支持逐条「保留」或「放弃」。

> 注意：审阅助手只在沉淀窗口右侧审阅面板中选用，不能在划线讨论区中 `@` 提及。

## 跨多份 PDF 做对比与导出

当你要同时对照多份竞品研报或几版合同时，把它们归入同一个**合集（Collection）**：

- 阅读新文档时，选中条款点击「查找关联」，直接检索其他 PDF 中已保存的相关划线、想法与沉淀；
- 打开「阅读记忆 > 问书库」，将范围限定在该合集或指定几份 PDF，提出跨文档对比问题，获得附带原文引用的回答，并可直接复制为 Markdown；
- 在单份 PDF 的阅读器工具栏中，也可以直接**导出 Markdown（`.md`）**或**复制 Markdown**，导出整份文档的全部划线、想法、讨论和已发布沉淀，用于会议讨论或归档。

## 适用对象与使用边界

### 适合的读者

- 需要细读商业合同、尽调材料、券商研报、技术白皮书与政策文件的法务、投资人、分析师和咨询顾问；
- 需要对照英文原版技术文档和论文做批注与双语阅读的研发人员；
- 希望把未公开文档留在本地、明确控制哪些片段发给模型端点的专业用户。

### 暂不适合的情况

- **PDF 表单填写、电子签章或页面编辑**：Yomitomo 专注阅读、批注与思考整理，不替代 Acrobat 等 PDF 编辑软件；
- **未做 OCR 的纯图片扫描件**：无文字层的扫描 PDF 无法选字、划线或翻译，需先用 OCR 工具生成文字层。

## 常见问题解答 (FAQ)

### Q1：导入的保密研报或商业合同会上传到 Yomitomo 服务器吗？

**答：** 不会。PDF 原文件、批注和讨论都保存在本机。只有在你主动触发 AI 伴读、沉淀审阅、「问书库」或双语翻译时，完成该任务所需的原文片段和上下文才会发送到你配置的模型端点；如果连接本机 Ollama 等本地模型，推理也在本机完成。

### Q2：可以导出带高亮标记的原版 PDF 文件吗？

**答：** 目前不支持导出带批注涂层的 PDF，因为批注存在本地 SQLite 中，不会修改原始 PDF 文件。你可以随时使用内置的**导出 Markdown（`.md`）**或**复制 Markdown** 导出整份文档的批注、讨论和已发布沉淀，或通过「设置 > 数据管理」创建完整备份，将数据库和原始 PDF 一并保存。

### Q3：为什么暗色模式下 PDF 默认不强制反色？

**答：** 研报与白皮书常包含彩色图表、热力图和截图，直接反色会让颜色与图例失真。Yomitomo 默认保留原页配色；如果阅读纯白底黑字文档时觉得刺眼，可以在阅读器内手动开启**深色护眼滤镜**。
