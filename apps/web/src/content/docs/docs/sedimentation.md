---
title: 沉淀与审阅
description: 将划线讨论提炼为高质量沉淀稿，借助审阅助手的结构化反馈逐条校验、预览与采纳。
---

知识沉淀是将围绕某处划线积累的分散想法，提炼为一份可长期保留的逻辑判断、分析框架、关键追问或行动清单。沉淀稿始终锚定在原文坐标上，方便你随时重返证据现场继续推演，彻底告别脱离上下文的碎片笔记。

## 开启沉淀窗口

在批注卡片上进入讨论区后，点击「沉淀」即可打开独立工作窗口。窗口左侧为沉淀稿编辑区，右侧为审阅助手协作区。

沉淀稿既支持自主手写编辑，也可借助审阅助手一键整理讨论并生成修改建议。每条沉淀稿具有两种状态：

- **草稿**：用于构思、推演与持续打磨。
- **已发布**：发布后，沉淀稿将替代侧边栏中的原始划线展示；取消发布可随时恢复原始划线与完整的审阅记录。

## 审阅协同流程

在右侧审阅区选择一位审阅助手并提交审阅请求。助手会输出高度结构化的专业评估，而非泛泛的文本段落：

- **综合评价**：对沉淀稿的整体质量给出明确结论（如「论据扎实」「存在逻辑缺口」「建议补充论证」）。
- **分类审阅意见**：按**证据支撑**、**逻辑推演**、**内容完备性**、**表达清晰度**与**行动可操作性**分门别类列出具体问题，标注重要度并精准引用草稿对应句子。
- **改动提议**：生成可直接作用于正文的修改建议，涵盖新增、修改与删除三类操作。

审阅反馈采用流式生成，无需等待即可实时阅读分析。

## 提议校验机制

所有改动提议在采纳前，系统都会与当前草稿进行精确的坐标和文本比对，杜绝误改与位置偏差。常见异常均有清晰提示：

- 目标文本在当前草稿中未找到，或存在多处匹配需人工确认。
- 提议新增的内容在草稿中已存在。
- 提议基于历史版本生成，原锚点已被大幅修改。

确保每条建议要么精准应用到目标位置，要么明确提示需手动调整。

## 变更内联预览

点击修改建议上的「预览变更」，可在沉淀稿中以 Git Diff 风格实时预览效果：新增内容高亮显示为绿色，删除内容标记为红色删除线，草稿临时转为只读保护状态。

预览支持**逐条独立处理**：每项变动均可单独点击「保留」或「放弃」。若单批建议中存在文本交叉冲突，系统会贴心提示进行局部微调。

## 一键整理讨论

点击「整理讨论」后，审阅助手会通读划线原文、你的历史想法与全部讨论记录，智能提炼出可直接并入沉淀稿的新增要点。该功能仅生成「新增建议」，绝不擅自覆盖或删改已有草稿。

整理完毕后，你可以逐条审阅提议，并通过预览确认后安全写入草稿。

## 智能锚点指示

在审阅意见或整理提议上悬停或聚焦时，沉淀稿中对应的目标段落会实时高亮提示，让你在采纳前看清变更落点。若生成建议后草稿被修改，系统会以警示色提醒锚点可能已发生偏移。
