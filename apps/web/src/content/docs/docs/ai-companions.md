## 在阅读流中调用助手

阅读过程中，可通过三种方式唤起助手协同：

1. **选区划线启发**：选中原文并创建划线，助手会基于当前选区自动补充思考视角。
2. **讨论区 `@` 追问**：在划线讨论区输入 `@助手名称`，邀请对应专业角色的助手加入多轮讨论。
3. **沉淀审阅校验**：在沉淀窗口中选择审阅助手，对沉淀稿进行结构化校验并生成修改建议。

助手的所有产出均根植于具体上下文与已有讨论，绝不生成脱离文本现场的空泛套话。

## 上下文感知范围

助手在生成想法、回复或审阅意见时，会动态参考：

- 当前段落与周边句子的完整上下文
- 你已记录的批注、疑问与历史讨论
- 前序阅读积累的长期记忆
- 全书/全文的目录树与逻辑框架

对于 EPUB 电子书，还支持自定义防剧透范围：仅当前选区、当前章节、已读范围或全书上下文。
