设置中心负责应用各层面的全局偏好：界面多语言、外部模型服务商、主题与反馈音效、应用锁密码、键盘快捷键、本地数据备份与自动更新。

## 模型供应商配置

Yomitomo 支持主流预设供应商以及任意兼容 OpenAI 接口规范的自定义服务商。配置过程清晰轻量：先选定服务商协议，再补充连接参数与模型列表。

内置预设服务商包括：

- OpenAI
- Anthropic
- Google Gemini
- DeepSeek
- 阿里云百炼 (DashScope)
- Moonshot (Kimi)
- 智谱 GLM
- 火山引擎 (豆包)
- 小米 MiMo

选择服务商后，输入自定义名称、API Base URL 和 API Key。填入 Key 后点击「获取」，系统将自动从服务端拉取最新的可用模型列表；若网络受限，也可直接使用预设的常用模型。支持对模型进行增删改查，并可隐藏不常用的预设模型。

API Key 由操作系统原生底层保管：macOS 存储于钥匙串（Keychain），Windows 存储于凭据管理器（Credential Manager）。Yomitomo 仅在本地记录配置元数据和密钥引用，绝不明文落盘。

## 微信读书数据源

微信读书笔记同步需要配置官方 Skill API Key（详见「[获取微信读书 API KEY](/docs/weread-api-key/)」）。

配置完成后，可选择同步工作模式：

- **手动同步**：仅在阅读库点击「同步微信读书」时触发拉取。
- **自动同步**：应用启动时自动同步一次，随后在后台以 30 分钟为周期静默同步。若上次同步仍在进行，将自动顺延，避免并发冲突。

## 任务智能路由

先选择一个默认模型，用于阅读理解、深度审阅和双语翻译。需要不同模型时，再展开「按任务单独设置」；各任务也可以继续使用默认模型。

| 任务场景     | 主要职责                               |
| ------------ | -------------------------------------- |
| 阅读理解助手 | 划线即时思考、`@` 讨论回复与文本答疑   |
| 深度审阅助手 | 沉淀稿的证据核实、逻辑复核与表达优化   |
| 双语对照翻译 | 网页文章的段落级流式翻译与刷新         |

「助手执行模式」支持全局切换：**快速回应**优先低延迟输出，**深入查证**则允许助手调用工具进行多步推理核验后再行作答。

## 多语言与界面外观

- **语言切换**：在「设置 > 通用」中可即时切换简体中文、English 与日本語，界面文案与助手人设会自适应调整。
- **主题与纸张**：侧边栏主题入口按亮色、暗色分类展示主题，包含 ShadLingo 明暗主题。主题卡片提供书库示例，纸张卡片提供阅读器示例，支持纯白、深蓝等纸色。同一分类内切换主题时，自选纸色会保留，主题默认纸色会随主题变化；切换明暗分类会恢复该分类记住的主题和纸张。暗色模式下，PDF 保留原始页面颜色。
- **反馈音效**：支持调节或关闭交互音效（导入成功、删除确认、高亮标记、沉淀发布、解锁及助手输入打字音）。

## 应用安全与隐私

- **模型请求**：使用远程 AI 时，任务所需的原文、批注和对话会发送到你配置的模型端点。连接本机模型时，推理在本机完成。
- **应用锁（PIN 码）**：开启后，闲置或重新进入应用时需输入 PIN 码验证。验证材料由系统安全钥匙串托管。
- **匿名遥测控制**：默认仅发送基础运行心跳（匿名 ID、应用版本、OS 架构），绝不包含任何书籍、文章、划线、思考与 AI 聊天记录。可在设置中一键彻底关闭。

## 数据备份与管理

升级前请备份数据。v0.16.3 将数据库升级至 reader level 4，升级后 v0.16.2 及更早版本无法打开；如需降级，须还原升级前的兼容备份。

在「数据管理」中，可以打开本地数据目录、查看运行日志，并选择完整备份或仅备份数据库。

- **完整备份**：在所选位置创建备份文件夹，包含数据库、电子书与 PDF 原文件、PDF 缩略图及文件校验清单。迁移时请保留整个文件夹。还原时先校验文件和数据库，并为当前数据保留安全备份；安装备份内容失败时回滚。
- **仅备份数据库**：保存 SQLite 文件，包含库内的批注、讨论、沉淀和设置，不包含电子书、PDF 原文件或缩略图，原文件需另行保存。

完整备份不包含 API Key，也不迁移应用锁。还原后需重新配置模型和微信读书密钥，并按需开启应用锁。本地阅读记忆模型需在新设备上重新下载。

## 阅读记忆的数据范围

阅读记忆检索你已保存的划线与想法、你参与的讨论以及已发布的沉淀，不搜索资料全文或未发布的沉淀草稿。「问书库」可选择全部资料、收藏夹或手选资料中的阅读记录。语义索引和检索在本机运行；使用 AI 判断时，所选证据与问题会发送到你配置的模型端点。

## 软件静默更新

Yomitomo 在启动后及每 24 小时后台检查更新。有新版本时，顶栏显示徽标；点击后可查看更新说明并开始下载，下载完成后可选择重启安装。

从 0.16.0 起，macOS 使用 Sparkle。旧版首次升级仍下载完整 ZIP，安装并重启后，后续版本可使用差分更新；没有适用差分或差分验证失败时回退完整包。macOS 安装包继续使用 Developer ID 签名与公证，Windows 继续使用原有更新机制。
