设置中心负责应用各层面的全局偏好：界面多语言、外部模型服务商、主题与反馈音效、应用锁密码、键盘快捷键、本地数据库备份与自动更新。

## 模型供应商配置

Yomitomo 支持主流预设供应商以及任意兼容 OpenAI 接口规范的自定义服务商。配置过程清晰轻量：先选定服务商协议，再补充连接参数与模型列表。

内置预设服务商包括：

- OpenAI
- Anthropic
- Google Gemini
- DeepSeek
- 阿里云百炼 (DashScope)
- Moonshot (Kimi)
- 智谱 GLM
- 火山引擎 (豆包)
- 小米 MiMo

选择服务商后，输入自定义名称、API Base URL 和 API Key。填入 Key 后点击「获取」，系统将自动从服务端拉取最新的可用模型列表；若网络受限，也可直接使用预设的常用模型。支持对模型进行增删改查，并可隐藏不常用的预设模型。

API Key 由操作系统原生底层保管：macOS 存储于钥匙串（Keychain），Windows 存储于凭据管理器（Credential Manager）。Yomitomo 仅在本地记录配置元数据和密钥引用，绝不明文落盘。

## 微信读书数据源

微信读书笔记同步需要配置官方 Skill API Key（详见「[获取微信读书 API KEY](/docs/weread-api-key/)」）。

配置完成后，可选择同步工作模式：

- **手动同步**：仅在阅读库点击「同步微信读书」时触发拉取。
- **自动同步**：应用启动时自动同步一次，随后在后台以 30 分钟为周期静默同步。若上次同步仍在进行，将自动顺延，避免并发冲突。

## 任务智能路由

支持根据不同任务的认知复杂度，灵活分配性价比最高的模型：

| 任务场景     | 主要职责                               |
| ------------ | -------------------------------------- |
| 阅读理解助手 | 划线即时思考、`@` 讨论回复与文本答疑   |
| 深度审阅助手 | 沉淀稿的证据核实、逻辑复核与表达优化   |
| 双语对照翻译 | 网页文章的段落级流式翻译与刷新         |

「助手执行模式」支持全局切换：**快速回应**优先低延迟输出，**深入查证**则允许助手调用工具进行多步推理核验后再行作答。

## 多语言与界面外观

- **语言切换**：在「设置 > 通用」中可即时切换简体中文、English 与日本語，界面文案与助手人设会自适应调整。
- **主题与纸张**：侧边栏主题入口提供亮色、暗色、黄昏靛蓝等视觉风格，搭配水墨质感的阅读纸张材质。暗色模式下，PDF 默认保留原始白底色，确保工程图表与公式的对比度。
- **反馈音效**：支持调节或关闭交互音效（导入成功、删除确认、高亮标记、沉淀发布、解锁及助手输入打字音）。

## 应用安全与隐私

- **应用锁（PIN 码）**：开启后，闲置或重新进入应用时需输入 PIN 码验证。验证材料由系统安全钥匙串托管。
- **内网导入防护**：默认拦截指向 `localhost`、私网 IP 及云厂商元数据地址的网页抓取请求，防止 SSRF 风险；仅在确有内网知识库抓取需求时建议手动开启。
- **匿名遥测控制**：默认仅发送基础运行心跳（匿名 ID、应用版本、OS 架构），绝不包含任何书籍、文章、划线、思考与 AI 聊天记录。可在设置中一键彻底关闭。

## 数据备份与管理

在「数据管理」中，可以一键打开本地数据存储目录、查看运行日志，并执行 SQLite 数据库的完整本地备份与还原（备份不含系统钥匙串内的 API Key 与外部电子书原始文件）。

## 软件静默更新

Yomitomo 支持无感检查更新机制。启动后及每 24 小时静默检测新版本，有可用更新时仅在顶栏显示轻量徽标，绝不弹窗打断阅读。点击徽标可查看更新日志并后台下载，下载完毕后由你决定立即重启或下次退出时生效。macOS 与 Windows 安装包均通过官方开发者签名与公证。
