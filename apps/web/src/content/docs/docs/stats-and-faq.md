统计面板帮助你清晰复盘长期的阅读足迹与思考密度，而不是面对一堆杂乱的文件列表。统计涵盖「本地阅读」与「微信读书」两大维度。

## 核心统计指标

统计页提供全面的数据看板：

- **今日活动**：今日阅读时长与交互频次
- **连续与累计**：已记录阅读天数、每周活跃天数、活跃峰值
- **知识产出**：导入文章总数、划线批注总数、沉淀笔记总数
- **思考互动**：讨论发言总次数、AI 助手参与次数及贡献度

活动趋势图直观呈现文章导入、划线标注、深度沉淀与讨论评论的历史曲线；70 天阅读热力图清晰映射你的持续阅读节奏。

## 微信读书统计同步

在设置中绑定微信读书 API KEY 后，即可在统计页切换至「微信读书」视图。支持按**周度**、**月度**、**年度**与**全周期**查询阅读时长与书籍分布。已查询的数据会自动在本地离线缓存，无需每次重复调用远程接口。

## 常见问题与故障排查

### AI 功能没有响应或报错？

请按以下步骤逐一排查：

1. **模型服务商**：确认已在「设置 > 模型与路由」中添加了至少一个可用的模型供应商。
2. **API Key 校验**：检查 API Key 是否完整粘贴，未夹带多余前后空格。
3. **连通性测试**：点击供应商卡片上的「测试连接」，确认网络畅通且认证成功。
4. **任务路由分配**：确认已在「任务路由」中为「阅读理解助手」和「深度审阅助手」明确指定了模型。

### 网页文章导入失败？

常见诱因包括：

- URL 格式不规范，请确保以 `http://` 或 `https://` 开头。
- 目标链接指向本地回环（`localhost`）、局域网私有 IP 或云厂商元数据地址（默认触发安全防护拦截）。
- 网页 HTML 原始响应超过 5MB 限制。
- 目标网站配置了严格的反爬虫或登录墙防护。
- 网络连接超时或源站服务器无响应。

Yomitomo 会自动唤起内置无头环境解析动态页面，但极少数高度定制的前端应用可能仍无法提取纯文本正文。

### 电子书导入失败？

- 请确认文件扩展名为标准 `.epub`、`.azw3` 或 `.mobi`，且单本文件大小不超过 80MB。
- 受 DRM 数字版权加密保护、或内部解包解压后内容异常庞大的电子书无法导入。

### PDF 文档导入失败？

- 请确认文件为标准 `.pdf` 格式，且单份文档大小不超过 120MB。
- 密码加密或损坏的 PDF 需先在外部解密/修复后导入。

### 我的数据存储在哪里？

所有导入的阅读材料、划线、讨论记录与沉淀笔记均**完全保存在本地应用数据目录**中，绝不会上传至 Yomitomo 服务器。各模型供应商的 API Key 通过操作系统的最高安全级别凭据库（macOS Keychain / Windows Credential Manager）加密托管。

### Yomitomo 是否会收集个人隐私数据？

Yomitomo 默认每天最多发送一次轻量匿名心跳（包含匿名安装 ID、应用版本、操作系统类型、架构与本地时区），仅用于统计版本留存与系统分布。**绝不采集任何阅读内容、书名、划线批注、本地文件路径或 AI 对话记录**。你可以在「设置 > 通用 > 隐私」中随时关闭此项。

### 支持哪些操作系统？

目前全面支持 **macOS（Apple Silicon & Intel）** 与 **Windows（x64 & ARM64）**。
