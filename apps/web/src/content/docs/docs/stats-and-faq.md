统计面板帮助你清晰复盘长期的阅读足迹、思考密度与助手调用情况。统计页提供「本地阅读」、「助手用量」和「微信读书」视图。

## 核心统计指标

本地阅读统计页提供以下数据看板：

- **今日与累计活动**：沉淀、想法、划线与助手参与次数（本地统计不计阅读时长）
- **连续与累计**：已记录阅读天数、每周活跃天数、七日纪念章与活跃峰值
- **近 21 天活动趋势**：按日展示沉淀、想法与划线的历史走势
- **70 天伴读地图**：通过热力图直观映射你的持续阅读节奏

切换至「助手用量」视图，可按时间范围查看助手调用总次数、Token 消耗、基于 `models.dev` 公开价格估算的花费以及按助手/模型的分布。

## 微信读书统计同步

在设置中绑定微信读书 API Key 后，即可在统计页切换至「微信读书」视图。支持按**周度**、**月度**、**年度**与**全周期**查询阅读时长与书籍分布。已查询的数据会自动在本地离线缓存，无需每次重复调用远程接口。

## 常见问题与故障排查

### AI 功能没有响应或报错？

请按以下步骤逐一排查：

1. **模型服务商**：确认已在「设置 > 模型与路由」中添加了至少一个可用的模型供应商。
2. **API Key 校验**：检查 API Key 是否完整粘贴，未夹带多余前后空格。
3. **连通性测试**：打开该供应商的配置弹窗，点击底部的「测试」，确认网络畅通且认证成功。
4. **默认模型与路由**：确认已在「设置 > 模型与路由」的「模型使用方式」中选择了默认模型（若展开了「按任务单独设置」，确认对应任务已指定有效模型）。

### 网页文章导入失败？

常见诱因包括：

- URL 格式不规范，请确保以 `http://` 或 `https://` 开头。
- 网页 HTML 原始响应超过 5MB 限制。
- 目标网站配置了严格的反爬虫或登录墙防护。
- 网络连接超时或源站服务器无响应。

Yomitomo 会自动唤起内置无头环境解析动态页面，但极少数高度定制的前端应用可能仍无法提取纯文本正文。

### 电子书导入失败？

- 请确认文件扩展名为标准 `.epub`、`.azw3` 或 `.mobi`，且单本文件大小不超过 80MB。
- 受 DRM 数字版权加密保护、或内部解包解压后内容异常庞大的电子书无法导入。

### PDF 文档导入失败？

- 请确认文件为标准 `.pdf` 格式，且单份文档大小不超过 120MB。
- 密码加密或损坏的 PDF 需先在外部解密/修复后导入。

### 我的数据存储在哪里？

所有导入的阅读材料、划线、讨论记录与沉淀笔记均**完全保存在本地应用数据目录**中，绝不会上传至 Yomitomo 服务器。各模型供应商的 API Key 通过操作系统的安全凭据库（macOS Keychain / Windows Credential Manager）加密托管。使用远程 AI 功能时，任务所需的阅读内容与对话会发送到你配置的模型端点；连接本机模型时，推理在本机完成。

### Yomitomo 是否会收集个人隐私数据？

Yomitomo 默认每天最多发送一次轻量匿名心跳（包含匿名安装 ID、应用版本、操作系统类型与版本、架构、本地日期与时区），仅用于统计版本留存与系统分布。阅读记忆另外发送打开、查询完成、回源、复审决定和降级的次数，这部分不含安装 ID。**绝不采集任何阅读内容、书名、划线批注、本地文件路径或 AI 对话记录**。你可以在「设置 > 通用 > 隐私」中随时关闭此项，关闭后会清空尚未发送的阅读记忆计数。

### 支持哪些操作系统？

目前支持 **macOS（Apple Silicon）** 与 **Windows（x64）**。
