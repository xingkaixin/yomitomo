Yomitomo 是一款本地优先的 AI 伴读桌面应用。它不替你阅读，而是在你阅读时陪你划线、批注、追问与讨论。所有文章、批注、讨论记录、模型配置和 API Key 均完整保存在本机。

## 首次上手

1. 打开 Yomitomo，浏览欢迎介绍后进入应用。
2. 进入「设置 > 模型与路由」。
3. 添加模型供应商，填入 API Key 并点击「测试连接」。
4. 为阅读理解助手、深度审阅助手与双语翻译分配对应的任务路由。
5. 回到「阅读库」，导入网页文章、EPUB/AZW3/MOBI 电子书、PDF 或 Markdown 文本。

界面语言可在「设置 > 通用」中随时切换。官方文档同时提供[中文](/docs/)、[英文](/en/docs/)与[日文](/ja/docs/)版本。如需同步微信读书的划线、想法与进度，可先阅读「[获取微信读书 API KEY](/docs/weread-api-key/)」。

## 核心功能模块

Yomitomo 由以下核心功能模块组成：

- **阅读库**：集中管理网页文章、电子书（EPUB/AZW3/MOBI）、PDF 文档、Markdown/文本、微信读书笔记以及自定义合集。
- **阅读器**：提供沉浸式正文阅读、精准划线、划线讨论、双语翻译与知识沉淀（详见「[沉淀与审阅](/docs/sedimentation/)」）。
- **助手**：管理各类 AI 伴读助手与深度审阅助手，定制思考角色与提示词。
- **统计**：回看本地阅读时长、批注趋势与活跃热力图，支持同步并查询微信读书阅读数据。
- **设置**：配置界面语言、模型与路由、主题外观、反馈音效、应用锁、快捷键、本地数据与隐私。
- **微信读书**：基于官方 Skill 凭据，单向同步微信读书的书籍、划线、想法和阅读进度。

## 思考模型

Yomitomo 的核心不是帮你生成一键摘要，而是忠实保留你的完整判断链路：

- **划线**是原文的证据锚点。
- **想法**是阅读中最具价值的原生洞见。
- **讨论**让想法在追问与辩驳中持续迭代。
- **AI 伴读**只在你需要启发时加入讨论或参与共读。
