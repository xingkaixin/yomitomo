Released: 2026-09-05

## Features

- Added responsive decorative section backgrounds and tactile paper textures across the website hero, companion cards, article margins, and shared footer. (#882)
- Expanded scenario guides across English, Simplified Chinese, and Japanese with in-depth workflows for Readwise migration, local Ollama companions, Zotero academic research, and Obsidian knowledge graphs, upgraded for helpful content SEO. (#883)

## Performance

- Optimized website fonts and media loading: subsetted CJK web fonts dynamically to slash font bundle size by over 93%, provided responsive multi-density WebP screenshots and avatar variants, and added explicit image aspect dimensions to boost mobile LCP. (#882)

## Fixes

- Fixed blog and documentation sidebar visibility layers above the shared footer, keeping table of contents and reading progress visible when reaching page ends. (#882, #883)

## Engineering

- Upgraded Electron, pnpm (11.25.0), and runtime/build dependencies to secure releases with zero known vulnerabilities. (#886)
- Upgraded test runner to Vitest 5 and improved preload module test isolation. (#885)
- Scoped repository and desktop agent guidance to clarify main/renderer architecture boundaries. (#884)
