Released: 2026-10-13

## Fixes

- Fixed EPUB annotation jumps during book opening, repeated-text anchors, and selections across line breaks; ignored PDF selection text that arrives after the selection changes. (#950, #951, #962)
- Prevented duplicate annotations from repeated save actions and kept translation annotations when retranslation fails before starting. (#956, #967)
- Fixed custom Anthropic proxy URLs and treated interrupted AI streams as failures; deep-to-fast fallback now discards the incomplete deep reply. (#952, #957)
- Applied assistant and visibility filters before limiting memory search results, and checked nearby duplicate thoughts before limiting matches. (#958)
- Preserved search highlight positions after case folding, including text whose lowercase form changes length. (#965)
- Counted annotations, discussions, and distillations on the day they happened, preserving historical activity and reading streaks when an article is reopened. (#953)
- Rejected WeRead sync results after the API key changes and retried the value that failed to save. (#964, #966)
- Prevented late model-list responses from overwriting provider edits or another provider's settings. (#968)
- Preserved legacy API keys when keyring migration is unavailable and stopped using old keyring credentials after key removal or backup restore. (#954)
- Closed discussion and distillation windows when the app locks, canceling the AI requests they started. (#949)
- Denied permission requests and popups from pages loaded for article import. (#948)
- Used full URL digests for new web article IDs to avoid collisions while keeping existing article IDs. (#959)
- Restored the mobile documentation sidebar and kept keyboard focus inside the website reading demo dialog. (#955, #960)

## Engineering

- Completed third-party notices for code shipped with the desktop app and checked them before release packaging. (#963)
- Aligned network and privacy documentation with telemetry, model pricing requests, and actual app lock behavior. (#961)
- Upgraded Electron to 44.7.0, pnpm to 12.11.2, and runtime/build dependencies and CI actions, retaining the model runtime versions required by installed Reading Memory models. (#969)
