Released: 2026-10-09

## Performance

- Deferred startup modules and heavy import dependencies, bounded cover caches, and resized assistant images to reduce startup work and memory use. (#931, #932, #933, #942, #943)
- Reduced reader re-renders, article recomputation, and whole-document scans during text operations. (#934, #935)
- Replaced Reading Memory background polling with notifications and avoided repeated model hashing and search buffer copies. (#936, #937)
- Separated article bodies from metadata so saving reading progress no longer rewrites full book content; settings saves also avoid loading article summaries. (#938, #940)
- Preferred system CJK fonts for the interface and appended log lines with fewer file operations. (#939, #941)

## Fixes

- Preserved web reader text selections while annotations update. (#944)
- Fixed web article imports being rejected under fake-IP proxies such as Clash and Surge; private network articles also no longer require a separate setting. (#946)
- Restricted desktop packages to build outputs and runtime resources to avoid bundling unnecessary project files. (#930)

## Engineering

- Improved website search and download tracking, and migrated website and Worker deployments to the cf CLI. (#922, #926)
- Reduced test startup overhead, removed low-value tests, and cached CI tasks. (#923, #924, #925)
- Centralized shared dependency versions, consolidated project documentation, and removed unused selection routing and daily quote code. (#927, #928, #929, #945)

## Upgrade notes

- Back up your data before upgrading. This release migrates the database to reader level 4; v0.16.2 and earlier cannot open it afterward. To downgrade, restore a compatible backup made before upgrading. (#938)
