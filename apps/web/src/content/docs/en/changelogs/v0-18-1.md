Released: 2026-11-20

## Features

- Minimizing a discussion window now returns it to a folded-bookmark capsule in the reader instead of the Dock or taskbar. Opening the capsule restores the same window and unsent reply. Drag the capsule group to any corner of the reader; the minimize and restore animation stays continuous when the window extends past the reader. (#1084, #1085, #1091)
- Press ⌘F / Ctrl+F to search the current web article, ebook, or PDF. The selection menu adds a one-click Highlight that saves without opening the composer. In-article anchors and footnotes scroll within the reader, and passage links in discussion or distillation windows open the article in the main window and briefly mark the passage. (#1100)
- Edit your own thoughts and replies after saving; AI replies and highlighted excerpts stay unchanged. Each highlight can have its own color from the card menu or discussion header. (#1101)
- Export or copy Markdown for an article's notes, a distillation, or WeRead book notes. Highlights, thoughts, discussions, and published distillations are kept verbatim. (#1102)
- Failed assistant replies show the cause, such as a missing model, invalid key, insufficient balance, rate limiting, or network failure, with a retry button and a link to model settings. Reader Q&A can stop generation, start, switch, or clear sessions, and copy answers. The embedded WeRead reader hides while a dialog is open and keeps its reading position. (#1104)
- Reading memory links directly to the local model download or provider setup when it is not ready, and shows model download and indexing progress. Library questions keep up to 20 entries of session history and can be copied as Markdown with citations. Provider configurations can be duplicated; the API key is copied into a separate keychain entry. (#1105)
- Drag EPUB, AZW3, MOBI, PDF, TXT, or Markdown files onto the library to import them, or use File > Import Text. Card menus add Add to Collection and Edit Info for title and author. Sort the library by recently updated, title, progress, or annotation count, and filter by unread, reading, finished, or annotated. When a local PDF or ebook file is missing, choose it again from the reader. (#1107)
- Translate the current PDF page into a bilingual overlay; this first version targets single-column text PDFs and rejects scanned pages without a text layer. PDFs add a dark eye-care filter, fit-width, fit-page, and 100% presets, and ⌘/Ctrl + / − / 0 zoom shortcuts. (#1108)
- Added OpenRouter and Vercel AI Gateway provider presets. (#1111)

## Performance

- PDF import and thumbnail rendering run in a worker thread instead of the main process. The reader releases the PDF file buffer once it is loaded, and full-book text is sent to the assistant only when text or the outline changes. (#1096)
- SQLite uses `synchronous = NORMAL` and a busy timeout, runs `VACUUM` in the background after startup, and drops an obsolete index that slowed reading-progress writes. (#1097)
- Reading memory shares one embedding worker for queries and indexing, with queries served first, and speeds up the review query. (#1098)
- Bilingual translation sends only the finished paragraph on each update instead of the whole translation, and web reader highlight layout avoids recomputing on every render. (#1095)

## Fixes

- Backup and restore no longer fail as busy while WeRead sync, translation, or imports wait on the network. Quitting no longer hangs on stalled background work. (#1097)
- EPUB reading-memory search, thread reading, and reply links follow the assistant's readable range, so they no longer expose notes from unread chapters. (#1082)
- Replies to a thought deleted in another window are rejected and keep the draft. Switching assistants no longer drops a reply that has just arrived, and a single-book WeRead refresh during a full sync no longer loses new notes. (#1088, #1089, #1090)
- Assistant sessions no longer skip a message after the app exits mid-delivery, and retracting a comment in one discussion no longer affects another. Reader Q&A syncs across windows without overwriting newer replies, and database restore stops active assistant and reading-memory work first. (#1092, #1093, #1099)
- Web article import uses separate timeouts for direct fetching and browser rendering and retries empty single-page app shells with rendering. EPUBs with `%` in file paths import correctly, and import failures show specific reasons. (#1095)
- Diagnostic log entries written during log cleanup are no longer lost, and the agent log is capped at 10 MB. (#1094, #1095)

## Engineering

- Upgraded Effect to 4.1.4, Electron to 45.3.3, better-sqlite3 to 13.2.0, pnpm to 12.21.0, and Astro, Vite, DOMPurify, and other dependencies; refreshed third-party notices. Type-aware linting now uses tsrs, cutting median lint time from about 8 s to 3 s. (#1086, #1087)
- Added an offline exporter for reading-memory human review templates and a local task for emulated-AI debugging. (#1083, #1110)
