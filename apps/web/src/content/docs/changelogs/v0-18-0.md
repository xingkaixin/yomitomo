发布日期：2026-11-13

## 新功能

- 阅读库改为书架，材料以书籍封面展示，合集以木箱展示。可拖动书籍归入合集，也可在合集内挑选材料；翻页平滑切换，空合集提供添加引导。(#1054–#1061, #1074, #1075, #1077)
- 原有主题统一为亮色、暗色和跟随系统，旧主题保留原来的亮暗倾向。设置与主题切换移到侧栏底部，字号与阅读栏宽移到阅读器工具栏。(#1032, #1045, #1053)
- 统一侧栏、阅读器、设置、助手、统计、阅读记忆和独立对话窗口的界面材质。讨论改为聊天气泡，划线使用手绘下划线，正文与批注卡片通过脚注编号对应。(#1033–#1044, #1046, #1052, #1076)
- 可在设置中选择在 Yomitomo 内打开微信读书网页版。用小窗回看划线，或展开阅读；小窗中定位、跳章节和翻页不改变微信读书账号的阅读进度。(#1050)
- 首次启动增加开场动画与音乐，重新设计文件导入并更新反馈音效。打开阅读器、删除书籍、生成 AI 结果和顶部通知增加动作反馈。(#1031, #1056, #1062–#1068)
- 更新预置模型，按型号设置上下文与输出上限，避免思考模型在回答前耗尽原有的 4,096 token 输出额度；修复 Moonshot、智谱和国内百炼的花费估算。(#1072)
- 新增 Gemini 4 Hydrogen 和 Carbon 预置，配置可用思考级别和 65,536 token 输出上限。Gemini 默认模型保持不变；pi-ai 尚未支持 Hydrogen 的 xhigh 传输，该设置暂按 high 发送。

## 性能

- EPUB 切换章节后释放旧章节文档，并以更大的块读取压缩内容，减少残留章节内存和多图书籍的加载开销。(#1029)

## 修复

- 恢复沉淀审阅建议的逐条定位、独立滚动的变更预览和引用回源。助手引用显示原文摘录，旧回复也不再显示内部段落编号；用户写下的内容保持原样。(#1080)
- EPUB 正文中的快捷键正常传递给阅读器，内容面板顶部的空隙可拖动窗口。(#1069, #1070, #1071)
- 丢弃过期的供应商与微信读书连接测试结果，防止手动同步书库重叠，并按网关要求使用微信读书 Skill 版本。(#1021, #1028, #1048)
- 延迟返回的主题保存和助手错误不再影响新状态；导入拒绝取消时继续显示进度，应用锁定失败时给出提示。(#1022, #1024, #1027)
- 助手执行失败时正确结束任务，修复新想法与整理讨论的重试流程，并补索引后台最后一轮处理期间新增的阅读证据。(#1023, #1025, #1026)
- 独立数据目录使用独立钥匙串条目，测试或其他配置目录不再复用主目录的凭据。(#1051)

## 工程

- 升级 Electron 至 45.2.3、Node.js 至 24.22.3、pnpm 至 12.18.0、Effect 至 4.1.3、pi 至 1.5.2；更新依赖、第三方声明和 undici 安全补丁。(#1072, #1073, #1078)
- 测试聚焦产品与数据保证，明确产品边界，移除未使用的微信读书统计字段，并新增发版前预置模型检查。(#1020, #1030, #1049, #1072)
- 官网预览、截图和三语帮助文档同步当前桌面界面。(#1079)
