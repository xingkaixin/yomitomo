发布日期：2026-11-27

## 新功能

- 新增「使用 ChatGPT 登录」供应商预置，通过浏览器 OAuth 登录 ChatGPT 账号即可调用模型，无需配置 API Key。OAuth 凭据存放在系统钥匙串中且不包含在完整备份内，令牌到期自动刷新，所有 ChatGPT 配置共用同一账号连接。(#1116)
- 模型供应商设置新增按模型能力适配的「思考强度」选项，自动限制为模型支持的档位，并修复 `gpt-6.2-sol` 的档位映射。(#1116)
- 首次启动开场背景音乐由合成音频替换为录制音轨。(#1119)
- 更新预置模型：从月之暗面移除已弃用的 `kimi-k2.6`（默认改用 `kimi-k3.1-pro`），并按 models.dev 更新阿里云百炼（`qwen3.7-plus`）与火山引擎（`doubao-seed-2-1-lite-260915`、`doubao-seed-2-1-pro-260915`、`deepseek-v4-1-flash-260910`）的输出上限。

## 性能

- 延迟主进程启动导入与 SQLite 初始化，拆分渲染进程启动并预取阅读库目录，缩短桌面端启动耗时。(#1120)
- 为阅读库目录查询新增 top-k 快速路径，并加快 EPUB 压缩包加载与章节排版。(#1120)
- 压缩官网落地页图片、样式表与构建产物，减少传输体积。(#1120)

## 修复

- 修复启动更新检查在记录 `lastSeenVersion` 时带入旧设置对象、覆盖并发设置写入（如任务路由）的问题。(#1123)

## 工程

- 升级 `@earendil-works/*`（`pi-durable`、`pi-ai`、`chord`、`pi-schema`）至 1.6.1、Effect 至 4.1.5、Electron 至 45.5.0、pnpm 至 12.23.0 及其他上游依赖；移除已被 `pi-ai` 1.6.1 原生支持的 Gemini 4 临时回退并更新第三方声明。(#1123)
- 重做官网首屏背景与统一页脚，优化落地页 SEO 与作者博客链接，并校准中英日三语官网、帮助文档与博客内容。(#1117, #1118, #1121, #1122)
