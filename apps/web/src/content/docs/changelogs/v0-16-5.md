发布日期：2026-10-17

## 新功能

- 助手为每篇材料保留对话记忆，讨论回复、划线想法和阅读问答会延续之前的交流。助手按需查阅目录、章节、原文检索、阅读记忆和讨论串；EPUB 中从划线发起时可阅读所在整章，未选中文本的提问以阅读进度为界。(#971)
- 关闭窗口后助手回复继续进行，重启应用后自动恢复；同时被提及的多位助手并行回复。工具调用前写下的文字会保留，讨论区和阅读问答会显示每个工具步骤。移除「助手执行模式」（快速回应 / 深入查证）设置。(#971)
- 回复中引用的段落和讨论变为带下划线的链接，点击可在阅读器中定位原文或打开对应讨论。(#971)
- 沉淀审阅延续审阅助手在这篇材料中的对话；审阅条目不合格时由模型修正后重新提交，不再导致整次审阅失败。(#972)
- 预设模型更新为当前版本并移除已下线的模型 ID，重新整理本地阅读记忆设置卡片。(#972)

## 修复

- 按 pi-ai 模型目录为各模型设置思考与温度参数，Claude 5、Gemini 3.8、GPT-6 等模型不再收到不支持的参数；温度仅在关闭思考时生效。(#972)
- 供应商模型列表过长时改为滚动，不再挤压列表项或截断底部。(#972)

## 工程

- 助手回复、沉淀审阅、翻译、阅读判断、`@` 提及路由和连接测试迁移到 pi-ai 与 pi-durable，移除 AI SDK 工具循环运行时和旧的评论流。(#971, #972)
- 移除未使用的批注生成、助手审阅、阅读上下文和记忆视图代码。(#972, #973)
