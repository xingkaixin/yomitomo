发布日期：2026-08-25

## 新功能

- 桌面端、助手角色、官网、帮助文档与更新说明新增日文支持，可与简体中文、英文一起在设置中切换。(#775)
- 更新弹窗与顶部入口新增后台下载进度，实时显示已下载大小、总大小和速度；关闭弹窗后仍保留下载状态，差分更新改用稳定的顺序分段请求。(#833)

## 性能

- 移除阅读器运行时 CSS 压缩，批量处理流式增量与模型价格回填，并减少目录重复查询，让阅读、流式响应和大书库刷新少做重复工作。(#782, #791, #810, #818)

## 修复

- 阻止过期沉淀写入，正确解析嵌套评论，校验阅读记忆数据，恢复失败的评论修改，同步对话活跃时间，协调阅读器持久化失败，并停止阅读器递归更新。(#776, #796, #798, #802, #805, #817, #834)
- 数据库恢复、设置保存、凭据清理、文章删除与迁移失败时，保留原数据、目录修订和正在使用的导入弹窗；来源内容损坏时会给出可处理的错误。(#794, #795, #800, #801, #803, #804, #806, #819, #820)
- 校验所有 invoke 参数且不改变 schema 解析语义，导入错误改为结构化返回，并允许可信的内联图片助手头像通过 IPC。(#788, #797, #816, #835)

## 工程

- 简化导入弹窗、阅读器格式、批注、导航、设置、桌面 store、IPC 契约、AI 生成、沉淀与阅读库会话的状态归属和生命周期。(#777–#780, #783–#787, #789–#790, #792, #799, #807–#809, #811–#815, #822–#830)
- 拆分过大的测试套件，替换脆弱的源码字符串断言，扩大真实 SQLite 覆盖，并升级上游依赖。(#781, #793, #821, #831, #832)
- 让 native SQLite 验证与 macOS 准备流程识别 `better-sqlite3` 预编译产物，并把 native 校验纳入桌面构建，使发布打包问题提前在 PR CI 暴露。(#837)
