发布日期：2026-11-03

## 新功能

- 新增蓝墨亮色主题：冷白纸面、钢笔蓝墨和铅笔手绘的边框与线条，覆盖书库、设置、统计、阅读记忆、助手、对话框和阅读器界面；书籍正文不加装饰。(#1007)
- 重新设计首次启动页面：增加语言切换，以划线、想法和助手回复的示例说明阅读体验，并注明不接入 AI 也能阅读；导入入口补充 AZW3 和 MOBI。(#1006)
- 卡片在批注与沉淀之间切换时改为 3D 翻转，发布沉淀时播放翻纸音效；堆叠卡片从顶角展开，批注较多时提交沉淀不再卡顿。(#1008)
- 更换应用图标和官网标志；官网重新设计落地页、文档布局和 404 页面，字体下载量减少 67–90%。(#1011, #1012)

## 性能

- PDF 页面直接绘制到 canvas，打开大型 PDF 时内存占用降低 24–27%，滚动时降低 24–35%，首帧更快。(#999)
- 清理旧版本导入 EPUB 时存入章节的 base64 图片。在示例书库中章节数据从 53 MB 降至 4.4 MB，大书翻页不再推高内存。(#1000)
- 最多同时导入三本电子书，批量导入耗时约减半。(#1018)
- 网页文章图片并发下载，单张慢图不再拖慢其他图片；站点图标 3 秒超时。(#1017)
- 钥匙串读取移出主线程，每次助手回复少一次钥匙串读取；助手写想法前不再多调用一次模型。(#1014, #1015)
- 并行执行启动时的缓存清理、备份文件校验和首次打开电子书的加载。(#1016)

## 修复

- 修复老用户的任务模型设置：未单独设置的任务跟随默认模型并显示「继承默认模型」；只设置默认模型时，助手不再提示缺少路由。(#1005)
- 打开 PDF 时停在首页顶部，顶部附近的批注立即可见。(#1004)
- 滚动时批注栏卡片的出现、消失和移动更平滑，密集页面不再跳动或闪烁。(#1003)
- 切换堆叠批注卡片时只移动被交换的卡片，较短的后排卡片在较高卡片后方保持可见。(#1002)
- 关闭阅读器目录时面板正常收起，不再先变成半透明。(#1001)

## 工程

- 渲染进程状态迁移到 zustand store、reducer 和 TanStack Query，并限制渲染进程代码直接使用状态与副作用 hooks。(#983–#997)
- 升级 Electron 至 45.2.1、Node.js 至 24.22.2、Effect 至 4.1.1、pi 至 1.5.0，更新 undici 安全版本，并关闭服务商请求中的 pi 归属请求头。(#979, #998, #1013)
- 以并行 job 和按改动范围跳过加快 CI，oxlint suspicious 与 perf 规则改为阻断，新增打包版启动基准脚本。(#978, #980, #1009)
- 精简 README 与官网文案。(#981, #982)
