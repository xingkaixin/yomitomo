发布日期：2026-07-31

## 新功能

- 明确网页文章、电子书、PDF 与文本导入的文章身份和来源阅读模型，让内容在应用中流转时，翻译、进度与批注始终绑定同一个来源。(#732, #733, #736, #770)
- 深化助手任务编排并统一工具循环入口，让流式任务绑定到发起它的窗口，同时限制模型枚举规模。(#738, #739, #755, #759, #772)

## 性能

- SQLite 目录改为分页，并复用词法、章节前缀、文本范围和助手索引，减少大书库与长文阅读中的重复扫描。(#711, #712, #713, #726–#730, #761)
- 微信读书快照按块批量写入，并拆分 PDF 与电子书阅读工具，减少无关计算。(#742, #756)

## 修复

- PDF 滚动时保持选区锚定；文本导入后无需重启即可显示；更新弹窗会先打开，再加载更新说明。(#760, #765, #766)
- 为文本导入与 Kindle 解码设置工作量上限，校验事件与流式 IPC，按窗口角色授权入站 IPC，并明确数据库恢复生命周期。(#709, #751–#754)
- 异步日志写入、来源生命周期变更和凭据替换失败后都可以恢复，不再留下半完成状态。(#706–#708)

## 工程

- 集中管理桌面 IPC 描述符、preload 域、文章 reconciler、应用会话归属和应用锁读取，收窄跨层契约。(#714, #720, #725, #744, #758, #767, #768)
- 统一作者身份、翻译会话、目录条目变体、批注接受流程和来源阅读器边界；清理未使用的包导出并迁移到 Hugeicons 图标。(#716, #718, #723, #735, #737, #740, #743, #745–#750, #771)
- 增加 PDF 翻译、文章阅读记忆和 preload 接口的桌面 UI/E2E 刻画测试，并让发布门禁文档可验证。(#757, #762–#764)
