发布日期：2026-10-03

## 新功能

- 新增完整备份与还原，包含数据库、电子书与 PDF 原文件及 PDF 缩略图。备份不包含 API Key；还原前校验文件摘要，并保留当前数据的安全备份。(#913)
- 首次启动改为阅读任务引导，可直接导入 EPUB、PDF 或网页。普通阅读与手动批注仍无需配置 AI。(#910)
- 阅读理解、深度审阅与翻译可共用一个默认模型，需要时再按任务单独设置。(#912)

## 性能

- 减少批注卡片的重复渲染与日期格式化开销，调整字号时复用高亮元素。(#920)
- 阅读时暂停不可见书库的目录查询，并移除初始化时的一次重复查询。(#915, #918)
- 电子书导入解析移入 Worker，空闲时释放本地向量推理进程，减少主进程工作与内存占用。(#916, #917)
- AI 批注仅在回退匹配需要时建立文本映射，减少重复准备。(#914)

## 修复

- 取消翻译时同步中止底层模型请求。(#907)
- 微信读书同步批次失败后，取消批次内剩余请求，避免继续运行。(#906)
- 明确「问书库」只检索已保存的阅读记录，不搜索资料全文或未发布的沉淀草稿。(#911)

## 工程

- 使用 Effect 管理后台任务与本地推理的生命周期，协调取消与清理。(#908, #909)
- 增加书库查询与批注卡片的性能观测，为优化提供测量依据。(#918, #919, #920)
