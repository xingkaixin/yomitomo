## 新功能

- 最小化讨论窗口时，窗口收回阅读器中的折页书签胶囊，不再进入程序坞或任务栏。点开胶囊即可恢复同一窗口和未发送的回复。胶囊组可拖到阅读器任一角落停靠；讨论窗口超出阅读器时，收起与展开动画保持连贯。(#1084, #1085, #1091)
- 按 ⌘F / Ctrl+F 在当前网页文章、电子书或 PDF 中搜索。选区菜单新增一键「划线」，无需打开输入框即可保存。文内锚点与脚注在阅读器内滚动定位；在讨论或沉淀窗口点击段落引用，会在主窗口打开对应材料并短暂标出该段落。(#1100)
- 保存后的想法和回复可以编辑，仅限你自己写的内容；AI 回复和划线原文保持不变。每条划线可在卡片菜单或讨论窗口顶部单独设置颜色。(#1101)
- 文章笔记、沉淀和微信读书书籍笔记可导出或复制为 Markdown，划线、想法、讨论和已发布沉淀按原文保留。(#1102)
- 助手回复失败时显示原因，例如未配置模型、Key 无效、余额不足、请求限流或网络失败，并提供重试和前往模型设置。阅读问答支持停止生成、新建、切换和清空会话，以及复制回答。打开设置等弹窗时，内嵌微信读书暂时隐藏并保留阅读位置。(#1104)
- 阅读记忆未就绪时可直接前往下载本地模型或配置模型服务，并显示模型下载与索引进度。问书库保留本次最多 20 条提问记录，回答可连同引用复制为 Markdown。模型供应商配置支持复制，API Key 会复制为独立的钥匙串条目。(#1105)
- 可将 EPUB、AZW3、MOBI、PDF、TXT 或 Markdown 文件直接拖入阅读库导入，也可使用「文件 > 导入文本」。卡片菜单新增「加入合集」和「编辑信息」（标题与作者）。阅读库可按最近更新、标题、阅读进度或批注数排序，并按未读、阅读中、已读完或有批注筛选。本地 PDF 或电子书文件丢失时，可在阅读器中重新选择文件。(#1107)
- PDF 支持按页双语翻译，译文叠加在页面上；首版面向单栏文本型 PDF，没有文本层的扫描页不会翻译。PDF 新增深色护眼滤镜、适应宽度、适应整页和 100% 缩放，以及 ⌘/Ctrl + / − / 0 缩放快捷键。(#1108)
- 新增 OpenRouter 和 Vercel AI Gateway 供应商预置。(#1111)

## 性能

- PDF 导入和缩略图渲染移到工作线程，不再占用主进程。阅读器载入 PDF 后释放文件缓冲；只有正文或目录变化时才向助手发送全书文本。(#1096)
- SQLite 启用 `synchronous = NORMAL` 与忙等待超时，`VACUUM` 改到启动后在后台执行，并删除拖慢阅读进度写入的过时索引。(#1097)
- 阅读记忆的检索与索引共用一个向量模型进程，检索优先；重新审视的查询更快。(#1098)
- 双语翻译每完成一段只发送该段，不再重复发送整份译文；网页阅读器的划线定位不再在每次渲染时重算。(#1095)

## 修复

- 微信读书同步、翻译或导入等待网络时，备份与还原不再报数据库忙；后台任务卡住时退出应用不再挂起。(#1097)
- EPUB 的阅读记忆检索、讨论读取和回复链接遵守助手的可读范围，不再暴露未读章节的笔记。(#1082)
- 回复已在其他窗口删除的想法时会被拒绝并保留草稿；切换助手不再丢失刚到达的回复；全量同步期间单独刷新微信读书书籍不再丢失新笔记。(#1088, #1089, #1090)
- 投递中途退出应用后，助手不再跳过消息；在一个讨论中撤回评论不再影响其他讨论。阅读问答跨窗口同步且不覆盖较新的回复；还原数据库前会先停止进行中的助手和阅读记忆任务。(#1092, #1093, #1099)
- 网页文章导入为直接抓取和浏览器渲染分别计时，空白的单页应用外壳会改用渲染重试；文件路径含 `%` 的 EPUB 可正常导入，导入失败时显示具体原因。(#1095)
- 日志清理期间写入的诊断记录不再丢失，助手日志上限为 10 MB。(#1094, #1095)

## 工程

- 升级 Effect 至 4.1.4、Electron 至 45.3.3、better-sqlite3 至 13.2.0、pnpm 至 12.21.0，并更新 Astro、Vite、DOMPurify 等依赖和第三方声明。类型感知 lint 改用 tsrs，中位耗时从约 8 秒降至 3 秒。(#1086, #1087)
- 新增阅读记忆人工复核模板的离线导出工具和本地模拟 AI 调试任务。(#1083, #1110)
