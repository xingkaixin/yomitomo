发布日期：2026-08-31

## 新功能

- 新增「阅读记忆」（Reading Memory）：本地优先的语义证据与检索体系，将阅读笔记与批注投射为版本化向量索引，支持从 ModelScope 与 Hugging Face 直接下载模型并在独立的子进程中运行本地推理。(#865–#870, #872, #880)
- 新增限定书库范围提问与带引用的研判生成：支持跨文献提问已有阅读资产，基于原文证据生成研判，并支持将引用的想法一键流转为对话草稿。(#871, #873, #875)
- 在网页、EPUB 与 PDF 中新增阅读证据关联面板：选中文本即可探索关联证据卡片，精准反查原文上下文与 PDF 页面坐标，并提供明确的隐私授权机制。(#874)
- 新增盲评研判审查流与发布质量门禁，支持只追加的评审记录链与方向性检索评测校验。(#876, #877, #878)
- 官网 Landing Page 接入轻量、隐私友好的 Umami 访问统计。(#864)

## 性能

- 将本地向量推理隔离至独立子进程，解耦向量索引与 SQLite 锁占用，并对流式图片下载、PDF 缩略图位图尺寸与向量推理批次设置上限，保障内存与阅读响应。(#847, #848, #868, #870, #872)

## 修复

- 微信读书同步改为串行处理，保持设置变更顺序，在重置草稿前优先应用已保存凭据，并在数据库恢复后正确重建同步配置。(#844, #855, #859, #862, #863)
- 对话请求与批注更新严格绑定所属文章，阅读进度保存时保留当前选区，对话请求自动携带最近对话上下文。(#839, #840, #842, #852, #854, #873)
- 书库在重新导入与本地编辑后保持分页与筛选状态，电子书改用完整文件指纹以防止不同版本互相覆盖。(#841, #845, #849, #850, #858)
- 设置手动保存期间保护编辑草稿不被重置，串行化 Provider 保存与删除操作，恢复中断的翻译会话并精确匹配目标语言。(#843, #846, #851, #853, #856)
- 数据库恢复期间安全暂停后台任务并在恢复后正确清理，更新检查期间保留正在进行的下载进度。(#838, #857, #860, #861)

## 工程

- 为阅读记忆构建了发布质量门禁、方向性检索基准、盲评审查流以及打包测试夹具。(#867, #870, #876, #877, #878)
- 优化了中文、英文与日文全语言的帮助文档与场景指南文案。(#879)
