发布日期：2026-10-01

## 新功能

- macOS 更新切换至 Sparkle，并新增阅读主题的 DMG 安装背景。旧版首次升级仍下载完整 ZIP；安装并重启后，后续版本可使用差分更新，无法使用差分时回退完整包。(#893)

## 性能

- 阅读器搜索复用当前文档的标准化文本与位置映射，减少连续修改关键词时的重复计算。(#894)
- PDF 引擎移入 Worker，减少界面主线程上的处理；打开 PDF 时优先提取当前页与相邻页文本，全文搜索和需要全文的助手操作再按需准备全文。(#895, #896)
- 阅读记忆语义检索限制临时候选列表大小，减少大书库查询时的内存占用。(#899)
- 官网带内容指纹的静态资源使用一年缓存，减少再次访问时的资源下载。(#890)

## 修复

- 首次启动可直接进入阅读，无须逐页看完引导；AI 配置可稍后完成。(#897)
- 改善官网移动端产品预览布局与下载按钮的平台标识。(#892)
- 明确本地阅读数据、远程 AI 请求和数据库备份的边界；修正文档，将未实现的整书导出等说明改为逐条手动复制。(#898, #900)

## 工程

- 升级 Electron 至 44.3.0、pnpm 至 12.3.4，并更新运行时与构建依赖。(#889, #891)
- 发布流程新增签名的 Sparkle feed、差分产物与 macOS 更新烟测，保留旧版更新所需的 ZIP、blockmap 和 latest-mac.yml。(#893)
