发布日期：2026-10-13

## 修复

- 修复 EPUB 打开过程中的批注跳转、重复文本定位和跨换行划线；PDF 选区变更后忽略延迟返回的旧文本。(#950, #951, #962)
- 防止连续点击保存产生重复批注；重新翻译未能启动时保留原有翻译批注。(#956, #967)
- 修复自定义 Anthropic 代理地址，AI 流中途出错时按失败处理；深度核验回退快速回复时清除未完成的深度回复。(#952, #957)
- 助手记忆搜索先按助手与可见范围筛选，再限制结果数量；重复想法检查也先筛选当前锚点附近的记录。(#958)
- 修复大小写转换后搜索高亮的位置，包含小写形式长度发生变化的字符。(#965)
- 批注、讨论与沉淀按实际发生日期统计，重新打开文章不再挪动历史活动或重置阅读连续天数。(#953)
- 微信读书 API Key 更换后丢弃旧同步结果；保存失败时重试原先失败的值。(#964, #966)
- 模型列表延迟返回时，不再覆盖期间修改的供应商配置或另一个供应商的设置。(#968)
- 系统钥匙串暂不可用时保留待迁移的旧 API Key；删除密钥或还原备份后不再使用钥匙串中的旧凭据。(#954)
- 应用锁定时关闭讨论与沉淀窗口，并取消这些窗口发起的 AI 请求。(#949)
- 拒绝网页导入过程中页面发起的权限请求与弹出窗口。(#948)
- 新网页文章使用完整 URL 摘要生成 ID，避免碰撞，同时保留已有文章的 ID。(#959)
- 恢复官网移动端文档侧栏，并将键盘焦点保持在阅读演示弹窗内。(#955, #960)

## 工程

- 补全桌面端随包分发代码的第三方声明，并在发布打包前校验。(#963)
- 按实际行为完善遥测、模型价格请求与应用锁的网络及隐私说明。(#961)
- 升级 Electron 至 44.7.0、pnpm 至 12.11.2，并更新运行时、构建依赖与 CI actions；保留已安装阅读记忆模型要求的运行时版本。(#969)
